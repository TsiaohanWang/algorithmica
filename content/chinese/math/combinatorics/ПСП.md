正确括号序列（ПСП）有几种定义。

1）非形式定义

ПСП 是从算术表达式中删去除括号外的一切所得的、由开闭括号组成的字符串。

例如：从表达式 $(1 + 2) \* (3 + 100 \* (3 / 2))$ 得到 ПСП $()(())$。而 $)(())$ 不能由任何表达式得到。

2）显式定义

ПСП 是这样一种由开闭括号组成的字符串：所有括号都能配成对，其中第一括号是开、第二是闭，开在前闭在后，且任意两对不交叉。

例如：$((())())$ 是 ПСП，因为能配成如下不交叉的配对：
$\\textbf{(}\\underline{(}\\overline{(}\\overline{)}\\underline{)}\\textit{()}\\textbf{)}$。而字符串 $(()$ 无法配对——括号数为奇数。

3）递归定义

  - 空串是 ПСП
  - 如果 $A$ 是 ПСП，则 $(A)$ 也是 ПСП
  - 如果 $A$ 和 $B$ 是 ПСП，则 $AB$ 也是 ПСП

例如：空串是 ПСП，所以 $()$ 是 ПСП，所以 $(())$ 是 ПСП，所以 $(())()$ 是 ПСП，所以 $((())())$ 是 ПСП。而 $())((()$ 用这些规则无论如何也得不到。

4）用平衡定义 ПСП 是开闭括号组成的字符串。定义长度为 $n$ 的前缀上的**平衡**为该前缀上开括号与闭括号数之差。则 ПСП 必须满足两条性质：

  - 任意平衡大于或等于 0
  - 整串的平衡为 0

即在任何前缀上开括号不少于闭括号，整串中二者数量相等。

事实证明，判断字符串是否为 ПСП 用最后这个定义最方便。即从左到右遍历，遇到开括号加 $+1$，遇到闭括号加 $-1$。只需检查平衡始终非负、且最后为零。

还可以定义含多种括号的 ПСП。例如 $(\[\](\\{\\}))$ 是 ПСП，而 $\[(\])$ 不是。在显式定义里只需补充：同一对中的括号必须是同一种。在递归定义里要为每种括号加规则「如果 $A$ 是 ПСП，则 $\[A\]$ 也是 ПСП」。

但平衡定义不容易这样推广，而我们正想用它做 ПСП 检查算法。为推广要用栈：

ПСП 是这样一种由不同类型开闭括号组成的字符串：在遍历字符串构建开括号栈的过程中不出现错误，且最后栈为空。即维护一个空栈，从左到右遍历，遇到开括号把它压入栈尾，遇到闭括号则弹出——但需检查弹出的是与所遇闭括号同类型的开括号。

例如：字符串 $\\{\[(\[\])()\]{}\\}$。算法中栈的变化如下：

  - 空
  - $\\{$
  - $\\{\[$
  - $\\{\[($
  - $\\{\[(\[$
  - $\\{\[($ - 弹出的 $\[$ 匹配 $\]$
  - $\\{\[$ - 弹出的 $($ 匹配 $)$
  - $\\{\[($
  - $\\{\[$ - 弹出的 $($ 匹配 $)$
  - $\\{$ - 弹出的 $\[$ 匹配 $\]$
  - $\\{\\{$
  - $\\{$ - 弹出的 $\\{$ 匹配 $\\}$
  - 空 - 弹出的 $\\{$ 匹配 $\\}$

所有弹出的括号都匹配所遇闭括号，最后栈为空——所以这是 ПСП。

而字符串 $\[ \\{ \] \\}$ 不是 ПСП：

  - 空
  - $\[$
  - $\[ \\{$
  - 错误，因为栈尾的 $\\{$ 不匹配 $\]$

这个算法运行在 $O(N)$——遍历数组，每次对栈执行 push 或 pop 之一。
