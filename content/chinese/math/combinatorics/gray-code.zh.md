定义
格雷码是这样一种对非负整数编号的系统：相邻两个数的编码恰好只有一个位不同。

例如，对于 3 位长的数，有下面这个格雷码序列：000, 001, 011, 010, 110, 111, 101, 100。例如，G(4)=6。

这种编码由弗兰克·格雷（Frank Gray）于 1953 年发明。

求格雷码
考察数 n 的各个位和数 G(n) 的各个位。注意，G(n) 的第 i 位等于 1，当且仅当 n 的第 i 位是 1 且第 i+1 位是 0，或者反过来（第 i 位是 0 且第 i+1 位是 1）。于是有：G(n) = n \oplus (n>>1)：

int g (int n) {
	return n ^ (n >> 1);
}
求格雷码的逆
需要根据格雷码 g 还原出原数 n。

我们从高位向低位进行（设最低位编号为 1，最高位为 k）。得到数 n 的各个位 n_i 与数 g 的各个位 g_i 之间的如下关系：

 n_k = g_k, 
 n_{k-1} = g_{k-1} \oplus n_k = g_k \oplus g_{k-1}[...]
 n_{k-2} = g_{k-2} \oplus n_{k-1} = g_k \oplus g_{[...]
 n_{k-3} = g_{k-3} \oplus n_{k-2} = g_k \oplus g_{[...]
 \ldots 

用程序代码来写的话，最简单的方式如下：

int rev_g (int g) {
	int n = 0;
	for (; g; g>>=1)
		n ^= g;
	return n;
}
应用
格雷码在多个领域有一些应用，有时相当出人意料：

n 位格雷码对应 n 维立方体上的哈密顿回路。
在工程中，格雷码用于在模拟信号转换为数字信号时最小化误差（例如在传感器中）。事实上，格雷码正是因这个应用而被发明的。
格雷码用于解汉诺塔问题。
设 n 为圆盘数。从长度为 n、全为 0 的格雷码（即 G(0)）开始，沿格雷码序列移动（从 G(i) 走到 G(i+1)）。把当前格雷码的第 i 位与第 i 个圆盘对应（最低位对应最小的圆盘，最高位对应最大的圆盘）。由于每一步只有一个位发生变化，我们可以把第 i 位的改变理解为第 i 个圆盘的移动。注意，除最小的圆盘外，其他所有圆盘每一步都恰好只有一种走法（起点和终点位置除外）。最小的圆盘总是有两种走法，但存在一种总能得到答案的选法策略：如果 n 为奇数，则最小圆盘的移动序列形如 f \rightarrow t \rightarrow r \rightarrow f \rightarrow t \rightarrow r \rightarrow \ldots（其中 f 是起始柱，t 是目标柱，r 是剩下的柱）；如果 n 为偶数，则为 f \rightarrow r \rightarrow t \rightarrow f \rightarrow r \rightarrow t \rightarrow \ldots。

格雷码在遗传算法理论中也有应用。
