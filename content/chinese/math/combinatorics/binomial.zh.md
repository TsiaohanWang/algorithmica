二项式系数 C_n^k 表示从 n 个不同的物品中选出 k 个物品、不考虑排列顺序的方法数（即无序集合的数量）。

二项式系数也是 $(a+b)^n$（即牛顿二项式）展开式中的系数：

 (a+b)^n = C_n^0 a^n + C_n^1 a^{n-1} b + C_n^2 a^{[...]

人们认为，这个公式以及能够高效求出系数的三角形是由 17 世纪的布莱兹·帕斯卡（Blaise Pascal）发现的。不过，13 世纪的中国数学家杨辉（Yang Hui）就已经知道这个公式了。也许它是由波斯学者奥马尔·海亚姆（Omar Khayyam）发现的。此外，公元前 3 世纪的印度数学家平加拉（Pingala）还得到过相近的结果。而牛顿的功绩在于，他把这个公式推广到了非自然数的幂次。

计算
计算的解析公式：

 C_n^k = \frac{n!}{k! (n-k)!} 

这个公式很容易从无序样本问题中推出（从 n 个元素中无序地选出 k 个元素的方法数）。先计算有序样本的数量。选择第一个元素有 n 种方法，第二个有 n-1 种，第三个有 n-2 种，依此类推。于是有序样本的数量为： n (n-1) (n-2) \ldots (n-k+1) = \frac{n!}{(n-k)!} 。再转到无序样本就很容易了：只要注意到每个无序样本恰好对应 k! 个有序样本（因为 k 个元素共有这么多种排列方式）。于是，把 \frac{n!}{(n-k)!} 除以 k!，就得到所求公式。

递推公式（与著名的“帕斯卡三角形”有关）：

 C_n^k = C_{n-1}^{k-1} + C_{n-1}^k 

用前面的公式很容易推出它。

特别需要注意的是，当 n<k 时，C_n^k 的值一律视为零。

性质
二项式系数具有许多不同的性质，我们列出其中最简单的：

对称性质：
 C_n^k = C_n^{n-k} 

提出-代入（吸收）：
 C_n^k = \frac{n}{k} C_{n-1}^{k-1} 

对 k 求和：
 \sum_{k=0}^n C_n^k = 2^n 

对 n 求和：
 \sum_{m=0}^n C_m^k = C_{n+1}^{k+1} 

对 n 和 k 求和：
 \sum_{k=0}^{m} C_{n+k}^k = C_{n+m+1}^m 

平方和：
 (C_n^0)^2 + (C_n^1)^2 + \ldots + (C_n^n)^2 = C_{2[...]

加权求和：
 1 C_n^1 + 2 C_n^2 + \ldots + n C_n^n = n 2^{n-1} 

与斐波那契数的联系：
 C_n^0 + C_{n-1}^1 + \ldots + C_{n-k}^k + \ldots +[...]

程序中的计算
按解析公式直接计算
按第一个直接公式计算非常容易编程，但这种方法即使 n 和 k 相对较小也很容易发生溢出（即使答案完全能放进某种数据类型，中间阶乘的计算也可能导致溢出）。因此这种方法往往只能配合[[高精度运算|高精度运算]]使用：

 
int C (int n, int k) {
	int res = 1;
	for (int i=n-k+1; i<=n; ++i)
		res *= i;
	for (int i=2; i<=k; ++i)
		res /= i;
}
改进的实现
可以注意到，在上面给出的实现中，分子和分母的因数个数相同（都是 k 个），且每个因数都不小于一。因此可以把分数改写成 k 个分数的乘积，其中每个分数取值都是实数。不过可以注意到，把当前答案依次乘以每一个分数后，得到的仍然是整数（例如，这可由“提出-代入”性质推出）。于是得到如下实现：

 
int C (int n, int k) {
	double res = 1;
	for (int i=1; i<=k; ++i)
		res = res * (n-k+i) / i;
	return (int) (res + 0.01);
}
这里我们小心地把分数转换成整数，考虑到由于累积的误差，它可能比真实值略小（例如是 2.99999 而不是三）。

帕斯卡三角形
利用递推关系可以构造出一张二项式系数表（实际上就是帕斯卡三角形），然后从表中取结果。这种方法的优点在于，中间结果永远不会超过答案，而且计算表中的每个新元素只需一次加法。缺点是当 N 和 K 很大时运行缓慢——如果实际上我们并不需要整张表，而只需要一个单独的值（因为要计算 C_n^k 就需要为所有 C_i^j,\ \ 1 \le i \le n,\ \ 1 \le j \le n 建表，或者至少要建到 1 \le j \le \min(i,2k)）。

 
const int maxn = ...;
int C[maxn+1][maxn+1];
for (int n=0; n<=maxn; ++n) {
	C[n][0] = C[n][n] = 1;
	for (int k=1; k<n; ++k)
		C[n][k] = C[n-1][k-1] + C[n-1][k];
}
如果不需要整张表，那么不难发现，只需保存其中的两行（当前行——第 n 行，以及前一行——第 n-1 行）。

常数时间 O(1) 内计算
最后，在某些情况下，预先计算好所有阶乘的值是有利的，这样之后计算任意所需的二项式系数只需做两次除法。在使用高精度运算、内存不允许预先计算整个帕斯卡三角形时，或者需要在某个素数模下计算时（如果模不是素数，那么把分数的分子除以分母会遇到麻烦；可以先把模分解质因数，把所有数以这些素数幂次组成的向量形式存储来克服这一困难；参见“因式分解形式的高精度运算”一节）。
