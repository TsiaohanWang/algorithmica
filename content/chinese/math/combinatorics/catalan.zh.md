卡特兰数——一种出现在数量惊人的组合问题中的数列。

这个数列以 19 世纪比利时数学家卡塔兰（Catalan）的名字命名，不过实际上它早已为欧拉（Euler）所知，欧拉比卡塔兰早一个世纪。

数列
前几个卡特兰数 C_n（从第零个开始）：

 1,\ 1,\ 2,\ 5,\ 14,\ 42,\ 132,\ 429,\ 1430,\ \ldo[...]

卡特兰数出现在大量组合问题中。第 n 个卡特兰数等于：

由 n 个左括号和 n 个右括号组成的合法括号序列的数量。
有 n+1 个叶子的有根二叉树的数量（顶点不编号）。
用括号完整划分 n+1 个因式的方法数。
凸 n+2 边形的三角剖分数（即用不相交的对角线把多边形剖分成三角形的方法数）。
用 n 条不相交的弦连接圆周上 2n 个点的方法数。
有 n 个内部顶点（即至少有一个儿子）的不同构满二叉树的数量。
在大小为 n \times n 的方形网格中从 (0,0) 到 (n,n)、不高于主对角线的单调路径数。
可以用栈排序的长度为 n 的排列数（可以证明，一个排列能被栈排序当且仅当不存在满足 i<j<k 且 a_k<a_i<a_j 的下标）。
把 n 个元素的集合划分为连续块的方法数。
用 n 个矩形覆盖 1 \ldots n 阶梯的方法数（这里指由 n 列组成的图形，第 i 列的高度为 i）。
计算
卡特兰数有两个公式：递推公式和解析公式。由于我们认为上面列出的所有问题都是等价的，因此证明公式时，我们将选择最容易证明的那个问题。

递推公式
 C_n = \sum_{k=0}^{n-1} C_k C_{n-1-k} 

递推公式很容易从合法括号序列问题推出。

最左边的左括号 l 对应着某个确定的右括号 r，它把序列分成两部分，每一部分本身又都是合法括号序列。因此，如果记 k = r-l-1，那么对任意固定的 r 恰好有 C_k C_{n-1-k} 种方案。对所有合法的 k 求和，就得到 C_n 的递推关系。

解析公式
 C_n = \frac{1}{n+1} C_{2n}^{n} 

（这里 C_n^k 一如既往地表示二项式系数）。

这个公式最容易从单调路径问题推出。网格大小为 n \times n 的单调路径总数为 C_{2n}^{n}。现在来计算穿过对角线的单调路径数。任取这样的一条路径，找出第一个位于对角线上方的边。把这条边之后的整段路径关于对角线反射。结果得到网格 (n-1) \times (n+1) 中的一条单调路径。但另一方面，网格 (n-1) \times (n+1) 中的任意单调路径必然穿过对角线，因此它正是以这种方式由网格 n \times n 中某条（且唯一）穿过对角线的单调路径得到的。网格 (n-1) \times (n+1) 中的单调路径共有 C_{2n}^{n-1} 条。最终得到公式：
