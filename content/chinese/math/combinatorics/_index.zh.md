### 约瑟夫问题

约瑟夫斯（拉丁语 *Flavius Josephus*）——公元一世纪的著名历史学家。传说，如果不是他的数学才能，他根本活不到出名的那一天。

在犹太-罗马战争期间，他是被罗马人困在山洞中的 41 名犹太叛军之一。叛军宁愿自杀也不愿被俘，于是决定围成一圈，并沿着圆圈依次处决每第三个人，直到剩下一人为止。但约瑟夫斯和他的一位同谋可不想参与这种自杀式的胡闹；于是他迅速算出了他和朋友应该站在这残酷的圆圈中的什么位置。

**抽屉原理**。如果把兔子放进笼子，且兔子的数目多于笼子的数目，那么至少有一个笼子里装着不止一只兔子。

在英语世界它被称为 *Pigeonhole principle*（鸽笼原理），说的是鸽子，但本质不变。

![](https://miro.medium.com/max/1178/1*rj_4nlE4Qw_ok0P7A7chHA.png)

这个原理看似显然，但它的应用却不总是那么显然。来看几个例子。

**问题**。给定一个 $2 \times 2$ 的正方形和它内部的 $5$ 个点。证明其中必能找到两个点，它们之间的距离 $\leq \sqrt 2$。

**题解**。考虑 $4$ 个 $1 \times 1$ 的小方格。根据抽屉原理，必有一个小方格，其内部或边界上有 2 个点。这两个点即为所求。

再难一点的例子：

* 你想用多米诺骨牌铺满棋盘。如果去掉两个对角上的角格，这就变得不可能。

* 在六个人中，总能找到三个人，他们要么两两互为朋友，要么两两互不相识。

* 现实世界的例子：任何无损压缩算法都无法保证对所有可能的输入文件都能实现压缩。

关于宝可梦的问题。

## 组合

从给定集合中取 $k$ 个元素组成的有序集合（其中元素可能重复），称为从 $n$ 个元素中取 $k$ 个的*可重复排列*（размещение с повторением）。

相应地，如果元素可以重复，则该集合称为无重复的排列，或简称为排列。

从 $n$ 个元素中取 $k$ 个的组合（сочетание），是指该集合中由 $k$ 个元素组成的集合，其中仅顺序不同的集合被视为相同（这正是组合与排列的区别）。

类似地，组合也分为有重复和无重复两种。



读作「从 $n$ 个中取 $k$ 个的 C」。

### 怎么算

```cpp
int t[maxn];

int bp (int a, int n) {
    int ans = 1;
    while (n) {
        if (n&1) ans = ans*a % mod;
        a = a*a % mod;
        n >>= 1;
    }
    return ans;
}

int inv (int x) {
    return bp(x, mod-2);
}

int c (int n, int k) {
    return t[n]*inv(t[k]) % mod * inv(t[n-k]) % mod;
}

t[0] = 1;
for (int i = 1; i < maxn; i++)
    t[i] = i*t[i-1] % mod;
```

## 已知恒等式

$$
\sum_k \binom{r}{m+k}\binom{s}{n-k} = \binom{r+s}{m+n}
$$

$$
\sum_k \binom{l}{m+k} \binom{s}{n+k} = \binom{l+s}{l-m+n}
$$

$$
\sum_k \binom{l}{m+k}\binom{s+k}{n} (-1)^k = (-1)^{l+m} \binom{s-m}{n-l}
$$

$$
\sum_{k \leq l} \binom{l-k}{m}\binom{s}{k-n} (-1)^k = (-1)^{l+m} \binom{s-m-l}{l-m-n}
$$

$$
\sum_{0 \leq k \leq l} \binom{l-k}{m}\binom{q+k}{n} = \binom{l+q+1}{m+n+1}
$$

## 卡特兰数

卡特兰数（числа Каталана）——一种出现在数量惊人的组合问题中的数列。例如，第 $n$ 个卡特兰数等于：

* 由 $n$ 个左括号和 $n$ 个右括号组成的合法括号序列的数量。

* 有 $n+1$ 个叶子的有根二叉树的数量（顶点不编号）。

* 用不相交的对角线把凸 $(n+2)$ 边形剖分成三角形的方法数（这称为三角剖分）。

* 用 $n$ 条不相交的弦连接圆周上 $2n$ 个点的方法数。

* 把 $n$ 个元素组成的序列划分成连续块的方法数。

* 在大小为 $n \times n$ 的方形网格中，从点 $(0,0)$ 到点 $(n,n)$、不高出主对角线的路径数。

前几个卡特兰数（从第零个开始）：

$$
1, 1, 2, 5, 14, 42, 132, 429, 1430, …
$$

卡特兰数可以用平方级（quadratic）动态规划来计算。设第 $k$ 个卡特兰数 $C_k$ 等于长度为 $2k$（即 $k$ 对括号）的合法括号序列的数量。序列以左括号开头，这个左括号对应着某一个右括号。可以枚举它的位置（从零编号的所有奇数位置），对于每种情况，序列都被分成两个合法括号序列——位于该右括号之前（$k$ 对括号）和之后（$(n-1-k)$ 对）。于是得到如下递推公式：

$$
C_n = \sum_{k = 0}^{n-1} C_k C_{n-1-k}
$$

### 解析公式

但没必要，因为有一个我们马上要证明的解析公式：

$$
C_n = \dfrac{1}{n+1} \dbinom {2n} {n}
$$

这个公式最容易从单调路径问题导出——。网格大小为 n \times n 的单调路径总数为 C_{2n}^{n}。现在来计算穿过对角线的单调路径数。任取这样的一条路径，找出第一个位于对角线上方的边。把这条边之后的整段路径关于对角线反射。结果得到网格 (n-1) \times (n+1) 中的一条单调路径。但另一方面，网格 (n-1) \times (n+1) 中的任意单调路径必然穿过对角线，因此它正是以这种方式由网格 n \times n 中某条（且唯一）穿过对角线的单调路径得到的。网格 (n-1) \times (n+1) 中的单调路径共有 C_{2n}^{n-1} 条。最终得到公式：
