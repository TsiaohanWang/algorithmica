这个引理由伯恩赛德（Burnside）于 1897 年提出并证明，但后来证实，这个公式更早由弗罗贝尼乌斯（Frobenius）于 1887 年发现，而再往前，柯西（Cauchy）于 1845 年就已得到。因此这个公式有时被称为伯恩赛德引理，有时被称为柯西-弗罗贝尼乌斯定理。

伯恩赛德引理可以基于一个集合内部的某种对称性，计算该集合中等价类的数量。

对象与表示
我们要在对象的数量与表示的数量之间划清界限。

同一个对象可以对应不同的表示，但当然，任何一个表示都恰好对应一个对象。因此，所有表示组成的集合被划分成等价类。我们的任务正是计算对象的数量，也就是等价类的数量。

问题示例：二叉树染色
假设我们考虑如下问题：要求计算把有 n 个顶点的有根二叉树染成 2 种颜色的方法数，其中每个顶点的左右儿子不加区分。

这里的对象集合，就是在这种理解下互不相同的树的染色的集合。

现在定义表示的集合。给每种染色都对应一个表示它的函数 f(v)，其中 v = 1 \ldots n，而 f(v)=0 \ldots 1。那么表示的集合就是所有这种形式的函数，其大小显然等于 2^n。同时，我们在这个表示集合上引入了到等价类的划分。

例如，设 n=3，树长这样：根是顶点 1，顶点 2 和 3 是它的两个儿子。于是下面两个函数 f_1 和 f_2 被认为是等价的：

不变置换
为什么这两个函数 f_1 和 f_2 属于同一个等价类？直观上很清楚——因为我们可以交换顶点 1 的两个儿子的位置，即交换顶点 2 和 3，而经过这样的变换后函数 f_1 和 f_2 就重合了。但形式化地说，这意味着存在一个不变置换 \pi（即按题意不改变对象本身、只改变其表示的置换），使得：

 f_2 \pi \equiv f_1 

于是，根据题意，我们可以找出所有不变置换，即应用它们不会使我们从某个等价类跑到另一个等价类。那么，要检验两个函数 f_1 和 f_2 是否等价（即它们是否真的对应同一个对象），需要对每个不变置换 \pi 检验条件是否成立：f_2 \pi \equiv f_1（或等价地，f_1 \pi \equiv f_2）。只要发现对某个置换这个等式成立，f_1 和 f_2 就等价，否则它们不等价。

找出所有这些使我们的问题相对其保持不变的置换，是应用伯恩赛德引理和 Pólya（波利亚）定理的关键步骤。显然，这些不变置换取决于具体问题，找出它们是一个纯粹启发式的过程，基于直觉上的考虑。不过，在大多数情况下，手动找出几个“基本”置换就够了，其余所有置换都可以由它们通过各种各样的乘积得到（而这部分纯粹机械的工作可以交给计算机；下面会结合一个具体问题详细讨论）。

不难理解，不变置换构成一个群——因为任意不变置换的乘积仍然是不变置换。把不变置换群记作 G。

引理的表述
在表述引理之前，还需要提醒一个来自代数的概念。置换 \pi 的不动点 f，是指相对于该置换不变的这样一个元素：f \equiv f \pi。例如，在我们的例子中，不动点就是那些对应染色在施加置换 \pi 后不变（确切地说是在两个函数相等的形式意义上不变）的函数 f。用 I(\pi) 表示置换 \pi 的不动点个数。

那么伯恩赛德引理表述如下：等价类的数量等于群 G 中所有置换的不动点个数之和除以该群的大小：

 {\rm ClassesCount} = \frac{1}{|G|} \sum_{\pi \in [...]

虽然伯恩赛德引理本身在实践中用起来并不那么方便（还不清楚如何快速求 I(\pi) 的值），但它最清晰地揭示了计算等价类这一思想背后的数学本质。

伯恩赛德引理的证明
这里描述的伯恩赛德引理的证明，对于理解它并在实践中应用来说并不那么重要，因此初读时可以跳过。

这里给出的证明是已知证明中最简单的一个，不涉及群论。这个证明由博加特（Bogart）和肯尼思（Kenneth）于 1991 年发表。

我们要证明下面的结论：

 {\rm ClassesCount} |G| = \sum_{\pi \in G} I(\pi) 

右边这个量不是别的，正是“不变对”(f, \pi) 的数量，即满足 f \pi \equiv f 的对。显然，在公式中我们有权交换求和顺序——把外层求和改为对元素 f 求和，内层放入 J(f)——即使 f 不变的置换的数量：

 {\rm ClassesCount} |G| = \sum_{f} J(f) 

为了证明这个公式，我们构造一张表格，列用所有 f_i 标注，行用所有置换 \pi_j 标注，表格的单元格里放乘积 f_i \pi_j。那么如果把这些列看作集合，其中一些列可能相同，而这正意味着这些列对应的 f 也等价。因此，作为集合互不相同的列的数量，就等于所求的 \rm ClassesCount。顺便说一句，从群论的角度看，用某个元素 f_i 标注的列就是该元素的轨道；对于等价的元素，显然轨道相同，而不同轨道的数量正是 \rm ClassesCount。

于是表格的列自己也分成等价类；现在固定某个等价类，考察其中的列。首先注意到，这些列里只能出现同一等价类的 f_i（否则就意味着通过某个等价变换 \pi_j 我们跑到了另一个等价类，这是不可能的）。其次，每个元素 f_i 在所有列中出现的次数相同（这同样是由列对应等价元素推出的）。由此可以得出结论：同一等价类中的所有列作为多重集合彼此相同。

现在固定任意一个元素 f。一方面，它在自己的列中恰好出现 J(f) 次（根据 J(f) 的定义本身）。另一方面，同一等价类中的所有列作为多重集合相同。因此，在该等价类的每一列中，任意元素 g 恰好出现 J(g) 次。

于是，如果从每个等价类中各任取一列，并把其中元素个数相加，那么一方面得到 {\rm ClassesCount} |G|（这只需把列数乘以它们的尺寸即可得到），另一方面得到所有 f 的 J(f) 之和（这由上面的所有推理得出）：

 {\rm ClassesCount} |G| = \sum_{f} J(f) 

证毕。

Pólya 定理。最简单的形式
Pólya（波利亚）定理是伯恩赛德引理的推广，同时提供了计算等价类数量更方便的工具。需要指出的是，早在 Pólya 之前，雷德菲尔德（Redfield）已于 1927 年发现并证明了这一定理，但他的论文当时未被数学界注意到。Pólya 直到 1937 年才独立得到同样的结果，而他的论文更为成功。

这里我们考虑作为 Pólya 定理特例得到的公式，它非常适合实际计算使用。本文不讨论一般的 Pólya 定理。

用 C(\pi) 表示置换 \pi 中轮换（cycle）的个数。于是成立下面的公式（Pólya 定理的特例）：

 {\rm ClassesCount} = \frac{1}{|G|} \sum_{\pi \in [...]

其中 k 是表示 f(v) 的每个元素可能取值的个数。例如，在我们的示例问题（把有根二叉树染成 2 种颜色）中 k = 2。

证明
这个公式是伯恩赛德引理的直接推论。要得到它，只需为引理中出现的量 I(\pi) 找一个显式表达式（提醒一下，它是置换 \pi 的不动点个数）。

考虑某个置换 \pi 和某个元素 f。众所周知，在置换 \pi 的作用下，元素 f 沿着置换的轮换移动。注意，由于结果必须满足 f \equiv f \pi，置换的每个轮换内部必须是相同的元素 f。同时，不同轮换之间元素的取值没有任何关联。因此，对置换 \pi 的每个轮换各选一个值（在 k 个选项中选），就得到所有相对于该置换不变的表示 f，即：

 I(\pi) = k ^ {C(\pi)} 

其中 C(\pi) 是置换的轮换个数。

问题示例：项链
“项链”问题是经典组合问题之一。要求计算由 n 颗珠子组成的不同项链的数量，每颗珠子可以染成 k 种颜色之一。比较两条项链时可以把它们旋转，但不能翻转（即允许做循环移位）。

在这个问题中我们可以直接找出不变置换群。显然，它由 n 个置换组成：

 \pi_0 = 1\ 2\ 3\ \ldots\ n 
 \pi_1 = 2\ 3\ \ldots\ n\ 1 
 \pi_2 = 3\ \ldots\ n\ 1\ 2 
 \ldots 
 \pi_{n-1} = n\ 1\ 2\ \ldots\ (n-1) 

找出计算 C(\pi_i) 的显式公式。首先注意到，这些置换有这样的形式：第 i 个置换的第 j 个位置上是 i+j（如果大于 n 就取模 n）。考察第 i 个置换的轮换结构，可以看到 1 变成 1+i，1+i 变成 1+2i，1+2i 变成 1+3i，依此类推，直到回到某个数 1 + kn；其余元素也有类似的性质。由此可知，所有轮换的长度相同，等于 {\rm lcm}(i,n) / i，即 n / {\rm gcd}(i,n)（"gcd" 是最大公约数，"lcm" 是最小公倍数）。那么第 i 个置换的轮换个数就等于 {\rm gcd}(i,n)。

把求出的值代入 Pólya 定理，得到解：

 {\rm Ans} = \frac{1}{n} \sum_{i=1}^{n} k ^ {{\rm [...]

公式可以保留这种形式，也可以进一步压缩。从对所有 i 求和改成只对 n 的因数求和。确实，我们的和里会有很多相同的项：如果 i 不是 n 的因数，那么计算出 {\rm gcd}(i,n) 后就能找到对应的因数。因此，对于每个因数 d|n，它的项 k^{{\rm gcd}(d,n)} = k^d 会被计入多次，即和可以写成如下形式：

 {\rm Ans} = \frac{1}{n} \sum_{d|n} C_d k^d 

其中 C_d 是满足 {\rm gcd}(i,n) = d 的数 i 的个数。为这个数量找到显式表达式。任何一个这样的数 i 都有形式 i=dj，其中 {\rm gcd}(j,n/d) = 1（否则会有 {\rm gcd}(i,n) > d）。回忆欧拉函数，这样的 j 的个数就是欧拉函数的值 \phi(n/d)。于是 C_d = \phi(n/d)，最终得到公式：

伯恩赛德引理与程序计算的结合应用
并非总能纯粹通过解析途径为等价类数量得到显式公式。在许多问题中，群所含的置换数量可能太大，无法手工计算，也不可能解析地算出其中每个置换的轮换个数。

这种情况下，应该手动找出几个“基本”置换，让它们足以生成整个群 G。然后可以写一个程序，生成群 G 的所有置换，计算其中每个置换的轮换个数，并把它们代入公式。

以环面染色数量问题为例。有一张 n \times m 的矩形方格纸（n < m），其中一些格子被染成黑色。然后把这张纸沿两条长度为 m 的边粘起来，得到圆柱面。再把圆柱面沿两个圆（圆柱的底）粘起来（不扭转），得到环面。要求计算不同环面的数量（纸最初是任意染色的），粘合的线视为不可区分，且环面可以旋转和翻转。

在这个问题中，可以把纸片 n \times m（其中一些格子染成黑色）看作表示。不难理解，下面几种变换保持等价类不变：纸片行方向的循环移位、纸片列方向的循环移位、纸片旋转 180 度；凭直觉也能明白，这三种变换足以生成整个不变变换群。如果我们以某种方式给格子的位置编号，就可以写出与这三种变换对应的三个置换 p_1, p_2, p_3。剩下的就是生成这三个置换相乘得到的所有置换。显然，所有这样的置换都具有 p_1^{i_1} p_2^{i_2} p_3^{i_3} 的形式，其中 i_1 = 0 \ldots m-1，i_2 = 0 \ldots n-1，i_3 = 0 \ldots 1。

这样我们就可以写出这个问题的程序实现：

void mult (vector<int> & a, const vector<int> & b) {
	vector<int> aa (a);
	for (size_t i=0; i<a.size(); ++i)
		a[i] = aa[b[i]];
}
 
int cnt_cycles (vector<int> a) {
	int res = 0;
	for (size_t i=0; i<a.size(); ++i)
		if (a[i] != -1) {
			++res;
			for (size_t j=i; a[j]!=-1; ) {
				size_t nj = a[j];
				a[j] = -1;
				j = nj;
			}
		}
	return res;
}
 
int main() {
	int n, m;
	cin >> n >> m;
 
	vector<int> p (n*m),  p1 (n*m),  p2 (n*m),  p3 (n*m);
	for (int i=0; i<n*m; ++i) {
		p[i] = i;
		p1[i] = (i % n + 1) % n + i / n * n;
		p2[i] = (i / n + 1) % m * n + i % n;
		p3[i] = (m - 1 - i / n) * n + (n - 1 - i % n);
	}
 
	int sum = 0,  cnt = 0;
	set < vector<int> > s;
	for (int i1=0; i1<n; ++i1) {
		for (int i2=0; i2<m; ++i2) {
			for (int i3=0; i3<2; ++i3) {
				if (!s.count(p)) {
					s.insert (p);
					++cnt;
					sum += 1 << cnt_cycles(p);
				}
				mult (p, p3);
			}
			mult (p, p2);
		}
		mult (p, p1);
	}
 
	cout << sum / cnt;
}
