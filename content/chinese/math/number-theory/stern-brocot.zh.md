Stern–Brocot 树是一种精巧的构造，借助它可以构造出全体非负分数的集合。它由德国数学家莫里茨·施特恩（Moritz Stern）于 1858 年与法国钟表匠阿希尔·布罗科（Achille Brocot）于 1861 年独立发现。不过据某些资料记载，这一构造其实早已被古希腊学者埃拉托斯特尼（Eratosthenes）发现。

在第零次迭代时，我们有两条分数：

 \frac{0}{1}, \frac{1}{0} 

（严格说来，第二个量并不是分数；可以把理解为表示无穷大的既约分数）
此后，在每一次后续迭代中，都取当前的分数列表，并在每两个相邻分数 \frac{a}{b} 与 \frac{c}{d} 之间插入它们的中位分数（медианта），即分数 \frac{a+c}{b+d}。

于是，第一次迭代后当前集合为：

 \frac{0}{1}, \frac{1}{1}, \frac{1}{0} 

第二次迭代后：

 \frac{0}{1}, \frac{1}{2}, \frac{1}{1}, \frac{2}{1[...]

第三次迭代后：

 \frac{0}{1}, \frac{1}{3}, \frac{1}{2}, \frac{2}{3[...]

把这个过程一直进行下去，据称可以得到全体非负分数的集合。而且，得到的所有分数都互不相同（即当前集合中每个分数至多出现一次）、不可约（分子分母将两两互质）。最后，所有分数会自动按升序排列。Stern–Brocot 树这一切奇妙性质的证明将在下文给出。

证明
有序性。证明非常简单：注意，两条分数的中位分数总位于它们之间，即：

 \frac{a}{b} \le \frac{a+c}{b+d} \le \frac{c}{d} 

条件为

 \frac{a}{b} \le \frac{c}{d} 

这只需把三个分数通分即可证明。
由于第零次迭代时有序性成立，因此它会在每次新迭代中保持。

不可约性。为此证明，在任意迭代中，对列表中任意两个相邻分数 \frac{a}{b} 与 \frac{c}{d} 都有：

 bc-ad=1 

事实上，回忆二元丢番图方程 (ax+by=c)，由此断言可得 {\rm gcd}(a,b) = {\rm gcd}(c,d) = 1，这正是我们所需要的。
因此，我们要证 bc-ad=1 在任意迭代中都成立。同样用归纳法证明。在第零次迭代它成立（容易验证）。现在设它在上一迭代成立，证明它在当前迭代成立。为此考察新列表中三个相邻的分数：

 \frac{a}{b}, \frac{a+c}{b+d}, \frac{c}{d} 

对它们条件成为：

 b(a+c) - a(b+d) = 1, 
 c(b+d) - d(a+c) = 1 

在 bc-ad=1 成立的前提下，这两个条件的正确性是显然的。于是该性质在当前迭代也成立，证毕。

包含所有分数。这一性质的证明与在 Stern–Brocot 树中查找分数的算法密切相关。由于 Stern–Brocot 树中的所有分数都已排序，可知树的任意顶点的左子树里是比它小的分数，右子树里是比它大的分数。由此得到一个显然的查找算法：初始时位于根；把我们的分数与当前顶点的分数比较：若更小则进入左子树，若更大则进入右子树，若相等则找到该分数，查找结束。

为证明无穷 Stern–Brocot 树包含所有分数，只需证明：对任意给定分数，上述查找算法都将在有限步内结束。可以这样理解该算法：我们有一个当前区间 \left[ \frac{a}{b}; \frac{c}{d} \right]，要在其中寻找分数 \frac{x}{y}。初始时 \frac{a}{b}=\frac{0}{1}, \frac{c}{d}=\frac{1}{0}。每一步都把 \frac{x}{y} 与区间两端的中位分数即 \frac{a+c}{b+d} 比较，据此要么结束查找，要么进入区间的左半部分或右半部分。若查找算法无限进行下去，则每次迭代都满足以下条件：

 \frac{a}{b} < \frac{x}{y} < \frac{c}{d} 

可以改写成：

 bx-ay \ge 1, 
 cy-dx \ge 1 

（这里用到了这些量是整数，因此由 >0 可得 \ge 1）
于是，第一个不等式乘以 c+d，第二个乘以 a+b，再相加，得：

 (c+d)(bx-ay) + (a+b)(cy-dx) \ge a+b+c+d 

展开左边括号并利用 bc-ad=1（见前一性质的证明），最终得到：

 x+y \ge a+b+c+d 

由于每次迭代中 a, b, c, d 至少有一个严格增大，因此查找 \frac{x}{y} 的过程至多包含 x+y 次迭代，证毕。

树的构造算法
要构造 Stern–Brocot 树的任意子树，只需知道其左祖先和右祖先。初始时，在第一层，左祖先为 \frac{0}{1}，右祖先为 \frac{1}{0}。据此可以算出当前顶点的分数，然后对左、右儿子递归（把自身作为右祖先传给左儿子，把自身作为左祖先传给右儿子）。

试图构造整棵无穷树的伪代码如下：

void build (int a = 0, int b = 1, int c = 1, int d = 0, int level = 1) {
	int x = a+c,  y = b+d;
	... 在树的 level 层输出当前分数 x/y
	build (a, b, x, y, level + 1);
	build (x, y, c, d, level + 1);
}
查找分数的算法
查找分数的算法在证明 Stern–Brocot 树包含所有分数时已经描述过，这里再重复一遍。这个算法实际上就是二分查找，或者说是二叉搜索树中查找给定值的算法。初始时站在树根。站在当前顶点时，把我们的分数与当前顶点的分数比较。若相等则停止——已找到分数。否则，若我们的分数更小则进入左儿子，反之进入右儿子。

正如在“Stern–Brocot 树包含所有非负分数”这一性质的证明中所证明的，查找 \frac{x}{y} 时算法至多执行 x+y 次迭代。

下面给出实现：它返回到达包含给定分数 \frac{x}{y} 的顶点的路径，以字符序列 'L'/'R' 的形式返回：若当前字符为 'L'，表示在树中进入左儿子，否则进入右儿子（初始时站在树根，即分数 \frac{1}{1} 所在顶点）。事实上，这种存在且唯一确定任意非负分数的字符序列，称为 Stern–Brocot 记数制。

string find (int x, int y, int a = 0, int b = 1, int c = 1, int d = 0) {
	int m = a+c,  n = b+d;
	if (x == m && y == n)
		return "";
	if (x * n < y * m)
		return 'L' + find (x, y, a, b, m, n);
	else
		return 'R' + find (x, y, m, n, c, d);
}
无理数在 Stern–Brocot 记数制中对应无穷字符序列；如果预先给定精度，则可以取这个无穷序列的某个前缀。在对无理分数进行这种无穷查找的过程中，算法每次都会找到一个简单分数（分母逐渐增大），它给出该无理数越来越好的逼近（这个应用在钟表技术中恰恰很重要，阿希尔·布罗科正是因此发现了这棵树）。

法里序列
n 阶法里序列（Farey）是指 0 与 1 之间所有分母不超过 n 的既约分数，且分数按升序排列。

该序列以英国地质学家约翰·法里（John Farey）命名，他在 1816 年试图证明法里序列中任意分数都是两个相邻分数的中位分数。据我们所知，他的证明有误，而正确的证明稍后由柯西（Cauchy）给出。不过早在 1802 年，数学家哈罗斯（Haros）就已在某篇著作中得出了几乎相同的结果。

法里序列本身也有很多有趣的性质，但它们与 Stern–Brocot 树的关系最为明显：实际上，法里序列就是从树中删去某些分支得到的。或者说，要得到法里序列，需要取出构造 Stern–Brocot 树时在无穷迭代中得到的分数集合，并只保留其中分母不超过 n、分子不超过分母的分数。

由 Stern–Brocot 树的构造算法还可得到法里序列的类似算法。第零次迭代时集合只含 \frac{0}{1} 和 \frac{1}{1}。在每次后续迭代中，在每两个相邻分数之间插入它们的中位分数，仅当其中位分数的分母不超过 n。迟早集合不再变化，即可停止——我们已找到所需的法里序列。

计算法里序列的长度。n 阶法里序列包含 n-1 阶法里序列的全部元素，以及所有分母恰好为 n 的既约分数，而这个数量众所周知等于 \phi(n)。于是 n 阶法里序列的长度 L_n 由下式给出：

 L_n = L_{n-1} + \phi(n) 

或者展开递归式：

 L_n = 1 + \sum_{k=1}^n \phi(k)
