在机器学习中，进行黑盒分类最流行的方法大概就是逻辑回归了。

比如说，我们想把 $28 \times 28$ 的黑白手写数字图片分类到 10 个类别（0..9）之一：

![一些加拿大学生在答题纸上写下的数字构成了 MNIST 数据集](../img/mnist.png)

从计算的角度看，它是这样工作的。如果处理的是 $n$ 维数据、需要分类到 $m$ 个类别之一，那么我们把输入向量乘以一个大小为 $n \times m$ 的参数矩阵，然后对输出的 $m$ 元素向量应用一个特殊的「softmax」函数：

$$
softmax(x)\_k = \frac{e^{x_k}}{\sum_i^m e_{x_i}}
$$

换句话说，这个函数的作用是对输入向量逐元素求指数，然后归一化，使元素之和为 1。由于输出有 $m$ 个正元素且和为 1，它可以被看作样本属于某个类别的概率分布。然后我们看概率最高（最大预测值）的那个并把它当作模型的答案。

我们在一个大型样本数据集上拟合我们的参数矩阵，使得答对的次数最多。关于如何拟合，我们不做深入介绍；但一旦拟合完成，就需要对它进行*推理*（inference）：喂给它新的数据并得到预测。

这差不多就是一个性能工程师需要知道的关于机器学习的全部了。眼下，我们只关心计算层面。

```c++
float w[10][28*28];
// 796 x 10
int predict(float a) {
    float s[10] = {0};

    for (int k = 0; k < 10; k++)
        for (int i = 0; i < 28*28; i++)
            s[k] += a[i] * w[k][i];

    // there is not problem with calculating exponent of small numbers,
    // but exponent of large numbers may overflow
    int mx = *std::max_element(s, s + 10);
    float sumexp = 0;
    for (int i = 0; i < 10; i++) {
        s[i] = exp(s[i] - mx);
        sumexp += s[i];
    }

    int argmax = 0;
    
    for (int i = 0; i < 10; i++) {
        s[i] /= sumexp;
        if (s[i] > s[argmax])
            argmax = i;
    }

    return argmax;
}
```

这倒不完全值得优化，因为毕竟只是约 1 万次运算，但我们的使用场景可能更大。例如，神经网络并没有本质区别：它们只是使用更长的变换链，而不仅仅是矩阵乘法接一个 softmax。

这也可以用在热点代码中。例如，计算机国际象棋程序使用类似的模型来评估一个局面的价值（胜率）。顺便说一句，这就是「1-3-3-5-9」启发式评估的做法：你可以在一大批棋局面（转换为子力数量差值）的数据集上训练一个逻辑回归，权重就会呈现那样的形态。其他游戏中的评分也类似。

我们能注意到的第一件事是，我们其实不需要实现 softmax，因为可以观察到：最大的 logit（softmax 之前的数就是这么叫的）在经过 softmax 之后仍然最大，所以我们只需要在矩阵乘法之后取 argmax。

没有哪个头脑正常的人会用 C++ 来训练机器学习模型。

### 量化

机器学习正是那种既不需要范围也不需要精度的场景。机器学习的全部意义在于学习对数据中的小扰动鲁棒的函数。输入数据本身就有噪声，那我们的计算为什么不带点噪声呢？况且，误差应该会相互抵消。我们还可以强制矩阵参数落在某个范围内。

使用更低的精度有两个好处：

1. 取数据的时间更短。
2. 我们可以使用能打包更多值的 SIMD 指令。

```c++
char w[10][28*28];

int predict(char a) {
    short max = 0, argmax = 0;

    for (int k = 0; k < 10; k++) {
        short s = 0;
        for (int i = 0; i < 28*28; i++)
            s += a[i] * w[k][i];
        if (s > max)
            s = 0, argmax = k;
    }

    return argmax;
}
```
