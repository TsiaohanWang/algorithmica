实际算法很少需要达到最大可能的精度。在现实世界的数据中，建模误差和测量误差通常比浮点数舍入等带来的误差大好几个数量级，而且我们往往很乐意选择一种用精度换速度的近似方法。

在本节中，我们将介绍这类近似数值算法中最重要的构件之一：*牛顿法（Newton's method）*。

## 牛顿法

牛顿法是一种简单却非常强大的算法，用于求实值函数的近似根，即下面这个一般方程的解：

$$
f(x) = 0
$$

对函数 $f$ 唯一的要求是：至少存在一个根，且 $f(x)$ 在搜索区间上连续、可导。还有一些[无趣的边界情况](https://en.wikipedia.org/wiki/Newton%27s_method#Failure_analysis)，但它们在实践中几乎从不会出现，所以我们就不严格地称这个函数是“好的”。

算法的主要思想是：从某个初始近似值 $x_0$ 出发，然后在 $x = x_i$ 处作函数图像的切线，并把下一个近似值 $x_{i+1}$ 设为该切线与 $x$ 轴交点的 $x$ 坐标，如此迭代改进。其直觉是：如果函数 $f$ 是“[好的](https://en.wikipedia.org/wiki/Smoothness)”，且 $x_i$ 已经足够接近根，那么 $x_{i+1}$ 就会更接近。

![](../img/newton.png)

为了得到 $x_n$ 处的交点，我们需要令其切线函数等于零：

$$
0 = f(x_i) + (x_{i+1} - x_i) f'(x_i)
$$

由此我们推导出

$$
x_{i+1} = x_i - \frac{f(x_i)}{f'(x_i)}
$$

牛顿法非常重要：它是科学与工程中大量优化求解器的基础。

### 平方根

作为一个简单的例子，让我们推导求平方根问题的算法：

$$
x = \sqrt n \iff x^2 = n \iff f(x) = x^2 - n = 0
$$

如果把 $f(x) = x^2 - n$ 代入上面的一般公式，就可以得到下面的更新规则：

$$
x_{i+1} = x_i - \frac{x_i^2 - n}{2 x_i} = \frac{x_i + n / x_i}{2}
$$

在实践中，我们还希望在它足够接近正确答案时立即停止，这可以在每次迭代后简单检查：

```cpp
const double EPS = 1e-9;

double sqrt(double n) {
    double x = 1;
    while (abs(x * x - n) > eps)
        x = (x + n / x) / 2;
    return x;
}
```

该算法对许多函数都能收敛，不过它能可靠地、有证明地收敛的函数只是一部分（例如凸函数）。另一个问题是，如果收敛的话，收敛速度有多快。

仔细观察可以发现，每轮迭代后准确位数大约翻倍。这种惊人的收敛速度并非巧合。

为了定量分析收敛速度，我们需要考虑第 $i$ 轮迭代上的小相对误差 $\delta_i$，并确定下一轮迭代的误差 $\delta_{i+1}$ 会小多少：

$$
|\delta_i| = \frac{|x_n - x|}{x}
$$

我们可以把 $x_i$ 表示为 $x \cdot (1 + \delta_i)$。把它代入牛顿迭代公式，并在两边除以 $x$，得到

$$
1 + \delta_{i+1} = \frac{1}{2} (1 + \delta_i + \frac{1}{1 + \delta_i}) = \frac{1}{2} (1 + \delta_i + 1 - \delta_i + \delta_i^2 + o(\delta_i^2)) = 1 + \frac{\delta_i^2}{2} + o(\delta_i^2)
$$

这里我们在 $0$ 处对 $(1 + \delta_i)^{-1}$ 做了泰勒展开，使用了误差 $d_i$ 很小的假设（因为序列收敛，对足够大的 $n$ 有 $d_i \ll 1$）。

重新整理 $\delta_{i+1}$，我们得到

$$
\delta_{i+1} = \frac{\delta_i^2}{2} + o(\delta_i^2)
$$

这意味着一旦我们接近解，每轮迭代误差大约会平方（并减半）。由于对数 $(- \log_{10} \delta_i)$ 大致就是答案 $x_i$ 中准确有效数字的位数，对相对误差平方恰好对应着我们观察到的准确数字位数翻倍。

这被称为*二次收敛（quadratic convergence）*，事实上这并不限于求平方根。详细的证明留给读者作为练习，可以证明一般来说

$$
|\delta_{i+1}| = \frac{|f''(x_i)|}{2 \cdot |f'(x_n)|} \cdot \delta_i^2
$$

在一些额外假设下，这会带来至少二次的收敛，即 $f'(x)$ 不等于 $0$ 且 $f''(x)$ 连续。
