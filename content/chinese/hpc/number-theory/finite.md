还有其他的数学对象，其行为方式与模质数取余相同。根据这些对象集合保留的性质，它们被称为*群*（group）*、环*（ring）和*域*（field）。

### 置换

我们可以把置换的乘积定义为一个置换作用在另一个置换上。

这个运算是结合的，所以我们可以用快速幂在 $O(n \log n)$ 时间内计算 $n$ 次幂。

![](../img/permutation.png)

一般来说，这被称为*置换群*，而*群*是具有某种定义在其上的运算的元素集合。

### 单位根

复数是指形如 $a + bi$ 的数，其中 $a$ 和 $b$ 是实数，$i$ 被称为虚数单位：它是满足 $i^2 = -1$ 的数。

复数在代数中用于处理负数的根，因为在某种意义上 $i$ 等于 $\sqrt{-1}$。与负数类似，它们在现实世界中并不真正存在，而只存在于数学家的头脑中。

从几何角度思考复数最为方便。

*模*（modulus）是复数对应的实数 $r = \sqrt{a^2 + b^2}$。几何上，这就是向量 $(a, b)$ 的长度。

*辐角*（argument）是复数对应的实数 $\phi \in (-\pi, \pi]$，满足 $\tan \phi = \frac{b}{a}$。几何上，这是向量 $(a, 0)$ 与 $(a, b)$ 之间的夹角。

这样我们就可以用极坐标表示复数：

$$
a + bi = r \cdot ( \cos \phi + i \sin \phi )
$$

![](../img/complex-plane.png)

这种表示之所以有用，是因为如果要相乘两个复数，用高中三角函数知识可以证明，我们不需要做二项式展开，只需把它们的模相乘、辐角相加：

$$
\begin{aligned}
(a + bi) \cdot (c + di)
   &= r_1 \cdot ( \cos \phi_1 + i \sin \phi_1 ) \cdot r_2 \cdot ( \cos \phi_2 + i \sin \phi_2 )
\\ &= r_1 \cdot r_2 \cdot (\cos \phi_1 \cos \phi_2 - \sin \phi_1 \sin \phi_2 + i \cos \phi_1 \sin \phi_2 + i \cos \phi_2 \sin \phi_1 )
\\ &= r_1 \cdot r_2 \cdot (\cos (\phi_1 + \phi_2) + i \sin (\phi_1 + \phi_2) )
\end{aligned}
$$

现在，让我们把欧拉数 $e$ **定义**为满足

$$
e^{i\phi} = \cos \phi + i \sin \phi
$$

的数，也就是说，我们只是为 $(\cos \phi + i \sin \phi)$ 引入这种记号，而不去深究把一个数提升到复数指数到底意味着什么。几何上，所有这些点都位于单位圆上。

这种记法很有用，因为我们可以把 $e^{i\phi}$ 当作普通的指数来对待。如果我们要相乘单位圆上辐角分别为 $a$ 和 $b$ 的两个复数，只需写成

$$
(\cos a + i \sin a) \cdot (\cos b + i \sin b) = e^{i (a+b)}
$$

你可能会问，这一切与有限环有什么关系？关键在于，当我们相乘单位圆上的复数时，它们会像整数剩余那样绕回。它们仍然有无穷多个，所以相似性并不明显，但请考虑这一点：1 的 $n$ 次*根*有多少个？这些点就是自乘 $n$ 次后到达 1 的点。

事实证明恰好有 $n$ 个，而且它们等间距分布。具体来说，它们是如下形式的数

$$
w_k = e^{i \tau \frac{k}{n}}
$$

其中 $\tau$ 表示 $2 \pi$（一种[现代记号](https://tauday.com/tau-manifesto)）。

![](../img/roots.png)

第一个根 $w_1$（更准确地说，是第二个根，因为 $1$ 也是根）被称为本原单位根（generating root）。对它依次取 1 次、2 次……幂，将生成一个根序列，该序列在 $n$ 次迭代后循环。

$$
w_n = e^{i \tau \frac{n}{n}} = e^{i \tau} = e^{i \cdot 0} = w_0 = 1
$$

所有不在单位圆上的点，其模要么太大要么太小；所有辐角不能被 $w_1$ 整除的点，其辐角也偏离得太远。

这样的结构被称为*环*，或者更准确地说*，有限环*。

### 伽罗瓦域

剩余是*有限环*。模质数取余之所以不同，在于其乘法上总是存在逆运算，这时它被称为*有限域*。但质数并不是能容纳有限域的唯一集合大小。

质数有限域的问题在于，当面对以 2 的幂为单位的数据时，它们对计算机而言是浪费的。

事实证明，你也可以为任意质数 $p$ 构造大小为 $p^k$ 的域。这对计算机特别有用，因为你可以取 $p=2$、$k=8$，这样一个字节正好能容纳该集合的成员。

对于非质数域，你要抛开整数这一概念，改把信息编码为一种特殊类型的多项式。首先，选取一个*不可约多项式*。例如，对于 GF(8)，$p(x) = x3 + x + 1$ 就是这样一个多项式：它无法分解成乘积。

你通过多项式的系数来定义集合的成员。由于每个系数非 0 即 1，正好有 256 个成员。

你把加法定义为各元素的异或，把乘法定义为多项式相乘后再按那个不可约多项式取约减（可以仿照 GCD 的方式完成）。

异或在计算上没问题，但与其做这种奇怪的乘法，我们不如利用成员数量不多这一事实，直接预计算一张 256 个单字节条目的查找表。

这听起来很复杂，但这一切都是为了高效的实现：

```c++
char log[256], ilog[256];

char add(char x, char y) {
    return x ^ y;
}

char sub(char x, char y) {
    return x ^ y;
}

char mul(char x, char y) {
    return ilog[log[x] + log[y]];
}

char div(char x, char y) {
    return ilog[log[x] - log[y]];
}
```

这个域正是许多密码学和数据压缩技术的基础。事实上，当你加载这个页面时，你的计算机已经把一切通信内容变换成了这种形式。
