**小技巧**：在你没学完所有确定性字符串算法之前，先学会用哈希。

假设字符串是 1 到 $m$（字母表大小）的数序列。在 C/C++ 里 `char` 类型其实也是数（8 位），所以可以从字符中减去最小码并转成数：

```cpp
int x = (int) (c - 'a' + 1);
```

定义字符串的*正向多项式哈希*为下面这个多项式的值：

$$
h_f = (s_0 + s_1 k + s_2 k^2 + \ldots + s_n k^n) \bmod p
$$

其中 $k$ 是大于字母表大小的任意数，$p$ 是足够大的模数（一般不必是质数）。

可以线性计算它，维护一个等于 $k$ 所需次幂的变量：

```c++
const int k = 31, mod = 1e9+7;

string s = "abacabadaba";
long long h = 0, m = 1;

for (char c : s) {
    int x = (int) (c - 'a' + 1);
    h = (h + m * x) % mod;
    m = (m * k) % mod;
}
```

还可以定义*反向多项式哈希*：

$$
h_b = (s_0 k^n + s_1 k^{n-1} + \ldots + s_n) \mod p
$$

它的优点在于可以少写一行代码：

```c++
long long h = 0;
for (char c : s) {
    int x = (int) (c - 'a' + 1);
    h = (h * k + x) % mod;
}
```

作者觉得普通多项式更好想，所以处处使用正向多项式哈希，并简记为字母 $h$。

## 这有什么用？

利用哈希是多项式值这一事实，可以快速重算很多字符串操作结果的哈希。

例如，要算字符串 $a$ 和 $b$ 拼接（$b$ 接到 $a$ 末尾）的哈希，只需把 $b$ 的哈希乘以 $k^{|a|}$ 再加到 $a$ 的哈希上：

$$
h(ab) = h(a) + k^{|a|} \cdot h(b)
$$

删除字符串前缀可以这样：

$$
h(b) = \frac{h(ab) - h(a)}{k^{|a|}}
$$

删除后缀更简单：

$$
h(a) = h(ab) - k^{|a|} \cdot h(b)
$$

题目中我们常需要把 $k$ 乘以某次幂，所以值得把所需的幂预计算好存进数组：

```c++
const int maxn = 1e5+5;

int p[maxn];
p[0] = 1;

for (int i = 1; i < maxn; i++)
    p[i] = (1ll * p[i-1] * k) % mod; // 小心溢出
```

这在真实题目中怎么用？设我们需要回答一个大字符串的任意子串是否相等的查询。为每个前缀算哈希值：

```c++
int h[maxn];
h[0] = 0; // h[k] -- 长度为 k 的前缀的哈希

// 假设 s 已经是 int 序列

for (int i = 0; i < n; i++) 
    h[i+1] = (h[i] + p[i] * s[i]) % mod;
```

现在用这些前缀哈希可以定义一个算任意子段哈希的函数：

$$
h(s[l:r]) = \frac{h_r-h_l}{k^l}
$$

[模除法](/cs/modular/reciprocal)只在某些 `k` 和 `mod`（具体说互素时）下能做。无论怎样，写它很麻烦，我们不想写。

对我们的题目，关键是函数对相同子串返回相同多项式，而不是非得是多项式哈希。与其归到零次幂，不如把多项式归到某个足够大的次幂——例如 $n$ 次。

$$
\hat{h}(s[l:r]) = k^{n-l} (h_r-h_l)
$$

这样更简单——现在只需乘而不是除：

```c++
int hash_substring(int l, int r) {
    return (h[r+1] - h[l]) * p[n-l] % mod;
}
```

现在只需对两个区间调用这个函数，比较数值，就能在 $O(1)$ 内回答查询。

**练习**。 用*反向*多项式哈希写同样的东西——这个方法也成立，有些地方甚至更简单。反向子串哈希通常按定义中的标准形式计算和使用，因为那里不需要除法。

**小技巧**。 如果对短字符串、小字母表、取 $k=10$ 的反向多项式哈希，那么字符串的哈希数值会直观地与字符串对应：

$$
h(abacaba)=1213121
$$

调试时用起来很方便。

## 例题

**不同子串个数**。在 $O(n^2)$ 内算所有子串的哈希，全部加入 `std::set`。答案只需调用 `set.size()`。

**在字符串中找子串**。可以算模板（要找的字符串）的哈希，然后按模板大小在文本上滑动「窗口」，维护当前子串的哈希。如果某个子串哈希与模板哈希相同，就找到了。这叫 Rabin–Karp 算法。

**比较子串**大小而不仅是相等。任意两个字符串有某个公共前缀（可能为空）。对它的长度做二分查找，然后取两个子串中紧随其后的字符比较。运行在 $O(\log n)$。

**子串是否为回文**。可以算两个数组——反向哈希和正向哈希。回文检查就是比较第一个数组与第二个数组上 `hash_substring()` 的值。

**回文个数**。可以枚举回文中心，对每个中心用二分查找它的半径。检查子串是否为回文我们已经会。和往常一样，偶数与奇数回文要分开处理。运行在 $O(n \log n)$，尽管这[可以线性解决](/cs/string-searching/manacher)。
