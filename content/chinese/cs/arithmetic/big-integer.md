## 快速除法

有两个互相递归调用的函数。$n$ 总是不多于 2 的幂，$|a|$ 表示数 a 的长度。

1.  div21——把长度不超过 $2n$ 的数 $a$ 除以长度不超过 $n$ 的数 $b$，要求商的长度不超过 $n$。
2.  div32——把长度不超过 $3n$ 的数 $a$ 除以长度不超过 $2n$ 的数 $b$，要求商的长度不超过 $n$。

两函数都应返回商和余数。

### div21

div21 如何工作：设 $m=\\frac{n}{2}$。则 $a$ 长度不超过 $4m$，$b$ 长度不超过 $2m$，商长度不超过 $2m$。取 $a$ 前 $|a| - m \\le 3m$ 位，用 div32 除以 $b$。商长度不超过 $m$，否则 $a/b$ 会超过 $2m$ 长。再取这次除法余数，乘 $10^m$，接上 $a$ 最后 $m$ 位。再除以 $b$。因 $|b| \\le 2m$，余数长度不超过 $2m$，故乘 $10^m$ 的余数长度不超过 $m$，可用 div32 除。最后把第一次除法结果乘 $m$ 加第二次除法结果。得到答案。

### div32

div32 如何工作：若 $|b| \\le n$，则因商长度不超过 $n$、$|a| \\le 2n$，用 $div21$。否则取 $b$ 前 $n$ 位构成 $b_1$，取 $a$ 前 $|a| - (|b| - n)$ 位构成 $a_1$（即从 $a$、$b$ 末尾裁掉相同位数使 $b$ 长变为 $n$）。记 $k = |b| - n$（从 $a$、$b$ 末尾裁掉的位数）。记 $r_a = a - a_1 \\cdot 10^k$、$r_b = b - b_1 \\cdot 10^k$。则 $a / b = (a_1 \\cdot 10^k + r_a) / (b_1 \\cdot 10^k + r_b)$。

由此断言立即推出下个断言。

则 $a_1 / b_1 \\ge a / b \\ge a_1 / (b_1 + 1)$。取 $q = a_1 / b_1$，尝试由此得到 $a / b$。不难发现其实 $q \\ge a / b \\ge q - 10$。为此要证：

则 $a_1 / b_1 \\ge a / b \\ge a_1 / b_1 - 10$。于是 div32 的算法如下。构造 $a_1$ 与 $b_1$。用 div21 除 $a_1 / b_1$。（若 $a_1 \> b_1 \\cdot 10^n$，认为结果 $10^n - 1$。）再从 $a$ 减商乘 $b$，算当前除法余数。只要余数小于零，就加 $b$ 并把商减 1。这样做不超过 $n$ 次。

对非常小的数要改用 int 除法。

可把基数从 10 增到 $10^9$，但要小心。

复杂度易证。$div21(n)$ 做 $O(n)$ 操作并调 div32 两次。$div32(n)$ 做 $O(n \\log n)$ 操作（因有乘法）且可能调 $div21(n)$。于是 $div21(n)$ 做 $O(n \\log n)$ 操作并调 div21 两次。因此运行时间 $O(n \\log^2 n)$。

更详细的描述与证明见[此链接](http://cr.yp.to/bib/1998/burnikel.ps)。

## 快速任意次根

### 牛顿法

先看 $O(n\\log^3n)$ 但常数巨大的 $k$ 次根算法。用牛顿法找函数 $f(x)$ 的零点。它迭代工作——有初始数 $x_0$，之后 $x_{n+1}=x_n-\\frac{f(x_n)}{f'(x_n)}$。每次迭代把 $x_n$ 逼近函数零点。

取 $f(x)=a-x^k$，则使函数为正的最大整数 $x$ 就是 $a$ 的 $k$ 次根。则 $f'(x) = -k\\cdot x^{k - 1}$。于是 $$x_{n + 1} = x_n + \\frac{a}{k \\cdot x_n^{k - 1}} - \\frac{x_n}{k}$$ 若取 $x_0 = 10^{n/k}$，则迭代次数 $O(\\log n)$（常数大），每次有除法，故复杂度 $O(nlog^3n)$。

### 更快的算法

那是处处使用的常见开根算法，不是最快的。下面描述另一算法，$O(nlog^2n+klog^3k)$ 且常数小。递归地求 $x$ 的 $k$ 次根。但先来点数学。若不想懂这些，只想直接算法，见下方。

设 $\\sqrt\[k\]{x} = a10^m+b$，其中 $b \< 10^m$。则

$$x=a^k10^{km}+ka^{k-1}b10^{(k-1)m}+\\frac{k(k-1)}{2}a^{k-2}b^2
10^{(k-2)m}+...+b^k$$

若 $a \> b$ 且 $10^m \> k$，则

$$\\frac{k(k-1)}{2}a^{k-2}b^{2}10^{(k-2)m} \> \\frac{k(k-1)(k-2)}{1\\cdot2\\cdot3}a^{k-3}b^{3}10^{(k-3)m} \> ... \> b^k$$

于是

$$k\\left(\\frac{k(k-1)}{2}a^{k-2}b^{2}10^{(k-2)m} \\right)\>
\\frac{k(k-1)}{2}a^{k-2}b^{2}10^{(k-2)m} +
\\frac{k(k-1)(k-2)}{1\\cdot2\\cdot3}a^{k-3}b^{3}10^{(k-3)m} + ... +
b^k$$

若 $b\<10^m \<a$ 且 $10^m\>k^2$，则

$$a^{k-1}\\cdot10^{(k-1)m}\>
k\\left(\\frac{k(k-1)}{2}a^{k-2}b^{2}10^{(k-2)m} \\right)\>
\\frac{k(k-1)}{2}a^{k-2}b^{2}10^{(k-2)m} +
\\frac{k(k-1)(k-2)}{1\\cdot2\\cdot3}a^{k-3}b^{3}10^{(k-3)m} + ... +
b^k$$

由此得不太可怕的算法。

设 $n$ 是要求根的数 $x$ 的长度。设 $m=\\frac{n-1}{2k}$。若 $10^m\\leq k^2$，用牛顿法开根。否则取 $x$ 去掉最后 $km$ 位的数。设 $a$ 是这个数的根。注意 $\\sqrt\[k\]{x}$ 形如 $a10^m+b$，$b \< 10^m$。且 $b\<10^m \<a$、$10^m\>k^2$。于是上面大不等式成立。则 $b=(x-a^k10^{km})/(a^{k-1}10^{(k-1)m})$ 或小一。做这次除法并检查是否需要从 $b$ 减 1，就得到 $\\sqrt\[k\]{x}$。注意我们做的最大渐近操作是除法，之后对长度减半的数递归。因最后还要对长度约 $k$ 的数用牛顿法开根，总复杂度 $O(nlog^2n+klog^3k)$。

高精度运算是一组软件工具（数据结构与算法），允许处理比标准数据类型大得多的数。

整数高精度运算的种类
其实哪怕只算竞赛题，工具集也相当大，因此对各类高精度算术分类。

经典高精度运算
核心思想是把数存成数字数组。

可用不同进制表示数字，通常用十进制及其幂（一万、十亿），或二进制。

这种高精度下的运算用「学校」算法（竖式加减乘除）。不过也可用快速乘法算法：快速傅里叶变换和 Karatsuba 算法。

这里只处理非负高精度数。要支持负数，需引入并维护数的「负性」标志，或用补码。

数据结构
把高精度数存成 int 向量，每个元素是一位数字。

typedef vector<int> lnum;
为提效，用十亿进制，即 lnum 向量每个元素存 9 位而不是 1 位：

const int base = 1000*1000*1000;
数字在向量中的顺序是最低有效位在前（即个位、十位、百位……）。

此外所有操作都保证操作后没有前导零（即数开头的多余零）（当然，假设每操作前也无前导零）。注意，实现中对数零正确支持两种表示：空数字向量，和含单个元素零的向量。

输出
最简单的输出高精度数。

先输出向量最后一个元素（向量空则 0），再输出其余元素，各补零到 9 位：

printf ("%d", a.empty() ? 0 : a.back());
for (int i=(int)a.size()-2; i>=0; --i)
	printf ("%09d", a[i]);
（这里有个细节：别忘了写 (int) 强转，否则 a.size() 是无符号的，若 a.size() \le 1，相减会溢出）

读入
把字符串读进 string，再转成向量：

for (int i=(int)s.length(); i>0; i-=9)
	if (i < 9)
		a.push_back (atoi (s.substr (0, i).c_str()));
	else
		a.push_back (atoi (s.substr (i-9, 9).c_str()));
若用 char 数组代替 string，代码更紧凑：

for (int i=(int)strlen(s); i>0; i-=9) {
	s[i] = 0;
	a.push_back (atoi (i>=9 ? s+i-9 : s));
}
若输入数可能已有前导零，读入后可这样删：

while (a.size() > 1 && a.back() == 0)
	a.pop_back();
加法
把数 b 加到数 a，结果存 a：

int carry = 0;
for (size_t i=0; i<max(a.size(),b.size()) || carry; ++i) {
	if (i == a.size())
		a.push_back (0);
	a[i] += carry + (i < b.size() ? b[i] : 0);
	carry = a[i] >= base;
	if (carry)  a[i] -= base;
}
减法
从数 a 减数 b（a \ge b），结果存 a：

int carry = 0;
for (size_t i=0; i<b.size() || carry; ++i) {
	a[i] -= carry + (i < b.size() ? b[i] : 0);
	carry = a[i] < 0;
	if (carry)  a[i] += base;
}
while (a.size() > 1 && a.back() == 0)
	a.pop_back();
这里减法后删前导零，以维护无前导零的不变量。

高精度乘短
长 a 乘短 b（b < {\rm base}），结果存 a：

int carry = 0;
for (size_t i=0; i<a.size() || carry; ++i) {
	if (i == a.size())
		a.push_back (0);
	long long cur = carry + a[i] * 1ll * b;
	a[i] = int (cur % base);
	carry = int (cur / base);
}
while (a.size() > 1 && a.back() == 0)
	a.pop_back();
这里除法后删前导零，以维护无前导零的不变量。

（注：额外优化。若速度极重要，可把两次除法换成一次：只算除法的整数部分（代码中变量 carry），再据此用一次乘法算余数。通常能加速，虽不明显。）

高精度乘高精度
乘 a、b，结果存 c：

lnum c (a.size()+b.size());
for (size_t i=0; i<a.size(); ++i)
	for (int j=0, carry=0; j<(int)b.size() || carry; ++j) {
		long long cur = c[i+j] + a[i] * 1ll * (j < (int)b.size() ? b[j] : 0) + carry;
		c[i+j] = int (cur % base);
		carry = int (cur / base);
	}
while (c.size() > 1 && c.back() == 0)
	c.pop_back();
高精度除短
长 a 除短 b（b < {\rm base}），商存 a、余数存 carry：

int carry = 0;
for (int i=(int)a.size()-1; i>=0; --i) {
	long long cur = a[i] + carry * 1ll * base;
	a[i] = int (cur / b);
	carry = int (cur % b);
}
while (a.size() > 1 && a.back() == 0)
	a.pop_back();
因式分解形式的高精度
思想是不存数本身，而存它的因式分解，即每个所含质数的幂。

此法实现也简单，乘除很易做，但无法做加减。另一方面，相比「经典」方法大幅省内存，且乘除渐近快得多。

此方法常用于需按非质模数除法时：把数存成按该模质因数的幂，外加一个按该模的余数。

按质数模系统的高精度（中国剩余定理或 Garner 方案）
要点是选一组模数（通常较小、能放进标准类型），把数存成对每个模取余的余数向量。

按中国剩余定理，这足以唯一存储 0 到这些模乘积减一之间的任何数。还有 Garner 算法可把数从模形式恢复成普通「经典」形式。

因此此法相对「经典」高精度省内存（虽在某些情形不如因式分解法激进）。而且模形式下加减乘都非常快——都渐近同时间，与模数个数成正比。

但这一切以非常费力的「模形式转普通形式」为代价，除不少时间外还需实现带乘法的「经典」高精度。

此外，这种模系统表示下无法做数的除法。

分数高精度运算的种类
分数运算在竞赛题中少得多，处理巨大分数也难得多，因此竞赛中只出现分数高精度的特定子集。
