> 实数的第一条规则——不要用实数

所有 `double` 类型的变量在计算机中存储得都不精确（那你怎么在二进制里表示 ⅓ 呢？）。因此用 double 时必须**始终**考虑这个误差。例如，要比较两个 double，需要检查它们之差的绝对值小于某个很小的数 `eps`：

```c++
const double eps = 1e-8;

bool eq (double a, double b) { return abs(a-b) < eps }
```

为了避免这样做，尽量只使用 int 和绝对精度。有时有一些技巧可以做到这一点：例如，如果题中所有输入点都是整数、且要求我们计算某个面积，那么可以把所有坐标乘以二，于是答案也是整数（见叉积），只在输出时再除以四即可。

### $0 \neq -0$

实数是这样存储的：$0$ 和 $-0$ 可能是不同的数。请牢记这一点。

### 反函数的定义域

`acos`、`asin` 等反三角函数要求输入在 -1 到 1 之间。为安全起见，在取这些函数之前先对数值做缩放。
