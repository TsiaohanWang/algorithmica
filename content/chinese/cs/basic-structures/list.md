链表（英文 *linked list*）是支持在任意位置快速插入、删除元素，但不一定支持快速随机访问的数据结构。

![](../img/linked.png)

用链表可以实现其他数据结构，例如[栈](stack)和[队列](queue)。

## 实现

链表通常实现为一组节点（英文 *node*），除了元素本身外，还存有指向链表中下一个元素、以及可选地指向前一个元素的引用。

```cpp
template <typename T>
struct Node {
    T val;
    Node *prev, *next;
};

Node *head = 0;
```

## C++

STL 中双向链表实现在 `std::list`。

```cpp
// 存 int 元素的空双向链表
list<int> l;

// 在迭代器 it 之后插入变量 x
l.insert(it, x);

// 删除迭代器指向的元素
l.erase(it);

// 开头和结尾
l.front(), l.back();
```

## 单向与双向链表

注意：这些链表与 Python 的 list（其实是动态数组）没有任何关系。

栈的问题：不能在中间添加、删除元素。

让我们维护一个存所需元素的数组 $values$，并对每个元素再存下一个元素的下标（存在结构体里，或单独放在数组 $next$ 中）。当然，还要存第一个元素的下标 $start$。我们称这种数据结构为单向链表。

要遍历整个单向链表，需要从第一个元素的下标开始，逐步沿着下一个元素的下标移动（$i$ -\> $next\[i\]$），直到 $next\[i\] \\neq i$。

那么如果我们有某个元素的下标 $index$，就能在 $O(1)$ 内在它后面插入一个元素：只需在数组右侧加一个元素，设它得到下标 $new$，并令 $next\[new\] = next\[index\], next\[index\] = new$。

除了下一个元素，通常还会方便地存前一个元素，以便能从右往左遍历链表，或在某个元素前面插入元素。这样的链表称为双向链表。
