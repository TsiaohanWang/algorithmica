*堆*（英文 *heap*）是支持下列操作的抽象数据结构：

1. 找最小值。
2. 删除最小值。
3. 向堆中加入新元素。

另一个更好反映功能的名称——*优先队列*（英文 *priority queue*）。

堆用于许多算法。例如，堆用于[最短路](/cs/shortest-paths/dijkstra)算法，也可以用堆做[排序](/cs/sorting/heapsort)（把数组变成堆、再把堆变成有序数组）。

## 二叉堆的构造

*二叉堆*（金字塔、排序树，英文 *binary heap*）是优先队列的一种实现，使用满足三个条件的根树：

1. 任意顶点的值不大于其后代的值。
2. 任意顶点至多有两个儿子。
3. 层自上而下、自左而右地连续填充，没有「洞」。

注意二叉堆的构建并不唯一：例如作为叶子的儿子值总可以互换。固定的只是结构本身和「父不大于子」的谓词。

![最大二叉堆](/img/binary-heap.svg)

记树高为 $h$。由于堆总由若干完全填满的层和一个部分填充的层组成，且下一层顶点数是上一层两倍，树高为 $\Theta(\log n)$。

与任何优先队列一样，二叉堆要支持操作：

1. 在 $O(1)$ 内找最小值。
2. 在 $O(h)$ 内删除最小值。
3. 在 $O(h)$ 内向堆加入新元素。

除这三个基本操作外，还可以定义别的，例如「修改键值」，但目前只看这三个。

### 实现

用数组 $t$ 存堆，根下标为 1，顶点 $k$ 的子节点下标为 $2k$ 和 $(2k + 1)$。数组第零个单元留空。

![堆在内存中的表示](/img/heap-layout.svg)

下面定义两个辅助函数，在单个元素值改变时恢复堆的不变量。

如果元素值*减小*，为满足堆的第一个条件，可能需要把它移上去。这可以通过反复把元素与其直接父节点比较、若更大则交换来迭代完成。由于每次都沿树上升，这个函数按其高度运行：

```cpp
void sift_up(int v) {
    // 如果元素不小于父节点，则一切正确，无需再做
    while (v > 1 && t[v] < t[v / 2]) {
        // 否则与父节点交换，并从父节点继续
        swap(t[v], t[v / 2]);
        v /= 2;
    }
}
```

如果被修改元素的值*增大*，则需要相反地把它移下去。可以用类似方式，把它与较小儿子交换并继续。同样，每次都下潜更深，因此这个过程也按树高运行：

```cpp
void sift_down(int v) {
    // 直到到达叶子
    while (2 * v <= n) { // n -- 堆中元素个数
        int l = 2 * v; // 左儿子
        int r = 2 * v + 1; // 右儿子
        // 如果右儿子存在且更小，选它
        int u = (r <= n && t[r] < t[l] ? r : l);
        if (t[v] <= t[u])
            break; // 不变量已满足，结束
        swap(t[v], t[u]);
        v = u;
   }
}
```

建议看看[可视化](https://visualgo.net/en/heap)帮助理解。

回到「有用」操作：

1. 最小值在常数内完成——返回根，即数组第一个元素。
2. 删除最小值时，把根的值替换为数组最后一个元素的值、减小堆大小，再从根调用 `sift_down`。
3. 加入元素时把它加到数组末尾，再对它调用 `sift_up`。

*注记*。 如果不用二叉堆，而用所谓 $d$ 叉堆（每个顶点至多 $d$ 个儿子），对任意常数 $d$ 运行时间不变。

## 线性时间构建

对 $n$ 个元素的集合建堆，可以逐个加入——这样建堆运行在 $O(n \log n)$，多数情况下已够快。但还能稍快——线性时间。

我们其实只想重排某数组 $t$ 的元素，使对任意下标 $1 \le i \le n$ 满足 $t_i \le t_{2 i}$ 和 $t_i \le t_{2 i + 1}$（若相应元素存在）。

那就从末尾恢复这个堆性质：用 `sift_down` 逐步扩大满足性质的后续部分。得到算法：

```cpp
void build_heap() {
    for (int i = n; i > 0; --i) {
        // 对后缀 t[i + 1 .. n] 堆性质成立
        sift_down(i);
        // 现在对后缀 t[i .. n] 成立
    }
}
```

为什么在 $O(n)$ 内？诚实地上界估计下潜的总次数。对每个高度 $i$，其上顶点数不超过 $2^{h - i}$，因此

$$
\sum_{i = 1}^h 2^{h - i} \cdot i
= 2^{h + 1} - h - 2
\le  2 n - h - 2
\le 2 n = O(n)
$$

第一个等式容易对 $h$ 归纳证明。

## 标准库

STL 提供几个在数组上操作二叉堆的原语：

```cpp
int ints[] = {10,20,30,5,15};
vector<int> v(ints, ints + 5);

make_heap(v.begin(), v.end());
v.front(); // 取最大元素 (30)

pop_heap(v.begin(), v.end()); // 从堆中删除最大值
v.pop_back(); // 把数组大小减一

v.push_back(99); // 在数组末尾加元素
push_heap(v.begin(), v.end()); // 对最后一个元素调用 sift_up

sort_heap(v.begin(), v.end()); // 堆排序：v 中会写入有序数组
```

不过它们很少直接用。更常用的是基于向量和这些操作的 `priority_queue` 接口：

```cpp
priority_queue<int> q;

for (int x : {1,5,3,4,2,0})
    q.push(x);

q.top(); // 返回最大元素 (5)
q.pop(); // 删除最大元素
```

`priority_queue` 中找最大（默认）元素在 $O(1)$ 内，加入与删除在 $O(\log n)$ 内。此外它有 `.size()`、`.empty()` 等 STL 容器应有的方法。

也常用任意[搜索树](/cs/tree-structures)（如 `std::set`）当优先队列。
