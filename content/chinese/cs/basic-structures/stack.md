在链表或动态数组之上可以做出功能更具体的结构，因算法而异。

栈是存储元素、支持在 $O(1)$ 内回答两种操作的数据结构：

- `push(x)`：把元素 x 放到栈尾。
- `top()`：返回栈尾元素。
- `pop()`：取出栈尾元素。

这种加入、删除数据的原则叫 FILO（first in, last out）：如果先把所有元素放进去、再全部取出，那么最后取出的是第一个放入的元素。

C++ 中栈已实现为 `stack<T> stack_name`。除 `push` 和 `pop` 外，还有辅助操作：

- `size()`：返回栈大小。
- `empty()`：判空。
- `clear()`：清空栈。

栈既可以用链表实现，也可以用动态数组实现——C++ 里用 `vector`，因此均摊所有操作在快速常数内完成，但可能需约两倍于存元素本身所需的内存。

### 括号序列

*正确括号序列*（ПСП）是由开、闭括号组成的字符串，能由某个正确的算术表达式删去除括号外的一切得到。

例如从表达式 $(1 + 2) \cdot (3 + 100 \cdot (3 / 2))$ 得到 ПСП `()(())`，而 `)(())` 不能从任何算术表达式得到。

在正确括号序列中，所有括号能配成对：第一括号是开、第二是闭，开在前闭在后，且任意两对不交叉。

把长度 $n$ 前缀上的*平衡*定义为该前缀上开、闭括号数之差。要判断括号序列是否合法，只需检查两条：

1. 整串的平衡为 0。
2. 任意前缀的平衡非负。

即任何前缀上开括号不少于闭括号，整串中二者数量相等。这容易从左到右遍历检查：遇开括号加 $+1$，遇闭括号加 $-1$。只需检查平衡始终非负、最后为零。

```cpp
bool is_correct(string s) {
    int bal = 0;
    for (char c : s) {
        if (c == '(')
            bal++;
        else
            bal--;
        if (bal < 0)
            return false;
    }
    return (bal == 0);
}
```

还可以定义含多种括号的正确括号序列，只需在形式定义中加上：每对括号必须是同一种。

例如 `([]({}))` 是 ПСП，而 `[(])` 不是。

通过平衡检查合法性不幸不能这样简单推广。需要更直接地解：为每个括号找它的另一半。

建空栈，从左到右遍历，把每个遇见的开括号压入栈尾，遇到任何闭括号时从栈尾取出一个开括号——并检查取出的开括号与所遇闭括号同类型。如果建栈过程中无错误、最后栈空，则序列正确。

例子：字符串 `{[([])()]{}}`。算法中栈的变化：

1. 栈空
2. `{`
3. `{[`
4. `{[(`
5. `{[([`
6. `{[(`: 取出的 `[` 匹配 `]`
7. `{[`: 取出的 `(` 匹配 `)`
8. `{[(`
9. `{[`: 取出的 `(` 匹配 `)`
10. `{`: 取出的 `[` 匹配 `]`
11. `{{`
12. `{`: 取出的 `{` 匹配 `}`
13. 栈空: 取出的 `{` 匹配 `}`

所有取出的括号都匹配所遇闭括号，最后栈空——所以是 ПСП。

而字符串 `[{]}` 不是 ПСП：

1. 栈空
2. `[`
3. `[{`
4. 错误，因为栈尾的 `{` 不匹配 `]`

实现：

```cpp
bool is_opening(char c) {
    return c == '(' || c == '[' || c == '{';
}

bool is_matching(char a, char b) {
    return (a == '(' && b == ')') ||
           (a == '[' && b == ']') ||
           (a == '{' && b == '}');
}

bool is_correct(string s) {
    stack<char> t;
    for (char c : s) {
        if (is_opening(c))
            stack.push(c);
        else {
            if (stack.empty() || is_matching(stack.top(), c))
                return false;
            stack.pop();
        }
    }
    return stack.empty();
}
```

算法运行在 $O(n)$，因为我们只是遍历字符串、每次对栈执行 push 或 pop 之一。

### 逆波兰表示法

栈也常用于按复杂顺序计算。例如，计算机如何计算表达式 $(1 + 2) \* (100 \* (3 / 2) + 3) + 4$？直接算很难，我们把它改写为更易算的格式：

$\[1, 2, +, 100, 3, 2, /, \*, 3, +, \*, 4, +\]$

这种数加操作的列表叫*逆波兰表示法*。它这样计算：从左到右遍历，

- 遇到数，压入栈。
- 遇到操作，从栈尾取出两个数、应用该操作、把结果压入栈。

例如这个表达式的栈：

  - \[\]
  - $\[1\]$
  - $\[1, 2\]$
  - $\[3\]$
  - $\[3, 100\]$
  - $\[3, 100, 3\]$
  - $\[3, 100, 3, 2\]$
  - $\[3, 100, 1.5\]$
  - $\[3, 150\]$
  - $\[3, 150, 3\]$
  - $\[3, 153\]$
  - $\[459\]$
  - $\[459, 4\]$
  - $\[463\]$

最后栈里剩下的唯一元素就是结果。

### 最大矩形

有一个直方图——一组宽度 1、高度到 $n$、从左到右紧挨的矩形，它们的下 $y$ 坐标总是 0。

任务是找这个格子直方图内部面积最大的矩形。

**解。**
注意最大矩形的下边界总是 $y = 0$。最大矩形应无法向任何方向扩展。让我们枚举所有这样的矩形，选面积最大的。

从左到右看直方图的竖直矩形，维护一个「阶梯」——栈里放已走过的柱子（下标与高度），但只放使柱子严格递增所需的部分，且阶梯以最后考察的柱子结尾。

构建方式：看新柱子。若其高度大于栈尾（上一根柱子），就直接压栈，完事。若高度小于等于栈尾，则从栈尾取出柱子，直到新柱高度终于大于栈尾。最后取出栈中所有柱子（为此方便地在末尾放一根高度为零的假柱子）。

取出柱子时，要算包含这根柱子的最大矩形面积。高度已知，要确定面积。注意它的左坐标是栈中位于它之前的柱子的下标（即最右的、位于被删柱左侧且高度更低的柱子）加一。右坐标是我们正考察的那个（因为要删这根柱子）。

这怎么工作？最大矩形顶部至少顶到一根柱子，因此删除它时会计入这个矩形。

这样能在 $O(N)$ 内求这种直方图最大矩形面积。

注意，这个题可以归结为「在黑白矩形中找最大白色矩形」：为每格算它上方连续白色格数（用简单动态规划），再枚举 $N$ 行、对该行作底的直方图求解——现在所有高度都已知。

于是 $O(N^2)$ 解决——这正是矩形大小，所以不能再快。
