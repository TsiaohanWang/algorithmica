C++ 内置了队列。它叫 queue。要使用它，需要包含头文件 `queue`。队列的声明如下：

``` C++
queue<T> q;
```

队列是遵循 FIFO（先入先出）原则的结构，也就是说队列有两个基本操作：在尾部插入、从头部取出。

``` C++
q.front(); // 第一个元素的引用
q.back(); // 最后一个元素的引用
q.push(x); // 加到尾部
q.pop(); //从头部删除
```

队列是一种数据结构，它以 $O(1)$ 的成本用这些操作存储有序元素：

  - `push(x)` —— 把元素放到队尾
  - `pop()` —— 取出并返回队首元素

它遵循 FIFO（First In - First Out）原则——先来先走。队列很适合用来模拟现实中的排队，因为它们能公平地分配某种东西——先到先得。队列也常用于有多个独立进程的算法——很适合保存待执行任务的队列，当某个进程空闲时，从队列中取出最早加入的任务去执行。
