Sprague–Grundy 理论是描述两名玩家之间所谓公平（英文 "impartial"）博弈的理论，即允许的走法以及胜负性只取决于游戏状态的博弈。具体是两名玩家中的哪一位在走，不产生任何影响：也就是说，玩家完全平等。

此外，假设玩家拥有全部信息（关于游戏规则、可能的走法、对手的位置）。

假设游戏是有限的，即无论采用什么策略，玩家迟早都会到达一个必败位置，从该位置没有通往其他位置的转移。这个位置对于必须从它开始走棋的玩家来说是必败的。相应地，它对于来到这个位置的玩家来说是必胜的。显然，这种博弈中不会有和局结果。

换句话说，这种博弈可以用有向无环图完整描述：顶点是游戏状态，边是当前玩家走一步后从一个状态到另一个状态的转移（再强调一次，在这方面第一和第二玩家是平等的）。一个或多个顶点没有出边，它们是必败顶点（对必须从该顶点走棋的玩家而言）。

由于不存在和局结果，所有游戏状态分为两类：必胜和必败。必胜状态是指存在当前玩家的一步走法，能导致另一个玩家即使最优对弈也必败无疑的状态。相应地，必败状态是指所有转移都通向导致第二玩家获胜的状态（尽管第一玩家会「抵抗」）。换句话说，必胜状态是存在至少一条通向必败状态的转移的状态，而必败状态是所有转移都通向必胜状态的状态（或者根本没有转移的状态）。

我们的任务是对任意给定的游戏对其状态进行分类，即判断每个状态是必胜还是必败。

这类游戏的理论由罗兰·施普拉格（Roland Sprague）于 1935 年和帕特里克·迈克尔·格朗迪（Patrick Michael Grundy）于 1939 年分别独立提出。

尼姆游戏
这个游戏是上述游戏的一个例子。不仅如此，稍后我们将看到，任何公平的双人博弈实际上都等价于「尼姆」游戏（英文 "nim"），因此研究这个游戏将自动让我们能够解决所有其他游戏（不过，这点稍后再谈）。

从历史上看，这个游戏在古代就很流行。它可能起源于中国——至少，中国的「捡石子」（Jianshizi）游戏与尼姆非常相似。在欧洲，关于尼姆的最早记载可追溯到 16 世纪。「nim」这个名称本身是由数学家查尔斯·布顿（Charles Bouton）发明的，他在 1901 年发表了对该游戏的完整分析。「nim」名称的来历至今不详。

游戏描述
「尼姆」游戏的内容如下。

有若干堆石子，每堆有若干颗。每回合玩家可以从任意一堆中取走任意非零数量的石子并扔掉。相应地，当没有走法可用时即输，也就是所有堆都空了。

于是，尼姆游戏的状态由一组无序的自然数唯一描述。每回合可以把其中任意一个数严格减小（如果结果变为零，就从集合中删去）。

尼姆的解法
这个游戏的解法由查尔斯·L·布顿（Charles L. Bouton）于 1901 年发表，内容如下。

定理。当前玩家拥有必胜策略，当且仅当各堆大小的异或和不为零。否则当前玩家处于必败状态。（数 a_i 的异或和指表达式 a_1 \oplus a_2 \oplus \ldots \oplus a_n，其中 \oplus 是按位异或运算）

证明。

下面证明的核心在于对手存在对称策略。我们将证明，一旦处于异或和为零的状态，玩家就无法离开这个状态——无论他转移到任何异或和不为零的状态，对手都能找到一步回应，把异或和重新变回零。

现在开始形式化的证明（它将是构造性的，即我们会展示对手的对称策略具体长什么样——他需要走出怎样的一步）。

我们用归纳法证明定理。

对空尼姆（所有堆大小都为零）异或和为零，定理成立。

现在假设我们要为某个至少有一条转移的游戏状态证明定理。利用归纳假设（以及游戏的无环性），我们认为定理对从当前状态可达的所有状态都已成立。

于是证明分成两部分：如果当前状态的异或和 s = 0，需要证明当前状态必败，即从它出发的所有转移都通向异或和 t \ne 0 的状态。如果 s \ne 0，则需要证明存在一步转移把我们带到 t = 0 的状态。

设 s = 0，我们要证明当前状态必败。考虑尼姆当前状态的任意一个转移：记 p 为被改变的堆的编号，x_i（i = 1 \ldots n）为走步前各堆的大小，y_i（i = 1 \ldots n）为走步后各堆的大小。利用 \oplus 运算的基本性质，我们有：
 t = s \oplus x_p \oplus y_p = 0 \oplus x_p \oplus[...]

但由于 y_p < x_p，这意味着 t \ne 0。因此新状态将具有非零异或和，即根据归纳基础它是必胜的，证毕。

设 s \ne 0。那么我们的任务是证明当前状态必胜，即从它存在一步通向必败状态（异或和为零）的走法。
考虑数 s 的二进制表示。取最高的非零位，设其编号为 d。设 k 为大小 x_k 的第 d 位非零的那堆的编号（这样的 k 一定存在，否则异或和 s 的这一位不可能是非零的）。

那么可以断言，所求的走法就是把第 k 堆改为大小 y_k = x_k \oplus s。

来验证一下。

首先需要验证这是一步合法的走法，即 y_k < x_k。这确实成立，因为 x_k 和 y_k 高于 d 的所有位都相同，而在第 d 位上 y_k 是 0，x_k 是 1。

现在计算这一步之后得到的异或和：

 t = s \oplus x_k \oplus y_k = s \oplus x_k \oplus[...]

因此，我们指出的走法确实是通向必败状态的走法，这也就证明了当前状态是必胜的。

定理得证。

推论。任何尼姆游戏状态都可以替换为等价状态：由大小等于原状态各堆大小异或和的唯一一堆组成。

换句话说，在分析多堆尼姆时，可以计算它们大小的异或和 s，转而分析大小为 s 的单堆尼姆——正如刚刚证明的定理所示，胜负性不会因此改变。

任意游戏与尼姆的等价性。Sprague–Grundy 定理
这里我们将展示如何把任意游戏（公平的双人博弈）与尼姆对应起来。换句话说，我们将学会把任意游戏的任意状态对应到一堆尼姆，使其完全描述原游戏的状态。

带增量的尼姆引理
首先证明一个非常重要的引理——带增量的尼姆引理。

具体来说，考虑如下修改版尼姆：与普通尼姆完全相同，只是现在多了一类走法：不减小而是增大某个堆的大小。更准确地说，玩家的每步现在要么从某堆取走非零数量的石子，要么增大某个堆的大小（按照某种规则，见下一段）。

这里需要理解的是，玩家具体如何增大的规则我们并不关心——但这样的规则必须存在，以保证我们的游戏仍然是无环的。下文「博弈示例」一节中考察了这类游戏的例子：「阶梯尼姆」、「nimble-2」、「turning turtles」。

再强调一次，这条引理将对所有这种类型的游戏——「带增量的尼姆」——成立；证明中完全不会用到具体的增量规则。

引理的表述。带增量的尼姆等价于普通尼姆，即状态的胜负性由按布顿定理依据各堆大小的异或和决定。（或者换句话说，引理的核心是增量毫无用处，在最优策略中没有必要使用它们，它们与普通尼姆相比不会改变任何胜负性。）

证明。

证明的思路与布顿定理一样——在于对称策略的存在。我们将证明增量不会改变任何东西，因为一旦一个玩家使用增量，另一个玩家就能对称地回应。

确实，假设当前玩家对某个堆做了一次增量。那么他的对手只需把这个堆重新减小回原来的大小来回应——因为普通的尼姆走法仍然可以自由使用。

因此，对增量走法的对称回应就是把它减小回堆原来的大小。于是这样的回应之后，游戏恢复到相同的堆大小，即使用增量的玩家什么也得不到。由于游戏是无环的，增量走法迟早会耗尽，当前玩家最终不得不走减量，这意味着存在增量走法完全不会改变任何东西。

Sprague–Grundy 定理：任意游戏等价于尼姆
现在转到本文最重要的结论——任何公平的双人博弈都等价于尼姆的定理。

Sprague–Grundy 定理。考虑某个公平双人博弈的任意状态 v。设从它有转移到某些状态 v_i（i=1 \ldots k）（其中 k \ge 0）。可以断言，这个博弈的状态 v 可以对应一堆大小为 x 的尼姆（它能完全描述我们的博弈的状态 v——即两个不同游戏的这两个状态是等价的）。这个数 x 被称为状态 v 的 Sprague–Grundy 值。

而且，这个数 x 可以按如下递归方式求出：对每个转移 (v,v_i) 计算 Sprague–Grundy 值 x_i，于是有：

 x = {\rm mex} \{ x_1, \ldots, x_k \}, 

其中 \rm mex 函数返回一个数集中最小的未出现的非负整数（"mex" 是 "minimum excludant" 的缩写）。

于是，从没有出边的顶点出发，我们可以逐步算出我们游戏所有状态的 Sprague–Grundy 值。如果某个状态的 Sprague–Grundy 值为零，则该状态必败，否则必胜。

证明。我们用归纳法证明定理。

对于没有任何转移的顶点，根据定理，x 将是空集的 \rm mex，即 x = 0。确实，没有转移的状态是必败状态，它确实应对应大小为 0 的一堆尼姆。

现在考虑任意一个有转移的状态 v。由归纳假设，对当前状态可达的所有状态 v_i，x_i 的值已经算出。

计算 p = {\rm mex} \{ x_1, \ldots, x_k \}。根据 \rm mex 函数的定义，对区间 [0; p) 中的任何数 i，都存在至少一个通向某个 v_i 状态的对应转移。此外，还可能存在额外的转移——通向 Grundy 值大于 p 的状态。

这意味着当前状态等价于带增量的尼姆中大小为 p 的一堆的状态：确实，从当前状态我们有通向所有更小堆大小状态的转移，也可能有通向更大堆大小状态的转移。

因此，{\rm mex} \{ x_1, \ldots, x_k \} 确实是当前状态所求的 Sprague–Grundy 值，证毕。

Sprague–Grundy 定理的应用
最后描述一个适用于任何公平双人博弈的完整算法，用于判断当前状态 v 的胜负性。

把每个游戏状态对应到一个尼姆数的函数称为 Sprague–Grundy 函数。

那么，要计算某个游戏当前状态的 Sprague–Grundy 函数，需要：

列出当前状态的所有可能转移。
每个这样的转移要么通向一个游戏，要么通向若干个独立游戏的和。
第一种情况——直接递归计算这个新状态的 Grundy 函数即可。

第二种情况，当从当前状态的转移通向多个独立游戏之和时——递归计算其中每个游戏的 Grundy 函数，然后规定多个游戏之和的 Grundy 函数等于它们各自值的异或和。

算完每个可能转移的 Grundy 函数后——对这些值取 \rm mex，得到的数就是当前状态所求的 Grundy 值。
如果得到的 Grundy 值为零，则当前状态必败，否则必胜。
因此，与 Sprague–Grundy 定理相比，这里我们额外考虑了游戏中可能存在从单个状态到多个游戏之和的转移。为了处理游戏之和，我们先把每个游戏替换成它的 Grundy 值，即一堆大小为某个数的尼姆。之后我们得到若干堆尼姆之和，也就是普通尼姆，而它的答案根据布顿定理就是各堆大小的异或和。

Sprague–Grundy 值的规律
在解决具体问题时，当需要学会计算给定游戏的 Sprague–Grundy 函数时，研究该函数的值表以寻找规律往往很有帮助。

在许多看似理论分析相当困难的游戏中，Sprague–Grundy 函数在实践中往往具有周期性，或者具有很容易「一眼」看出的非常简单的形式。在绝大多数情况下，观察到的规律都是正确的，并且在需要时可以用数学归纳法证明。

不过，Sprague–Grundy 函数并不总是含有简单规律，对某些（即使表述非常简单的）游戏，是否存在这种规律的问题至今仍然悬而未决（例如下面的 "Grundy's game"）。
