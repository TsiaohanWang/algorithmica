并查集（英文 *disjoint set union*）是允许合并不相交集合并回答关于它们的各种查询的数据结构，例如「元素 $a$ 和 $b$ 是否在同一集合中」「某集合大小是多少」。

更形式化地说，初始有 $n$ 个元素，每个都在单独（自己的）集合中。结构支持两个基本操作：

- 合并任意两个集合。
- 查询指定元素当前所在集合。

两个操作平均*几乎*在 $O(1)$ 内完成（但不完全）。

并查集常用于图算法中存储连通分量信息——例如[Kruskal 算法](/cs/spanning-trees/kruskal)。

## 结构组织

把元素集合存成树：一棵树对应一个集合。树的根是集合的代表（领袖）。对树根，认为它们的父节点是它们自己。

![](../img/dsu.png)

建数组 `p`，对每个元素存它在树中父节点的编号：

```c++
int p[maxn];

for (int i = 0; i < n; i++)
    p[i] = i;
```

对查询「元素 $v$ 在哪个集合」，需沿引用上升直到根：

```cpp
int leader(int v) {
    if (p[v] == v)
        return v;
    else
        return leader(p[v]);
}
```

合并两个集合时，把一个根挂到另一个根下：

```cpp
void unite(int a, int b) {
    a = leader(a), b = leader(b);
    p[a] = b;
}
```

遗憾的是，最坏情形这种实现运行在 $O(n)$——可以构造「竹竿」：把它 $n$ 次挂到新顶点下。现在来修复。

### 优化

先给优化思路，再分析它们效果如何。

**路径压缩启发式**。优化 `leader` 函数。在返回答案前，把它写入当前顶点的 `p`，即把它直接挂到最高处。

```cpp
int leader(int v) {
    return (p[v] == v) ? v : p[v] = leader(p[v]);
}
```

下面两个启发式意义相近，都试图优化树高，为重挂选择最优根。

**秩启发式**。为每个顶点存它的*秩*——子树高度。合并树时，让秩更大的顶点做新树的根，并重算秩（若两顶点秩相同，领袖秩应加一）。这个启发式直接优化树高。

```cpp
void unite(int a, int b) {
    a = leader(a), b = leader(b);
    if (h[a] > h[b])
        swap(a, b);
    h[b] = max(h[b], h[a] + 1);
    p[a] = b;
}
```

**重量启发式**。不用秩，而为每个顶点存子树大小，合并时挂到更「重」的一侧。

```cpp
void unite(int a, int b) {
    a = leader(a), b = leader(b);
    if (s[a] > s[b])
        swap(a, b);
    s[b] += s[a];
    p[a] = b;
}
```

选择领袖顶点的启发式互斥，但都能与路径压缩一起用。

### 实现

结合重量启发式与路径压缩的最终实现：

```c++
int p[maxn], s[maxn];

int leader(int v) {
    return (p[v] == v) ? v : p[v] = leader(p[v]);
}

void unite(int a, int b) {
    a = leader(a), b = leader(b);
    if (s[a] > s[b])
        swap(a, b);
    s[b] += s[a];
    p[a] = b;
}

void init(n) {
    for (int i = 0; i < n; i++)
        p[i] = i, s[i] = 1;
}
```

作者偏好重量启发式，因为题里常直接需要分量大小。

### 复杂度

路径压缩启发式把复杂度改进到平均 $O(\log n)$。这里用的是均摊估计——显然最坏情形要花 $O(n)$ 压缩整根「竹竿」。

![查询 $p(7)$ 后的路径压缩](../img/path-compression.png)

用归纳法不难证明重量与秩启发式把树高限制到 $O(\log n)$，从而也限制找根的复杂度。

同时用路径压缩加重量或秩启发式，复杂度为 $O(a(n))$，其中 $a(n)$ 是反阿克曼函数（增长极慢的函数，对所有实际数字都不超过 4）。

作者不推荐花时间学证明或读维基上阿克曼函数条目。
