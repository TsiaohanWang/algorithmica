### 平滑子序列

设给定一个序列 $a_1,\ldots,a_n$，最大值为 $A$。要求找出最长的这样的子序列，使得相邻元素之差不超过 1。使用动态规划，其中 $dp\[j\]$ 表示最后一个取的元素等于 $j$ 时的答案。从左到右遍历数组 $a$，同时更新并维护整个数组 $dp$ 保持最新。

相应地，对每个 $i$，只能从满足 $|a\[i\]-j|\\leq 1$ 的 $j$ 转移过来。

``` C++ numberLines
for (int i = 1; i <= n; I++) {
    dp[a[i]] += 1
    if (a[i] > 0) {
        dp[a[i]] = max(dp[a[i]], dp[a[i] - 1] + 1);
    }
    if (a[i] < A) {
        dp[a[i]] = max(dp[a[i]], dp[a[i] + 1] + 1);
    }
}
```

该解法的时间复杂度为 $O(n + A)$。

注意，下面这两种思想在题目中最常见：

  - 在 $dp\[i\]$ 中存储第 $i$ 个前缀的答案。例如背包问题（可以使用前 $i$ 件物品）、LIS（长度为 $i$ 的前缀上的答案）和 LCS（长度为 $i$ 与 $j$ 的前缀上的答案）。
  - 在 $dp\[i\]$ 中存储所有以 $i$ 结尾的序列的答案。

## 最长公共子序列

给定两个序列 $a_1,\\ldots,a_n$ 和 $b_1,\\ldots,b_m$。要求找出它们的最长公共子序列（LCS）的长度，也就是最大的这样的下标序列 $i_1\<\\ldots\<i_k$ 与 $j_1\<\\ldots\<j_k$，使得 $a\[i_1\]=b\[j_1\],\\ldots,a\[i_k\]=b\[j_k\]$。

用动态规划解决这个问题，其中 $dp\[i\]\[j\]$ 表示考察了两个序列长度为 $i$ 和 $j$ 的前缀时的 LCS 长度。

那么注意，计算 $dp\[i\]\[j\]$ 时有两种情况：

  - 若 $a_i \\neq b_j$，则这两个字符中至少有一个不在 LCS 中，否则 LCS 会以两个不同的字符结尾。此时 $dp\[i\]\[j\] = max(dp\[i - 1\]\[j\], dp\[i\]\[j - 1\])$
  - 若 $a_i = b_j$，不难证明一定存在包含这两个字符的最长公共子序列，因此 $dp\[i\]\[j\] = 1 + dp\[i - 1\]\[j - 1\]$。

而在空前缀上答案为 0。

``` C++ numberLines
for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= m; j++) {
        dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
        if (a[i - 1] == b[j - 1]) {
            dp[i][j] = max(dp[i][j], dp[i - 1][j - 1] + 1);
        }
    }
}
```

答案就是数组 $dp$ 中的最大值。该解法的时间复杂度为 $O(nm)$。

答案的还原采用经典方法——从末尾开始。我们只需在每个单元处判断：如果字符相等，就同时减小 $i$ 和 $j$；否则只减小其中一个——选择能使 LCS 最大的那个。

设给定一个由 $n$ 个数组成的序列 $a_1,\\ldots,a_n$。要求找出它的最长上升子序列（LIS）的长度，也就是最大的这样的下标序列 $i_1\<i_2\<\\ldots\<i_k$，使得 $a\[i_1\]\<a\[i_2\]\<\\ldots\<a\[i_k\]$。

例如：在序列 $100, \\underline{20}, \\underline{75}, 0, -40, \\underline{80}, -10, \\underline{120}, 110$ 中，最长上升子序列是 $20, 75, 80, 120$：它的长度为 $4$。这里不存在长度为 5 的上升子序列。

### $O(N^2)$ 的 LIS

让我们用动态规划朴素地求解——也就是在 $dp\[i\]$ 中存下我们要找的东西——前 $i$ 个数的 LIS 长度。

$dp\[0\] = 0$。但如何找到用前面各值表示 $dp\[i\]$ 的公式呢？

嗯，有两种情况：

  - 第 $i$ 个数不在 LIS 中。此时 $dp\[i\] = 1$
  - 第 $i$ 个数在 LIS 中。此时 $dp\[i\] = 1 + dp\[k\]$，其中 $k$ 是该 LIS 中前一个数的下标。那我们就直接枚举它。同时要注意，$a\[k\]$ 必须小于 $a\[i\]$\!* 第 $i$ 个数在 LIS 中。此时 $dp\[i\] = 1 + dp\[k\]$，其中 $k$ 是该 LIS 中前一个数的下标。那我们就直接枚举它。同时要注意，$a\[k\]$ 必须小于 $a\[i\]$\!数在 LIS 中。此时 $dp\[i\] = 1 + dp\[k\]$，其中 $k$ 是该 LIS 中前一个数的下标。那我们就直接枚举它。同时要注意，$a\[k\]$ 必须小于 $a\[i\]$

最终的公式如下：

$$dp\[i\] = \\max(1, 1 + \\max\\limits_{k \< i | a\[k\] \<
a\[i\]}dp\[k\])$$

该算法的时间复杂度为 $O(N^2)$：共有 $O(N)$ 个动态规划状态，每个状态在寻找最大值时需要 $O(N)$ 次操作。

答案的还原方式相同：对每个状态，需要保存最大值是在哪里取得的——那里就是 LIS 中前一个数的位置。

### $O(N\\log{N})$ 的 LIS

用稍微不常规一点的动态规划来解这个问题，其中 $min\\_end\[i\]$ 表示长度为 $i$ 的 LIS 可以以之结尾的最小数字。我们逐步从左到右处理数字，这个数组里只保存关于已经处理过的序列开头部分中所有 LIS 的信息。

初始时 $min\\_end\[0\]=-\\infty, min\\_end\[i\]=\\infty$（$i\>0$）。$\\infty$ 应选一个保证大于所有 $a_i$ 的数，$-\\infty$ 同理。

考虑下一个元素，试着用它延长每一条子序列：

答案是最大的这样的下标 $j$，满足 $min\\_end\[j\] \\neq 0$。该解法的时间复杂度为 $O(n^2)$。

注意到两个事实，可以显著加速：- 任意时刻都有 $min\\_end\[i-1\]\\leq min\\_end\[i\]$。这很容易用反证法证明。- 由前一个事实可知，任意 $a\[i\]$ 最多只会更新一个动态规划值，因为它最多落在一个区间内。

因此，要找到将被更新的 $j$，可以使用二分查找。这个解法已经达到 $O(n\\log n)$。

求最长上升子序列
题目描述如下。给定一个由 n 个数组成的数组 a[0 \ldots n-1]。要求在该序列中找出长度最大的严格递增子序列。

形式化地说：要求找到这样的下标序列 i_1 \ldots i_k，使得：

 i_1 < i_2 < \ldots < i_k, 
 a[i_1] < a[i_2] < \ldots < a[i_k]. 

本文将讨论该问题的各种解法，以及一些可以化归为该问题的其他问题。

O(n^2) 解法：动态规划方法
动态规划是一种非常通用的方法，可以解决一大类问题。这里我们将该方法应用于我们的具体问题。

先学会求出最长上升子序列的长度，稍后再处理子序列本身的还原。

用于求答案长度的动态规划
为此，我们先学会计算数组 d[0 \ldots n-1]，其中 d[i] 是以下标 i 的元素结尾的最长上升子序列的长度。我们将逐步计算这个数组（它本身就是动态规划）：先算 d[0]，再算 d[1]，依此类推。最后，当整个数组算完，答案就是数组 d[] 中的最大值。

设当前下标为 i，即我们要计算 d[i]，而之前的所有值 d[0] \ldots d[i-1] 都已经算好。这时我们有两个选择：

要么 d[i] = 1，即所求子序列只由数 a[i] 本身组成。要么 d[i] > 1。此时在所求子序列中，a[i] 前面还有某个数。我们来枚举这个数：它可以是任意满足 a[j] < a[i] 的元素 a[j]（j = 0 \ldots i-1）。假设当前考虑的某个下标是 j。由于它的动态规划值 d[j] 已经算好，那么数 a[j] 和 a[i] 组合起来就得到答案 d[j] + 1。因此，d[i] 可以按如下公式计算：
 d[i] = \max_{j=0 \ldots i-1, \atop a[j] < a[i]} ([...]

把这两种情况合并成一种，就得到计算 d[i] 的最终算法：

 d[i] = \max \Big( 1, \max_{j=0 \ldots i-1, \atop [...] 

这个算法本身就是动态规划。

实现
下面给出上述算法的实现，它求出并输出最长上升子序列的长度：

int d[MAXN]; // константа MAXN равна наибольшему возможному значению n
 
for (int i=0; i<n; ++i) {
	d[i] = 1;
	for (int j=0; j<i; ++j)
		if (a[j] < a[i])
			d[i] = max (d[i], 1 + d[j]);
}
 
int ans = d[0];
for (int i=0; i<n; ++i)
	ans = max (ans, d[i]);
cout << ans << endl;
还原答案
目前我们只学会了求答案的长度，但还不能输出最长子序列本身，因为我们没有保存任何关于最大值在哪取得的信息。

为了能够还原答案，除了动态规划 d[0 \ldots n-1]，还需要存储辅助数组 p[0 \ldots n-1]——记录每个 d[i] 的最大值是在哪里取得的。换句话说，p[i] 指向那个使得 d[i] 取得最大值的下标 j。（在动态规划中，数组 p[] 常被称为“前驱数组”。）

要输出答案，只需从 d[i] 最大的元素出发，沿着它的前驱一路走，直到输出完整个子序列，即走到 d = 1 的元素为止。

还原答案的实现
这样，动态规划本身的代码也要改，并新增一段输出最长子序列的代码（输出子序列元素的下标，使用 0 基下标）。

为了方便，我们一开始把 p[i] 设为 -1：对于动态规划值等于 1 的元素，它的前驱就保持为 -1，这会让还原答案稍微方便一些。

int d[MAXN], p[MAXN]; // константа MAXN равна наибольшему возможному значению n
 
for (int i=0; i<n; ++i) {
	d[i] = 1;
	p[i] = -1;
	for (int j=0; j<i; ++j)
		if (a[j] < a[i])
			if (1 + d[j] > d[i]) {
				d[i] = 1 + d[j];
				p[i] = j;
			}
}
 
int ans = d[0],  pos = 0;
for (int i=0; i<n; ++i)
	if (d[i] > ans) {
		ans = d[i];
		pos = i;
	}
cout << ans << endl;
 
vector<int> path;
while (pos != -1) {
	path.push_back (pos);
	pos = p[pos];
}
reverse (path.begin(), path.end());
for (int i=0; i<(int)path.size(); ++i)
	cout << path[i] << ' ';
还原答案的另一种方法
不过，和动态规划中的大多数情况一样，还原答案时可以不保存额外的前驱数组 p[]，而是重新计算当前动态规划元素，找出最大值是在哪个下标取得的。

这种方法的代码会稍长一些，但换来的是内存的节省，以及计算动态规划与还原过程中程序逻辑的完全一致。

O (n \log n) 解法：带二分查找的动态规划
为了得到更快的解法，我们先构造一个 O (n^2) 的动态规划变体，然后看看如何把它加速到 O (n \log n)。

新的动态规划如下：设 d[i]（i = 0 \ldots n）为长度 i 的上升子序列结尾的数（如果这样的数有多个，则取其中最小的）。

初始时设 d[0] = -\infty，其余所有元素 d[i] = \infty。

我们逐步计算这个动态规划：先处理 a[0]，再处理 a[1]，依此类推。

下面给出该动态规划的 O (n^2) 实现：

int d[MAXN];
d[0] = -INF;
for (int i=1; i<=n; ++i)
	d[i] = INF;
 
for (int i=0; i<n; i++)
	for (int j=1; j<=n; j++)
		if (d[j-1] < a[i] && a[i] < d[j])
			d[j] = a[i];
现在注意这个动态规划有一个非常重要的性质：对所有 i = 1 \ldots n 都有 d[i-1] \le d[i]。另一个性质是每个元素 a[i] 最多更新一个单元 d[j]。

这意味着我们可以在 O (\log n) 内处理下一个 a[i]：对数组 d[] 进行二分查找。具体来说，我们在数组 d[] 中找第一个严格大于 a[i] 的数，然后像上面的实现那样尝试更新该元素。

O (n \log n) 实现
借助 C++ 标准库中的二分查找算法 upper\_bound（它返回第一个严格大于给定值的元素位置），得到如下简洁的实现：

int d[MAXN];
d[0] = -INF;
for (int i=1; i<=n; ++i)
	d[i] = INF;
 
for (int i=0; i<n; i++) {
	int j = int (upper_bound (d.begin(), d.end(), a[i]) - d.begin());
	if (d[j-1] < a[i] && a[i] < d[j])
		d[j] = a[i];
}
还原答案
基于这个动态规划同样可以还原答案，为此除了动态规划 d[i]，同样需要存储“前驱”数组 p[i]——记录长度为 i 的最优子序列结尾元素的下标。此外，对于数组的每个元素 a[i]，还要存储它的“前驱”——即在最优子序列中应排在 a[i] 前面的那个元素的下标。

在计算动态规划的同时维护这两个数组，最后就不难还原出所求子序列。

（有趣的是，对于这个动态规划，答案只能通过前驱数组来还原——没有它们，动态规划算完后将无法还原答案。这是少数几个无法应用“不用前驱数组”的替代还原方法的动态规划之一。）

O (n \log n) 解法：数据结构
如果说上面的 O (n \log n) 方法相当漂亮，但思想上并不完全平凡，那么还有另一条路：使用某种已知的简单数据结构。

实际上，让我们回到最初的动态规划，它的状态就是当前的位置。当前动态规划值 d[i] 是所有满足 a[j] < a[i] 的元素 j 中 d[j] 的最大值。

因此，如果我们用 t[] 表示这样一个数组，把按数值对应的动态规划值写进去：

 t[a[i]] = d[i], 

那么我们需要的全部能力就是在数组 t 的前缀 t[0 \ldots a[i]-1] 上求最大值。

在数组前缀上求最大值（并且数组会不断变化）的问题可以用多种标准数据结构解决，例如线段树或树状数组。

使用任意一种这样的数据结构，我们就能得到 O (n \log n) 的解法。

这种方法有明显缺点：无论从代码长度还是实现难度看，它都比上面 O (n \log n) 的动态规划差。此外，如果输入的数 a[i] 可能很大，很可能需要压缩（即重新编号为 0 到 n-1）——否则许多标准数据结构会因内存消耗过高而无法使用。

另一方面，这条路径也有优点。首先，这种方法不必费心设计巧妙的动态规划。其次，它还能解决原问题的一些推广（见下文）。

相关问题
这里列出几个与最长上升子序列密切相关的问题。

最长不下降子序列
实际上这是同一个问题，只是现在所求子序列允许出现相等的数（即我们要找的是非严格上升子序列）。

该问题的解法与原问题本质上没有区别，只是在比较时不等号方向会变化，二分查找也要稍作修改。

最长上升子序列的个数
解决这个问题可以使用最初的 O (n^2) 动态规划，或者用数据结构实现 O (n \log n) 的解法。两种情况下，唯一的改动都是：除了动态规划值 d[i]，还要记录这个值可以通过多少种方式得到。

看来，基于 O (n \log n) 动态规划的方法无法应用到这个问题上。

覆盖给定序列所需的最少不上升子序列数
题目如下。给定一个由 n 个数组成的数组 a[0 \ldots n-1]。要求用尽可能少的颜色给这些数染色，使得每种颜色对应的数构成一个不上升子序列。

题解。可以断言，所需的最少颜色数等于最长上升子序列的长度。

证明。实际上，我们需要证明该问题与最长上升子序列问题之间的对偶性。

设 x 为最长上升子序列的长度，y 为所求的最少不上升子序列数。我们要证明 x=y。

一方面，显然不可能有 y<x：如果我们有 x 个严格上升的元素，那么其中任意两个都不能落入同一条不上升子序列，因此 y \ge x。

下面证明反过来 y 也不可能大于 x。用反证法：假设 y > x。考虑任意一组最优的 y 条不上升子序列。我们这样变换这组子序列：只要存在两条子序列，第一条的开头比第二条早，但第一条的开头元素大于等于第二条的开头元素——就把这个开头元素从第一条子序列上摘下来，接到第二条子序列的开头。经过有限步这样操作后，我们仍有 y 条子序列，且它们的开头元素构成一条长度为 y 的上升子序列。但 y > x，这便产生了矛盾（不可能存在长度超过 x 的上升子序列）。

因此，确实有 y = x，证毕。

答案还原。可以断言，所求的划分可以贪心地构造：从左到右扫描，把当前数放入那条当前以“大于等于当前数的最小值”结尾的子序列中。

### $O(N^2)$ 的 LIS

让我们用动态规划朴素地求解——也就是在 $dp\[i\]$ 中存下我们要找的东西——前 $i$ 个数的 LIS 长度。

$dp\[0\] = 0$。但如何找到用前面各值表示 $dp\[i\]$ 的公式呢？
