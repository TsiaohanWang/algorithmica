我们来分析几道动态规划教学题，其状态是某个数组的前缀或连续子段。

### 蚱蜢

有一条 $1 \times n$ 的条带。蚱蜢站在第一格，它每次可以向前跳 1、2 或 3 格。从起始格到最后一格有多少种走法？

试着找出递推公式——也就是推导出 $n$ 的答案如何由更小数字的答案得到。

设 $f[k]$ 为从第 1 格到达第 $k$ 格的走法数。先手动算出它的前几个值：

- $f[1] = 1$ 种走法（待在原地）
- $f[2] = 1$ 种走法：
$$
1 \rightarrow 2
$$
- $f[3] = 2$ 种走法：
$$
\begin{aligned}
    1 \rightarrow 2 \rightarrow 3
\\  1 \rightarrow 3
\end{aligned}
$$
- $f[4] = 4$ 种走法：
$$
\begin{aligned}
    1 \rightarrow 2 \rightarrow 3 \rightarrow 4
\\  1 \rightarrow 3 \rightarrow 4
\\  1 \rightarrow 2 \rightarrow 4
\\  1 \rightarrow 4
\end{aligned}
$$
- $f[5] = 7$ 种走法：
$$
\begin{aligned}
    1 \rightarrow 2 \rightarrow 3 \rightarrow 4 \rightarrow 5
\\  1 \rightarrow 3 \rightarrow 4 \rightarrow 5
\\  1 \rightarrow 2 \rightarrow 4 \rightarrow 5
\\  1 \rightarrow 4 \rightarrow 5
\\  1 \rightarrow 2 \rightarrow 3 \rightarrow 5
\\  1 \rightarrow 3 \rightarrow 5
\\  1 \rightarrow 2 \rightarrow 5
\end{aligned}
$$

再往后就变难了。不过可以发现规律，当然也可能发现不了。无论如何，当我们想出公式后，用写下的前几个值就能轻松验证它是否正确。

来想一想，在通往第 $n$ 格的路径中，蚱蜢的最后一步可能是什么？不外乎三种：

- $(n - 1) \rightarrow n$
- $(n - 2) \rightarrow n$
- $(n - 3) \rightarrow n$

也就是说，到达 $n$ 的所有路径被分成 3 组，而且我们知道每组里有多少条路径：第一组恰好有 $f[n-1]$ 条——这么多条路径先到第 $(n-1)$ 格，然后再跳一步；类似地，第二组和第三组分别有 $f[n-2]$ 和 $f[n-3]$ 条。

把三组路径数加起来，得到

$$
f[n] = f[n-3] + f[n-2] + f[n-1]
$$

和斐波那契数很像，对吧？事实上，如果蚱蜢只能向前跳 1 或 2 格，答案就恰好是第 $n$ 个斐波那契数。

要计算这个动态规划，同样可以开一个数组，从左到右遍历填充：

```cpp
f[0] = 1
f[1] = 1
f[2] = 2
for (int i = 3; i < n; i++)
    f[i] = f[i - 3] + f[i - 2] + f[i - 1];
```

**注。** 这个数列叫做*三波那契数*。

**练习题。** 求长度为 $n$ 的、不含三个连续 1 的 01 序列的个数。

### 带障碍的蚱蜢

稍微改一下问题：现在有些格子被封住了，也就是我们知道蚱蜢不能跳上某些特定的格子。

这个问题依然可以用同样的递推公式解决，只需要保证对所有被禁止的 $k$ 都有 $f[k] = 0$。

因为我们需要在实现中加入这样的检查，稍微重构一下代码，不再分别处理每种跳跃长度，并且只初始化 $f_1$：

```cpp
// a -- булевый массив, свободна ли i-ая клетка

f[0] = a[0];

for (int i = 1; i < n; i++)
    for (int j = i; j > max(i - 3, 0); j--)
        // f[i] изначально заполнены нулями
        f[i] += f[j] * a[j];
```

注意，这种实现可以扩展到任意跳跃长度 $k$。渐近复杂度为 $O(n k)$。

### 回文子串计数

**回文串**是指长度为 $n$ 的字符序列 $a_i$，满足 $a_i = a_{n-i}$。

对于给定的长度为 $n$ 的字符串，求它有多少个子串是回文串。

定义动态规划 $f[l, r]$：如果从 $l$ 到 $r$ 的子串是回文串则为 1，否则为 0。算出它之后，我们就能找出原串中所有的回文子串，答案只需把该动态规划的所有单元求和。

回文串的定义也可以换一种说法：字符串 $s$ 是回文串，当且仅当 $s_0 = s_n$ 且字符串 $s_{1\ldots n - 1}$ 是回文串。我们就用这个定义来递推：

$$
f[l, r] = (s_l = s_r) \land f[l + 1, r - 1]
$$

开一个*二维*数组存放动态规划，先处理基础情形：长度为 1 的子串总是回文串；长度为 2 的子串，在第一个字符等于第二个字符时是回文串。其余状态用上面的公式计算。

唯一的细节是遍历顺序。不能简单地用 for 循环先按 $l$ 递增、再按 $r$ 递增的顺序遍历，因为递推依赖于 $l$ 更大的动态规划值。因此我们改为按子串*长度* $d = r - l + 1$ 迭代，再枚举所有该长度的子串。这样对任意子串，$f[l + 1][r - 1]$ 都已经被算好了。

```cpp
bool f[n][n];

for (int i = 0; i < n; i++) {
    f[i][i] = true;
    f[i][i + 1] = (s[i] == s[i + 1]);
}

for (int d = 3; d <= n; d++)
    for (int l = 0, r = l + d - 1; r < n; l++, r++)
        f[l][r] = (s[l] == s[r]) && f[l + 1][r - 1];

int ans = 0;
for (int l = 0; l < n; l++)
    for (int r = l; r < n; r++)
        ans += f[l][r];
```

另一种做法是按照 $l$ 递减、$r$ 递增的顺序遍历。此外，对于长度为偶数的回文串，可以把基础情形选为「长度为 0 的子串」——它们总是回文串——只需在循环中执行 `f[i][i - 1] = true`；或者干脆把整个动态规划数组初始化为 1，然后从 $d=2$ 开始：

```cpp
memset(f, 1, sizeof f);

for (int l = n - 1; l >= 0; l--)
    for (int r = l + 1; r < n; r++)
        f[l][r] = (s[l] == s[r]) && f[l + 1][r - 1];
```

注意，这个问题存在[更优的](/cs/string-searching/manacher)解法，其中包括线性解法。
