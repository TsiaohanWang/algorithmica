## 定义

树状数组（英文 *Fenwick tree*、*binary indexed tree*）是支持以下操作的数据结构：

* 区间加（对整个区间加 $x$）与区间和查询。

我们以类似定义区间的方式来定义树状数组：

$$
t_i = \sum_{k=F(i)}^i a_k
$$

其中 $F$ 是满足 $F(i) \leq i$ 的某个函数，稍后具体定义。

**求和查询**。 需要区间和时，归结为两个前缀和：

$$
sum(l, r) = sum(r) - sum(l-1)
$$

两个都用公式：

$$
sum(k) = t_k + sum(F(k)-1)
$$

**更新查询**。 修改原数组第 $k$ 个单元时，更新所有计入它的 $t_i$。

可以选 $F$ 使求和时的「下降」与更新时关心的 $t_i$ 都是 $O(\log n)$。两种流行函数：

* $F_1(x) =$ `x & (x + 1)`
* $F_2(x) =$ `x - (x & -x) + 1`

第一个变体在 Wikiconspects 和 E-maxx 有介绍，因此更出名。第二个，如后所见，更好记、更好写，也更灵活——例如能在前缀和上二分。我们就用它。

**注**。 大概会写这个结构的人中不到四分之一完全理解它如何工作。分析确实很复杂，所以文末给出。建议先抽象地接受：任何前缀分解为 $O(\log n)$ 个形如 $[F(i), i]$ 的区间，且任何元素至多进入 $O(\log n)$ 个这样的区间。

## 实现

由于 $F(0) = 1 > 0$，$[0, F(0)]$ 不是合法区间。因此用 1 下标存储数组更方便，且不用 $t_0$。

```c++
int t[maxn];

// 返回前缀和
int sum (int r) {
    int res = 0;
    for (; r > 0; r -= r & -r)
        res += t[r];
    return res;
}

int sum (int l, int r) {
    return sum(r) - sum(l-1);
}

// 更新需要的 t
void add (int k, int x) {
    for (; k <= n; k += k & -k)
        t[k] += x;
}
```

作者指出公式 `r -= r & -r` 与 `k += k & -k` 有漂亮的对称性，这是「传统」版本没有的。

## 多维情形

> $k$ 维树状数组用 $(k+1)$ 行写

只需在 `sum`、`add` 里各加一行同样代码，并在算矩形和时用四个前缀和查询代替两个。

`sum` 重写如下：

```c++
int sum (int r1, int r2) {
    int res = 0;
    for (int i = r1; i > 0; i -= i & -i)
        for (int j = r2; j > 0; j -= j & -j)
            res += t[i][j];
    return res;
}
```

在 $k$ 维情形，按容斥原理，求和查询需要 $2^k$ 次前缀和查询。

如果维数超过内存允许，可用哈希表代替数组 `t`——那样潜在需 $O(q \log^2 A)$ 内存（$A$ 是最大坐标），但这仍是最无痛地解相当简单的二维结构题的方法之一。

## 二分

事实证明，可以在 $O(\log n)$ 内对前缀和做二分查找（更准确说，下降）。

```c++
// 返回和已经更大的下标
int lower_bound (int s) {
    int k = 0;
    for (int l = logn; l >= 0; l--) {
        if (k + (1<<l) <= n && t[k + (1<<l)] < s) {
            k += (1<<l);
            s -= t[k];
        }
    }
    return k;
}
```

若知道 $F(x)$ 去掉 $x$ 的末位，原理就清楚：只是像线段树那样沿二叉树下潜。有点像生成第 $k$ 个字典序组合对象：总在可能时增大下一个字符。

注意，「传统」下标下不能这样做。

## 对运算的限制

当运算可逆、且前缀和技巧成立时可用树状数组。这通常是像和、`xor`、模乘法（若保证不被该模整除）的简单运算。最小值、`gcd`、延迟操作和可持久化一般不能加——那就得写线段树。

## 为什么它工作

于是我们选了 $F(x)$ = `x - (x & -x) + 1`。弄清 `x & -x` 是什么意思。

**引理**。`x & -x` 返回 x 二进制中最末的置位位。

**证明** 需要知道计算机如何存整数。为避免处理器在算术运算时烧掉多余周期检查符号，整数按模 $2^k$ 存储，首位管符号（0 正 1 负）。所以要知道负数长什么样，要从零减它：$-x = 0-x = 2^k-x$。

`-x` 的位写法是什么样？答案可以心算分成三段：

- x 末尾的若干（可能零个）零，在答案中仍是零。
- 然后，恰在 x 最末置位位上，我们「借」许多 1，使整个前缀变成 1。答案中此处一定是 1。
- 然后，前缀中恰那些在原数中为 1 的位被抵消。

例子：

$$
\begin{aligned}
    +90 = 2+8+16+64          & = 0 \, 10110_2
\\  -90 = 00000_2 - 10110_2  & = 1 \, 01010_2
\\  \implies (+90) \& (-90) & = 0 \, 00010_2
\end{aligned}
$$

现在证明引理。做 & 时，在最末置位位之前的前缀里，`x` 与 `-x` 的各位都相反；最末置位位保持为 1；后缀保持全零。因此「幸存」的只有这个最末置位位，证毕。

**推论 1**。 `sum` 运行在对数时间，更准确说是在 $x$ 二进制置位位数内：每次迭代做 `x -= x & -x`，即去掉末位。

**推论 2**。 `add` 也运行在对数时间：每次迭代 $x$ 末尾的零数至少增加一。

**推论 3**。（为什么树状数组是树。）

* 任意 $t_i$ 对应区间长度是 2 的幂，且该区间从同样 2 的幂的倍数的下标开始。

* $\implies$ 任意 $t_i$ 与 $t_j$ 计入的元素集合要么不相交，要么一个是另一个的子集。

* $\implies$ 可在 $t_i$ 上定义嵌套关系。

即如果发挥想象，$t$ 可看成森林。特例当 $n$ 是 2 的幂时只有一棵树。

现在唯一要证明的是 `add` 的正确性。其实在 `add` 里我们做的不外乎从顶点上升到根、经过所有祖先。

如何为 $x$ 找直接父节点？需找最小数 $y > x$，使 $t_y$ 包含 $x$。即应满足 `y >= x > y - (y & -y)`。

读者可自己看看例子，理解 `x + (x & -x)` 正是最小这样的数：

$$
\begin{aligned}
    x = 90 = 2+8+16+64 & = 10110_2
\\\ y = 96 = 32 + 64   & = 11000_2
\end{aligned}
$$
