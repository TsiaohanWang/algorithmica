### 算法描述

学会在某连续函数 $f$ 的区间 $\[l, r\]$ 上找局部最大值。假设该区间上只有一个局部最大值，即 $f$ 先增后减。

维护不变量——所求最大值在区间 $\[l, r\]$ 上。像[二分查找](Бинарный_поиск "wikilink")那样逐步把边界移向所求点。

把当前区间分成<b>三等份</b>。得到区间：$\\left\[l, m_1\\right\]$、$\[m_1, m_2\]$、$\[m_2, r\]$。现在比较 $m_1$ 与 $m_2$ 处的值。

  - 若 $f(m_1) \> f(m_2)$，则函数最大值在 $\[l, m_2\]$ 上。$m_2$ 右侧不可能，因为那样 $\[m_1, m_2\]$ 上递减、$\[m_2, m_3\]$ 上递增，但我们要求先降后升。把边界移为 $r \\rightarrow m_2$。
  - 若 $f(m_1) \< f(m_2)$，则最大值在 $\[m_1, r\]$ 上，理由同上。把边界改为 $l \\rightarrow m_1$。

### 复杂度

注意每段长度是原长三分之一，即搜索区间长度每次乘以 $\\frac{2}{3}$。若在 $n$ 个元素的数组上搜索，约做 $\\log_{3/2}n$ 次迭代。复杂度 $O(\\log n)$，因为我们忽略[对数](Логарифм "wikilink")的底。

### 另一种解法

如我们所知，函数 $f$ 的局部最大值就是这样的 $x_0$：对一切接近它的 $x$ 有 $f(x) \< f(x_0)$。对连续函数有更强条件：最大值左侧函数递增、右侧递减。在二分查找中用这个条件。

若已知 $x_1$（它邻域内 f(x) 递增）和 $x_2$（它邻域内 f(x) 递减），可在它们之间二分，找使函数值左侧递增、右侧递减的点 $x_0$。这就是局部最大值。

若函数凸，它样子很漂亮：先增、后最大、再减。

为判断某点邻域内函数值增还是减，只需取它附近两个足够近的点、比较这两点的 $f$ 值。

<em><b>注：</b>这方法也叫按导数二分，因为先导数大于零、后小于零。</em>

### 常值区间

描述函数 $f$ 时我们要求<b>严格</b>增与减。解释这个限制。假设允许非严格单调。

找局部最小值。假设函数有一段值恒定。搜索区间在这里可能以两种方式改变——取决于相等时搜索走向哪部分。若左边界移到橙线，搜索就停留在值 $1$ 的区间上，远大于真正的局部最小值 $0$。

这样我们刚学会找连续函数（已知其取小于与大于 0 的值）的根。但能否用二分查找找函数局部最大值？能！

如所知，函数 $f$ 的局部最大值就是这样的 $x_0$：对一切接近它的 $x$ 有 $f(x) \< f(x_0)$。对连续函数有更漂亮的事：最大值左侧递增、右侧递减。这正是实二分查找的绝佳条件！

若已知 $x_1$（它邻域内 f(x) 递增）和 $x_2$（它邻域内 f(x) 递减），可在其间二分找 $x_0$。这就是局部最大值。

若函数凸，它样子很漂亮：先增、后最大、再减。

只有一个问题：如何判断某点邻域内函数值增还是减？只需取它附近非常非常近的两个点比较即可！（非常非常近——距离 $\\epsilon \< 10^{-6}$）

## 凸函数最大值：三分查找、二分查找

这样我们刚学会找连续函数（已知其取小于与大于 0 的值）的根。但能否用二分查找找函数局部最大值？能！

如所知，函数 $f$ 的局部最大值就是这样的 $x_0$：对一切接近它的 $x$ 有 $f(x) < f(x_0)$。对连续函数有更漂亮的事：最大值左侧递增、右侧递减。这正是实二分查找的绝佳条件！

若已知 $x_1$（它邻域内 f(x) 递增）和 $x_2$（它邻域内 f(x) 递减），可在其间二分找 $x_0$。这就是局部最大值。

若函数凸，它样子很漂亮：先增、后最大、再减。

只有一个问题：如何判断某点邻域内函数值增还是减？只需取它附近非常非常近的两个点比较即可！

### 三分查找

找最大值的另一方法是三分查找。设最大值位于 left 与 right 之间。把区间分成**三**等份：

- middle_left = (2 * left + right) / 3
- middle_right = (left + 2 * right) / 3

若 f(middle_left) < f(middle_right)，可放心把 left 换成 middle_left（最大值肯定不左于 middle_left）；若 f(middle_left) > f(middle_right)，可放心把 right 换成 middle_right。它不是按二进对数，而是按底 1.5 的对数运行，更大（但渐近相同，因差常数倍）。

两种方法都快，且都能推广到离散情形（即开头那种：给一个先增后减的数组）。但问题在于**如果函数非严格增、非严格减，即存在常值段，算法不工作**。函数值相等时，无法判断应从哪侧找最大值——它可能在任何一侧。

### 未排序数组上的二分查找

注意，原始题里「先零后一」的条件并不重要。重要的是我们知道指向 0 的下标和指向 1 的下标。之后二分查找同样能找出数组中相邻的 0 和 1。

因此，如果任务正是找两个「条件成立与不成立」的相邻下标，二分查找对递增数组/函数之外也工作。

例如，若已知 $f(x_0) < 0$、$f(x_1) > 0$，且函数连续，那么即使函数不单调，也能用二分在 $x_0$ 与 $x_1$ 之间找零点！

又如，若需在数组中找相邻的偶数和奇数，且已知某个偶数和某个奇数的位置，也容易用二分完成。

记住这点很有用，它出现在多道竞赛题中。

设函数 f(x) 在某区间 [l;r] 上单峰。单峰指两种情况之一。第一种：函数先严格增、达到最大值（在一点或整段）、再严格减。第二种对称：先减、达最小值、再增。后文只看第一种，第二种完全对称。

要求在区间 [l;r] 上求函数 f(x) 的最大值。

算法
在该区间取任意两点 m_1 和 m_2：l < m_1 < m_2 < r。算 f(m_1) 与 f(m_2)。有三种情形：

若 f(m_1) < f(m_2)，则所求最大值不可能在左部，即 [l;m_1]。易验证：若左点函数值小于右点，则要么这两点都在函数「上升区」，要么只有左点在。无论哪种，都说明最大值应只在 [m_1;r] 中找。
若相反 f(m_1) > f(m_2)，情形与上一对称。现在最大值不可能在右部 [m_2;r]，转到 [l;m_2]。
若 f(m_1) = f(m_2)，则要么两点都在最大值区，要么左点在上升区、右点在下降区（这里关键用了严格增/减）。因此后续应在 [m_1;m_2] 中找，但（为简化代码）此情形可归入前两者之一。
于是按两内点函数值比较结果，把当前搜索区间 [l;r] 换成新区间 [l^\prime;r^\prime]。对新区间重复，再得新的更小区间，依此类推。

迟早区间长度小于预定的精度常数，可停止。此方法数值性，停止后近似认为 [l;r] 所有点都达到最大值；答案可取如 l。

剩下注意我们没对 m_1、m_2 的选择加任何限制。显然收敛速度（及误差）取决于此。最常用是把区间 [l;r] 分成 3 等份：

 m_1 = l + \frac{r-l}{3} 
 m_2 = r - \frac{r-l}{3} 

不过其他选择（m_1 与 m_2 更靠近）会稍快收敛。

整参情形
若函数 f 参数为整数，区间 [l;r] 也离散，但因为我们没对 m_1、m_2 选择加限制，不影响正确性。仍可让 m_1、m_2 把区间 [l;r] 分成 3 份，只是近似相等。

第二个不同点是停止准则。此时三分查找应在 r-l<3 时停止，因为否则无法选互异且不同于 l 和 r 的 m_1、m_2，可能死循环。三分查找停止（r-l<3）后，从剩余的候选点（l,l+1,\ldots,r）中选函数值最大的。

实现
连续情形的实现（即函数 f 为 \rm double\ f\ (double\ x)）：

double l = ..., r = ..., EPS = ...; // 输入
while (r - l > EPS) {
   double m1 = l + (r - l) / 3,
      m2 = r - (r - l) / 3;
   if (f (m1) < f (m2))
      l = m1;
   else
      r = m2;
}
这里 \rm EPS 实际上是答案的绝对误差（不含函数计算误差）。

可用下面准则替代 "while (r - l > EPS)"：

for (int it=0; it<iterations; ++it)
一方面得选常数 \rm iterations 保证所需精度（通常几百就够达到最大精度）。但另一方面，迭代次数不再依赖 l、r 的绝对值，即我们用 \rm iterations 设定所需相对误差。
