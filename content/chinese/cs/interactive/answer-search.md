本文通过几道题介绍二分查找的一个重要变体——二分答案：把问题表述为「找出最大的 $x$，使得关于 $x$ 的某个容易计算的属性成立」，然后用二分查找找到这个 $x$。

### 「牛棚里的牛」

> 直线上有 $n$ 个牛棚（给出它们在直线上的坐标），需要把 $k$ 头牛放进去，使牛之间的最小距离尽可能大。
> 
> 保证 $1 < k < n$。

如果正面硬解这道题，完全不知道怎么做。我们转而解决一个更简单的问题：假设我们知道这个距离 $x$——牛不能被放得比它更近。那么能把牛放进去吗？

答案是可以，而且相当简单：把第一头牛放到最左边的牛棚，因为这总是有利的。接下来几个牛棚如果距离小于 $x$ 就空着，把第二头牛放到剩下最左边的牛棚，依此类推。

实现方法：从左到右遍历排序后的牛棚数组，维护最后一头牛的坐标，根据到上一头牛的距离决定跳过还是放入新牛。

```cpp
bool check(int x) {
    int cows = 1;
    int last_cow = coords[0];
    for (int c : coords) {
        if (c - last_cow >= x) {
            cows++;
            last_cow = c;
        }
    }
    return cows >= k;
}
```

如果这样贪心到最后牛先用完了，那么答案肯定不小于 $x$；如果没成功，答案肯定小于 $x$。

现在可以枚举 $x$，做 $X = \frac{\max x_i - \min x_i}{k}$ 次 $O(n)$ 检查，但还能更快。

对 $x$ 做二分查找——因为对某些小的 $x$ 肯定能放下牛，从某个大的 $x$ 开始放不下，而题目正是让我们找这个分界。

```cpp
int solve() {
    sort(coords.begin(), coords.end());
    int l = 0; // 因为牛比牛棚少，x = 0 总够用
    // 按题意至少有 2 头牛，
    // 最好情况下我们把它们放到相反的两端：
    int r = coords.back() - coords[0] + 1;
    while (r - l > 1) {
        int m = (l + r) / 2;
        if (check(m))
            l = m;
        else
            r = m;
    }
    return l;
}
```

每次检查运行在 $O(n)$，外部二分查找做 $O(\log n)$ 次检查，所以复杂度是 $O(n \log X)$。

### 「打印机」

> 有两台打印机。一台每 $x$ 分钟打印一页，另一台每 $y$ 分钟打印一页。它们打印 $n$ 页需要多少分钟？
> 
> $n > 0$

这里与上一题不同，似乎存在带公式的直接解法。但与其去想它，不如干脆把问题归结为逆问题。让我们想：给定分钟数 $t$（答案），怎么知道这段时间内打印了多少页？非常容易：

$$
\left \lfloor \frac{t}{x} \right \rfloor + \left \lfloor \frac{t}{y} \right \rfloor
$$

显然，$0$ 分钟内打印不出 $n$ 页；而 $x \cdot n$ 分钟内仅第一台打印机就能打印 $n$ 页。因此 $0$ 和 $xn$ 是二分查找合适的初始边界。
