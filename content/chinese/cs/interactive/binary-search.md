**题目**。 猜了一个 1 到 100 之间的整数 $x$，你需要用某种「是否题」猜出它：例如可以问 $x$ 是否大于某个数、是否偶数。最坏情况下要多少问题能找出 $x$？

一个最优解的结构是：第一个问题问「$x$ 是否大于 50」，若答「是」再问「$x$ 是否大于 75」，否则问「$x$ 是否大于 25」，如此重复，每次都把可能值区间缩小约一半。

更结构化地说，如果有搜索区间——初始从 $l=1$ 到 $r=100$——则每次迭代选「中间」元素 $m = \lfloor \frac{l+r}{2} \rfloor$，问「$x>m?$」，按回答做赋值 $l = m + 1$ 或 $r = m$，并用新边界重复，直到它们相等（说明 $l = r = x$）。

这样一个程序可以在控制台运行：

```python
l, r = 1, 100

while l < r:
    m = (l + r) // 2
    resp = input(f'x > {m}? ')
    if resp == 'yes':
        l = m + 1
    else:
        r = m

print(f'x = {l}')
```

如果猜 $x=42$ 并如实回答：

```
x > 50? no
x > 25? yes
x > 38? yes
x > 44? no
x > 41? yes
x > 43? no
x > 42? no
x = 42
```

这里需要 7 个问题，但取决于猜的数，有时恰好问 7 个、有时 6 个。

一般地，由于每次迭代搜索区间长度保证减半（可能向上取整），需要 $O(\log n)$ 次操作，更准确说是 $\lceil \log_2 n \rceil$ 或 $\lfloor \log_2 n \rfloor$ 个。

### 在数据结构中

给数组 $a$，判断其中是否有元素 $x$。

显然最坏情形下该元素不在数组中，但为确认需花 $O(n)$ 次操作遍历数组所有元素。

但如果数组已排序，就能更快地找数 $x$：可以类似地找*下界*（英文 *lower bound*）——不小于 $x$ 的最小数——再检查它是否等于 $x$。

```cpp
bool find(int x, int *a, int n) {
    int l = 0, r = n + 1;
    // 搜索区间现在是半开区间: [l, r)
    while (l + 1 < r) {
        int m = (l + r) / 2;
        if (a[m] >= x)
            l = m;
        else
            r = m;
    }
    return (l < n && a[l] == x);
}
```

对 STL 标准容器，这个函数已实现：

```cpp
bool find(x, vector<int> a) {
    auto it = lower_bound(a.begin(), a.end(), x);
    return (it != a.end() && *it == x);
}
```

C++ 中还有 `upper_bound` 函数，找第一个严格大于参数的数。

### 检查性质

这类方法不仅用于找元素，还能检查某些先成立后不成立（或反之）的单调性质。

在数组中找下界是特例：我们检查条件 $(a[k] \geq x)$，想找从哪个 $k$ 开始成立。

其他例子：

- 找有序数组中*最后一个*等于 $x$ 的数，或输出没有。
- 数有序数组中 $x$ 出现多少次。
- 给一个数组，前半全是奇数、后半全是偶数。找从哪个下标起全是偶数。

这些题都能用二分查找在 $O(\log{n})$ 内解决。但要明白，以纯形式用二分找这种题没意义——因为创建大小为 $n$ 的数组本身就要 $O(n)$。

所以这类题常这样表述：给大小为 $n$ 的有序数组，回答 $m$ 个「数 $x_i$ 是否在数组中」查询。在 $O(n + m\log{n})$ 内解决——先 $O(n)$ 建数组，再 $m$ 次运行二分查找。

### 实参二分查找

仍有一个先取 0 后取 1 的谓词函数 $f(x)$，想找它改变值的位置。但现在函数参数是实数。

这种函数的例子：

$$
f(x) = \begin{cases}
   0, & x^2 < 2
\\ 1, & x^2 \geq 2 
\end{cases}
$$

当 $x < \sqrt 2$ 时 $f(x) = 0$，稍大时 $f(x) = 1$。如果学会找 $x_0$ 使 $f(x_0) = 0$ 且对某个小 $\epsilon$ 有 $f(x_0 + \epsilon) = 1$，那我们就学会算根号二——以及任何正数的平方根。

这里也能用二分查找，但有个问题：实数在计算机中存得不精确。

```python
# 著名例子
print(0.1 + 0.1 + 0.1)
# = 0.30000000000000004
```

更不能找到 $\sqrt 2$ 的*精确*值，因为它是无限不循环小数。

所以实现实参二分查找要小心：

- 要确认 $f(l_0) = 0$ 且 $f(r_0) = 1$。
- 要么在 $r - l < \epsilon$ 时停止，要么（更好）做固定次数迭代。

要得到 $k$ 位正确数字需要多少次迭代？由于*二分*查找用*二*进制对数，可以说猜一位十进制数字大约需要三步二分（$\log 10 \approx 3$）。所以如果例如需要算到小数点后六位，在 $l$ 与 $r$ 距离达到 1 之后还需约 18 步。

为避免每次想这些，可以认为一百步二分对所有合理目的总够：

```cpp
float sqrt(float x) {
    float l = 0, r = x;
    for (int i = 0; i < 100; i++) {
        float m = (l + r) / 2;
        if (m * m < x)
            l = m;
        else
            r = m;
    }
    return l;
}
```

实际上，用这种方法可以找任何已知其取负与取正参数值的连续函数的零点（刚才我们找的是函数 $x^2 - 2$ 的零点）。
