这里看最大和子段问题（"maximum subarray problem"），以及它的一些变体（包括作者 KADR（Yaroslav Tverdokhleb）描述的在线变体算法）。

问题描述
给数数组 a[1 \ldots n]。求使和最大的子段 a[l \ldots r]：

 \max_{ 1 \le l \le r \le n } \sum_{i=l}^{r} a[i].[...]

例如，如果 a[] 的所有数都非负，那答案可取整个数组。当数组同时含正数与负数时，解就不平凡。

显然，最小和子段问题本质相同——只需把所有数取反。

算法 1
这里看一个几乎显然的算法。（后面看另一个更难想、但实现更短的。）

算法描述
算法很简单。

方便起见记 s[i] = \sum_{j=1}^{i} a[j]，即 s[i] 是 a[] 的部分和数组。另设 s[0] = 0。

现在枚举下标 r = 1 \ldots n，为每个当前 r 学会快速找最优 l，使子段 [l; r] 上达到最大和。

形式化地说，对当前 r 要找不超过 r 的 l，使 s[r] - s[l-1] 最大。平凡变换后，要在 s[] 数组的 [0;r-1] 区间找最小值。

由此立得解：只需存 s[] 中当前最小值的位置。用这个最小值在 O(1) 内找当前最优 l；从当前 r 转到下一个时更新最小值。

显然这个算法运行在 $O(n)$ 且渐近最优。

实现
实现时甚至不必显式存部分和数组 s[]——只需它的当前元素。

实现用 0 下标数组（上面描述用 1 下标）。

先给只求数值答案、不找区间下标的解：

int ans = a[0],
	sum = 0,
	min_sum = 0;
for (int r=0; r<n; ++r) {
	sum += a[r];
	ans = max (ans, sum - min_sum);
	min_sum = min (min_sum, sum);
}
再给同时找区间边界的完整解：

int ans = a[0],
	ans_l = 0,
	ans_r = 0,
	sum = 0,
	min_sum = 0,
	min_pos = -1;
for (int r=0; r<n; ++r) {
	sum += a[r];
 
	int cur = sum - min_sum;
	if (cur > ans) {
		ans = cur;
		ans_l = min_pos + 1;
		ans_r = r;
	}
 
	if (sum < min_sum) {
		min_sum = sum;
		min_pos = r;
	}
}
算法 2
这里看另一个算法。它稍难理解，但比上面优雅、实现稍短。由 Jay Kadane 于 1984 年提出。

算法描述
算法如下。沿数组走，在变量 s 中累积当前部分和。若某时刻 s 为负，就赋 s=0。断言：运行期间 s 出现过的最大值就是答案。

证明这个算法。

考虑 s 首次为负的时刻。这意味着从零部分和出发，最终到负部分和——因此整个这段数组前缀、连同其任何后缀都有负和。于是这个数组前缀此后毫无用处：它只能给答案负贡献。

但这不足以证明算法。算法中我们实际把答案搜索限制在 s<0 发生位置紧后开始的区间。

但确实，考虑任意区间 [l;r]，其中 l 不在这种「关键」位置（即 l > p+1，p 是最近一次 s<0 的位置）。由于最近的关键位置严格早于 l-1，得 a[p+1 \ldots l-1] 的和非负。这意味着把 l 移到 p+1 会增大答案或至少不变。

总之，搜索答案确实只需考虑紧接 s<0 位置之后开始的区间。这证明算法正确。

实现
与算法 1 一样，先给只求数值答案的简化实现：

int ans = a[0],
	sum = 0;
for (int r=0; r<n; ++r) {
	sum += a[r];
	ans = max (ans, sum);
	sum = max (sum, 0);
}
带边界下标的完整解：

int ans = a[0],
	ans_l = 0,
	ans_r = 0,
	sum = 0,
	minus_pos = -1;
for (int r=0; r<n; ++r) {
	sum += a[r];
 
	if (sum > ans) {
		ans = sum;
		ans_l = minus_pos + 1;
		ans_r = r;
	}
 
	if (sum < 0) {
		sum = 0;
		minus_pos = r;
	}
}
相关题
带约束的最大/最小子段
若对所求区间 [l;r] 有额外约束（例如长度 r-l+1 须在某给定范围），上述算法大多容易推广——无论如何，问题仍是「在给定额外约束下找 s[] 数组中的最小值」。

二维情形：最大/最小子矩阵
本文的问题自然推广到更高维。例如二维情形变成：在给定矩阵中找数和最大的子矩阵 [l_1 \ldots r_1; l_2 \ldots r_2]。

由上面一维解容易得到 $O(n^3)$ 解：枚举 l_1 和 r_1，算矩阵每行从 l_1 到 r_1 的和数组；就回到一维的找 l_2 与 r_2 下标问题，可线性解决。

更快的算法虽已知，但不比 $O(n^3)$ 快多少，且相当复杂（复杂到按隐藏常数，许多算法在所有合理限制下都不如平凡算法）。据信最好已知算法运行在 $O \left( n^3 \frac{ \log^3 \log n }{ \log^2 n} \right)$（T. Chan 2007 "More algorithms for all-pairs shortest paths in weighted graphs"）。

Chan 算法及该领域许多其他结果实际上描述快速矩阵乘法（其中乘法经修改：用最小值代替加法、用加法代替乘法）。因为最大和子矩阵问题可归结为全对最短路问题，后者又归结为这种矩阵乘法。

最大/最小平均和子段
此题要找使平均值最大的区间 [l;r]：

 \max_{l \le r} \frac{ 1 }{ r-l+1 } \sum_{i=l}^{r}[...]

当然，若对区间 [l;r] 无其他约束，答案总是数组最大点处的长度 1 区间。只有存在额外约束（例如区间长度有下界）时问题才有意义。

此时应用处理平均问题的标准技巧：二分查找所求最大平均值。

为此要会解子问题：给数 x，判断 a[] 中是否有（满足所有额外约束的）子段，使平均值大于 x。

解子问题：把 a[] 每个元素减 x。子问题就变成：该数组中是否存在正和子段。这个已会解。

于是得到复杂度 O (T(n) \log W)，W 是所需精度，T(n) 是解长度为 n 数组子问题的时间（依具体额外约束而定）。

在线解
题意：给 n 个数的数组和数 L。来查询 (l,r)，回答区间 [l;r] 中长度至少 L、平均算术和尽可能大的子段。

此算法相当复杂。作者 KADR（Yaroslav Tverdokhleb）在论坛帖中描述了这个算法。
