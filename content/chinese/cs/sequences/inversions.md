**定义。** 排列 $p$ 中的*逆序*指一对下标 $i$ 和 $j$，满足 $i < j$ 且 $p_i > p_j$。

例如：

- 排列 $[1, 2, 3]$ 没有逆序，
- $[1, 3, 2]$ 有一个逆序（$3 \leftrightarrow 2$），
- $[3, 2, 1]$ 有三个逆序（$3 \leftrightarrow 2$、$3 \leftrightarrow 1$ 和 $2 \leftrightarrow 1$）。

本文讨论如何求排列中逆序的数量。这个问题可以朴素地在 $O(n^2)$ 内解决：枚举所有下标对，逐一检查是否为逆序：

```cpp
int count_inversions(int *p, int n) {
    int res = 0;
    for (int i = 0; i < n; i++)
        for (int j = i + 1; j < n; j++)
            if (p[i] > p[j])
                res++;
    return res;
}
```

更快地解决它更难。

## 归并排序法

出人意料的是，这个问题可以用略微改造的归并排序解决。

沿用同样的思路：设我们能在大小为 $n$ 的数组里求逆序数，就能学会在大小为 $2n$ 的数组里求。

如果我们对两半递归调用，就已经分别知道左半和右半数组里的逆序数。剩下只需数「一个数在左半、另一个在右半」的逆序个数。

仔细看左右两半的合并操作。第一个指针指向左半的元素，第二个指针指向右半的元素，我们看较小的那个并把对应指针右移。

考虑左半的数 $x$。它参与了多少个跨两半的逆序？等于右半中比它小的数的个数。我们知道这个数吗？知道！恰好在我们把 $x$ 写入合并数组的那一刻——第二个指针正指向右半中第一个比 $x$ 大的数。因此当我们从左半加入数 $A$ 时，只需把第二个指针相对于右半起点的下标加到答案上。这样我们就统计了所有跨两半的逆序。

## 区间和结构法

再想想逆序的定义：它是一对下标 $i$ 和 $j$，满足 $i < j$ 且 $p_i > p_j$。

把下标和它们的 $p_i$ 画到二维平面上。对固定点 $(i, p_i)$，$(j, p_j)$ 的条件几何上长什么样？

它是一个矩形，包含所有第一坐标更大、第二坐标更小的点。

于是我们可以取[某个结构](/cs/range-queries/segment-tree)支持单点加与前缀和，应用扫描线方法：从末尾开始遍历所有元素 $i$，在单元 $p_i$ 上加一，再用前缀和 $p_i$ 求所有合适的 $j$ 之和——所有已计入的点 $p_j$ 都更小，因为这是前缀；而 $j$ 更大，因为我们从右往左遍历——把它加到答案上。

> 求 $n$ 个元素的排列中逆序的个数（逆序指满足 $p_i > p_j$ 的一对数 $i < j$）。

这个问题只要会手写归并排序就很容易。但我们走另一条路。建一棵 $n$ 个元素、初始全零的求和线段树。现在从左到右遍历数组。处理到某个数 $x$ 时做两件事：

* 在线段树里查询从 $k$ 到 $n$ 的和。
* 在线段树第 $k$ 个位置加一。

这样每个逆序都会在查询它的右元素的求和时被计入。于是我们用 $O(n \log n)$ 个查询解决了问题。
