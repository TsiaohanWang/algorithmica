比前缀函数稍容易理解的另一种选择是 z 函数。

字符串 $s$ 的 z 函数定义为数组 $z$，其中 $z_i$ 等于从第 $i$ 个位置**开始**、且等于 $s$ 前缀的最长子串的长度。

$$
\underbrace{aba}c\overbrace{aba}daba \hspace{1em} (z_4 = 3)
$$

它的朴素实现甚至更简单：

```c++
vector<int> slow_z_function(string s) {
    int n = (int) s.size();
    vector<int> z(n, 0); // z[0] 认为未定义
    for (int i = 1; i < n; i++)
        // 如果没有越界且后续字符相同
        while (i + z[i] < n && s[z[i]] == s[i + z[i]])
            z[i]++;
    return z;
}
```

```bash
aaaaa
04321

abcdef
000000

abacabadaba
00103010301
```

z 函数可以在 KMP 算法中代替前缀函数——只是现在需要的位置从 $|s|$ 处开始，而不是结束。剩下只需学会在 $O(n)$ 内求它。

### 如何快速计算

我们从左到右遍历，维护一个 *z-块*——我们所发现的最右边的、等于前缀的子串。用 $l$ 和 $r$（含）表示它的边界。

设我们现在想求 $z_i$，之前的所有都已求出。新的第 $i$ 个字符可能位于 z-块右侧，或位于其内部：

* 如果在右侧，就直接用朴素枚举求 $z_i$（从 $s_i$ 开始、等于前缀的最大段），并把它声明为新的 z-块。
* 如果第 $i$ 个元素在 z-块内部，我们可以看 $z_{i-l}$ 的值，用它来把 $z_i$ 初始化为可能非零的某个值。如果 $z_{i-l}$ 在 z-块右边界左侧，则 $z_i = z_{i-l}$——$z_i$ 不可能更大。如果它顶到边界，就把它「截断」到边界，再逐个增加。

```c++
vector<int> z_function(string s) {
    int n = (int) s.size();
    vector<int> z(n, 0);
    int l = 0, r = 0;
    for (int i = 1; i < n; i++) {
        // 如果我们已经见过这个字符
        if (i <= r)
            // 那可以尝试把它初始化为 z[i - l]，
            // 但不超过右边界：那边我们已经什么都不知道了
            z[i] = min(r - i + 1, z[i - l]);
        // 之后每次成功增加 z[i] 都会把 z-块右移一位
        while (i + z[i] < n && s[z[i]] == s[i + z[i]])
            z[i]++;
        // 检查我们是否在当前 z-块右侧
        if (i + z[i] - 1 > r) {
            r = i + z[i] - 1;
            l = i;
        }
    }
    return z;
}
```

**复杂度**。 在算法中我们做的操作次数等于 z-块右边界移动的次数——这是 $O(n)$。

### 比较

总体上 z 函数和前缀函数非常相似，但 KMP 算法出现在所有经典编程教科书里，而 z 函数除了算法竞赛选手外不知为什么很少有人知道。

关于前缀函数还值得知道的一点是它是线上的（online）——只需读入下一个字符，马上就能知道值。

**练习 1**。 给定前缀函数数组，未给原字符串。在 $O(n)$ 内计算这个字符串的 z 函数。

**练习 2**。 给定 z 函数数组，未给原字符串。在 $O(n)$ 内计算这个字符串的前缀函数。
