模拟退火算法（英文 *simulated annealing*）是一种用于全局优化的启发式算法，在解决离散和组合问题时尤其有效。

该算法灵感来源于冶金中的[退火](https://ru.wikipedia.org/wiki/%D0%9E%D1%82%D0%B6%D0%B8%D0%B3)工艺——通过加热并逐渐冷却金属来增加其结晶度、减少缺陷。在枚举类问题中，模拟退火可用于近似求解具有大量自由变量的函数的全局最小值。

![使用模拟退火最大化单变量函数](../img/annealing.gif)

该算法是概率性的，几乎不提供任何收敛保证，但在求解 NP 完全问题方面实践中表现很好。有时在比赛中还能用它通过一些本有正规解法的复杂组合题：例如，伊尔达尔·盖努林（Ильдар Гайнуллин）在八年级时曾用[模拟退火](http://codeforces.com/contest/745/submission/23067030)通过了 div2E，而那题的标解是基于子集动态规划的。

## 算法总体描述

以一个具体例子为例，我们考虑旅行商问题：

> 有 $n$ 个城市，彼此之间有道路相连。需要规划一条经过每个城市恰好一次的最短闭合路线。

设我们有一个关于*状态* $x$ 的函数 $f(x)$，并希望*最小化*它。本例中 $x$ 是顶点（城市）的访问顺序排列，而 $f(x)$ 是对应路线的长度。

取某个状态 $x_0$ 作为基础解，然后尝试改进它。本例中，我们可以取一个随机排列作为初始路线。

引入*温度* $t$——某个实数，初始值为 1，它会在优化过程中变化并影响跳到相邻状态的概率。

在到达最优解或时间耗尽之前，重复以下步骤：

1. 按某个公式 $T$ 降低温度 $t_{k} = T(t_{k-1})$。
2. 选择一个随机的*邻居* $x$：即通过某个小改动从 $x$ 得到的某个状态 $y$。
3. 以概率 $p(f(x), f(y), t_k)$ 执行赋值 $x \leftarrow y$，否则保持 $x$ 不变。

每一步的实现都有很多自由度。主要的启发式考虑如下：

1. 优化开始时我们的解本来就很差，可以承受较高的温度和跳入更差状态的风险。临近结束时则相反——解已接近最优，我们不想失去已有进展。温度在开始时应该较高，结束时缓慢降低。

2. 如果函数 $f(x)$ 相对于这种改动是“光滑”的，即变化不大，算法会工作得更好。

3. 当新状态比旧状态更差时，概率应该更小。同时，温度越高，概率应该越大。

例如，在旅行商问题中可以这样做：

1. $t_k = \gamma \cdot t_{k-1}$，其中 $\gamma$ 是某个接近 1 的数（例如 $0.99$）。它应该取决于计划迭代次数：低温下的优化几乎不会改变什么。

2. 在排列的情形下，这种最小改动可以是例如交换两个随机元素。

3. 如果 $y$ 不比 $x$ 差，即 $f(y) \leq f(x)$，则无论如何都跳过去。否则以概率 $p = e^\frac{f(x)-f(y)}{t_k}$ 跳到 $y$——这是负数的指数，给出的概率落在 $(0, 1)$ 区间内。

但必须认识到，在具体启发式的选择上并不存在“黄金法则”：算法的所有组成部分相互之间以及和具体问题都密切相关。

## 实现

在实践中，我们把算法应用于另一个问题：

> 给定 $n \times n$ 的国际象棋棋盘和 $n$ 个皇后。要求放置它们，使它们互不攻击。

我们同样用 0 到 $(n-1)$ 的排列来编码状态：编号 $i$ 的皇后放在第 $i$ 行与第 $p_i$ 列的交点上。

这种表示并未编码所有可能的放置方式，但这反而是好事：那些皇后在竖直或水平方向上互相攻击的放置方式肯定不会出现。

选择函数 $f(p)$ 为成功放置的皇后数量。

大致等价的 C++ 代码：

```c++
const int n = 100;  // размер доски
const int k = 1000; // количество итераций алгоритма

int f(vector<int> &p) {
    int s = 0;
    for (int i = 0; i < n; i++) {
        int d = 1;
        for (int j = 0; j < i; j++)
            if (abs(i - j) == abs(p[i] - p[j]))
                d = 0;
        s += d;
    }
    return s;
}

// генерирует действительное число от 0 до 1
double rnd() { return double(rand()) / RAND_MAX; }

int main() {
    // генерируем начальную перестановку
    vector<int> v(n);
    iota(v.begin(), v.end(), 0);
    shuffle(v.begin(), v.end());
    int ans = f(v); // текущий лучший ответ 

    double t = 1;
    for (int i = 0; i < k && ans < n; i++) {
        t *= 0.99;
        vector<int> u = v;
        swap(u[rand() % n], u[rand() % n]);
        int val = f(u);
        if (val > ans || rnd() < exp((val - ans) / t)) {
            v = u;
            ans = val;
        }
    }

    for (int x : v)
        cout << x + 1 << " ";

    return 0;
}
```

这里统计空闲对角线数量需要 $O(n^2)$ 时间。可以优化到 $O(n)$，从而多进行 $O(n)$ 倍的迭代：可以建立一个布尔数组，记录每条对角线是否已被占用。有了这个优化，[informatics 上的这道题](https://informatics.mccme.ru/mod/statements/view.php?id=1975)应该就能通过了。

**练习题。**把重算优化到 $O(1)$。
