*贪心*算法是一类在每个阶段都做出局部最优决策的算法。由于计算局部最优解比计算全局最优解容易得多，这类算法通常具有很好的复杂度。

在某些情况下，贪心算法能得到最优的最终解，而在另一些情况下则不能。设计出贪心算法，尤其是证明其正确性，往往非常困难。

本文将分析几个用贪心算法解决的经典问题。

### 硬币问题

**问题**。某国的硬币体系由面值 $a_1 = 1 < a_2 < a_3 < \ldots < a_n$ 的硬币组成，且每个后面的面值都能被前面的面值整除。要求用尽可能少的硬币凑出金额 $S$。

解决该问题的贪心算法是：先取尽可能多的 $a_n$ 面值硬币（即 $\lfloor \frac{S}{a_n} \rfloor$ 枚），然后对剩余金额取尽可能多的 $a_{n-1}$ 面值硬币，依此类推。由于 $a_1 = 1$，最后总能凑出所需的金额。

```python
a = [1, 2, 5, 10, 50, 100, 500, 1000, 2000, 5000]

def solution(s):
    coins = []
    for x in reversed(a):
        coins += [x] * (s // x)
        s %= x
    return coins
```

注意，如果没有硬币面值相互整除这一假设，该算法并不总能输出最优解，此时就只能用动态规划来解。例如，用 1、5、7 卢布的硬币凑 24 卢布，贪心算法会拆成 $(7 \times 3 + 1 \times 3)$，而最优解是 $(7 \times 2 + 5 \times 2)$。

**正确性**。用反证法证明贪心算法的正确性：设最大面值硬币为 $a_n < S$，但最优解中并没有使用它。

设最优解中面值 $a_i$ 的硬币出现 $b_i$ 次：

$$
S = \sum a_i \cdot b_i
$$

如果 $b_i \geq \frac{a_{i+1}}{a_i}$，那么 $\frac{a_{i+1}}{a_i}$ 枚这种硬币可以换成 1 枚面值 $a_{i+1}$ 的硬币，因此这不是最优解。所以 $b_i \leq \frac{a_{i+1}}{a_i} - 1$。

现在计算，如果不使用最大面值硬币，最优解中所有硬币面值的总和最大能是多少：

$$
\begin{aligned}
  S &= a_1 \cdot b_1 + a_2 \cdot b_2 + \ldots + a_{n-1} \cdot b_{n-1}
\\  &\leq a_1 \cdot (\frac{a_2}{a_1} - 1) + a_2 \cdot (\frac{a_3}{a_2} - 1) + \ldots + a_{n-1} \cdot (\frac{a_n}{a_{n-1}} - 1)
\\  &= (a_2  - a_1) + (a_3 - a_2) + \ldots + (a_n - a_{n-1})
\\  &= a_n - a_1 < a_n
\end{aligned}
$$

由此得出结论：如果 $S \geq a_n$，那么最优解中必然要取最大面值的硬币 $a_k$，因为所有更小的硬币根本无法在最优解中提供这么大的金额。对更小硬币组成的集合做同样的推理，对所有的 $S < a_n$ 也能得到相同的结果，由此即可证明贪心算法的正确性。

另外，该算法不仅适用于相互整除的面值，也适用于某些其他体系。贪心算法有效的这类硬币体系被称为*规范体系*。

**练习题**。该算法对俄罗斯硬币体系（1、2、5……）是否正确？

### 可分割物品的背包

**问题**。有一个容量不超过 $W$ 克的背包和 $n$ 件物品，每件物品重 $w_i$ 克、每克价值为 $c_i$。我们可以从任意物品上切下整数克。要求装满背包且总价值最大。

按“价值密度” $\frac{c_i}{w_i}$ 降序排列物品，并按此顺序贪心地装入。对最后一件无法完整放入的物品，取其中一部分。

**正确性**。把每件物品想象成切成 $w_i$ 个 1 克的小块，此时每个小块的单价为 $\frac{c_i}{w_i}$。显然，对于重量同为 1 克的小块，最优做法就是直接取单价最高的那些小块，这正是我们的算法所做的。

总复杂度为排序的 $O(n \log n)$。

### 活动选择

**问题**。给定在某教室开展活动的申请。每份申请给出活动的开始时间 $l_i$ 和结束时间 $r_i$。需要从所有申请中保留尽可能多的活动，使它们互不重叠。

这里的贪心就不再那么明显了，因为不清楚应按什么顺序考察申请，以及如何“贪心地”选取它们。

考察*结束时间最早*的那份申请。注意，把它选入最优解总是划算的——它比所有其他活动结束得都早，因此如果最优解中的第一份活动是别的活动，我们可以无痛地把它替换成结束时间最早的那份，而且不会产生新的重叠，因为我们只是把最靠前的活动又往左移了一些。

选择结束时间最早的活动后，删去与它重叠的所有活动，然后在剩余活动中再选择结束时间最早的，再删去所有与之重叠的，如此重复直到没有活动为止。

实现时不必显式删除区间，只需按结束时间排序所有区间，并维护已选最后一个活动的结束时刻。

```cpp
struct activity {
    int l, r;
};

int solve(vector<activity> activities) {
    sort(activities.begin(), activities.end(), [](activity a, activity b) {
        return a.r < b.r;
    });
    int cnt = 0, last = 0;
    for (activity a : activities)
        if (a.l >= last)
            last = a.r, cnt++;
    return cnt;
}
```

复杂度为排序的 $O(n \log n)$。
