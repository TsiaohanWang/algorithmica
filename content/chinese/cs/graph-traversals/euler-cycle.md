**定义.** *欧拉路径*是经过图中所有边的路径。

**定义.** *欧拉回路*是作为环的欧拉路径。

为简单起见，两种情况都假设图是无向的。

![具有五个顶点的图及其一个欧拉回路：CDCBBADEBC](../img/euler-small.png)

此外还有*哈密顿*路径和回路的概念——它们恰好访问所有*顶点*一次，而不是边。求哈密顿回路（*旅行商问题*，英文 *travelling salesman problem*）是最著名的 NP 完全问题之一，而求欧拉回路可以在线性时间内解决，我们现在就来展示怎么做。

### 求欧拉回路

**定理.** 欧拉回路存在当且仅当图连通且所有顶点的度都是偶数。

**证明.** 必要性可以这样说明：直接取一个欧拉回路，并沿遍历顺序给它的所有边定向。那么从每个顶点出去的边数和进入的边数相等，因此原无向图所有顶点的度都是偶数。

充分性用构造法证明——给出求回路的算法：

```c++
void euler(int v) {
    while (!g[v].empty()) {
        u = *g[v].begin(); // берем любое ребро
        remove_edge(v, u); // удаляем его
        euler(u);            // запускаемся от противоположного конца
    }
    cout << v <<  " ";     // выписываем текущую вершину
}
```

注意：

- 输出的序列恰好包含 $(m + 1)$ 个顶点，
- 每对相邻的输出顶点之间都有一条边，
- 每条边恰好被输出一次。

因此，如果连通性和度数奇偶性的条件满足，那么输出的顶点序列就确实是欧拉回路，对于有向图也同样成立。

### 如何删除边

最简单的方法是把所有邻接表存储在类似 `set` 的结构中，直接在里面删除：

```c++
const int maxn = 1e5;
set<int> g[maxn];

void euler(int v) {
    while (!g[v].empty()) {
        u = *g[v].begin();
        g[v].erase(u);
        g[u].erase(v); // если граф ориентированный, обратное ребро удалять не надо
        euler(u);
    }
    cout << v <<  " ";
}
```

这样复杂度为 $O(m \log n)$，不过只要把平衡树换成哈希表（`unordered_set`），时间就能降到线性。

还可以用更通用的方法，它常用于边会发生某种变化的题目中。创建一个单独保存边元信息的数组，并在邻接表中不存顶点编号，而存边的编号：

```cpp
struct edge {
    int to;
    bool deleted;
};

vector<edge> edges;
stack<int> g[maxn];

void add_edge(int u, int v) {
    g[u].push(edges.size());
    edges.add({v, false});
    g[u].push(edges.size());
    edges.add({u, false});
}
```

如果通过 `add_edge` 添加无向图的每条边，那么得到的边编号会有一个有趣的性质：要得到边 `e` 的反向边，只需计算 `e^1`。这样在遍历时就可以维护这份信息，而无需对结构做复杂的修改：

```cpp
void euler(int v) {
    while (!g[v].empty()) {
        e = g[v].top();
        g[v].pop();
        if (!edges[e].deleted) {
            edges[e].deleted = edges[e^1].deleted = true;
            euler(e.to);
        }
    }
    cout << v <<  " ";
}
```

在所有实现版本中，当图里有自环和重边时都需要稍微小心一些。

### 欧拉路径

现在来谈谈欧拉*路径*。如果并非所有顶点的度都是偶数，是不是还是可以做点什么？

注意，由于每条边恰好改变两个顶点的度数奇偶性，而空图中所有度初始都为 0，所以度数为奇数的顶点个数一定是偶数。

如果恰好有两个度数为奇数的顶点，可以这样做：用一条边把它们连起来，构造欧拉回路（现在所有顶点的度都是偶数了），然后从回路中删掉这条边。如果恰当地旋转这个回路，就能得到欧拉路径。

或者，直接从其中一个度数为奇数的顶点启动遍历，也能得到同样的结果。

如果度数为奇数的顶点多于两个，就无法构造欧拉路径了，因为任何欧拉路径进入或离开每个顶点的次数都是偶数，除了（可能存在的）两个端点。

**推论.** 欧拉路径存在当且仅当图连通且度数为奇数的顶点数不超过 2。

**练习题.** 给定一个连通无向图，要求用最少数量的互不相交的路径覆盖它的所有边。复杂度 $O(n + m)$。

**练习题.** 请为有向图的情形表述并证明类似的结论。
