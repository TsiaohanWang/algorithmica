---
title: 求连通分量
weight: 3
---

无向图的*连通分量*是从某个给定顶点可达的顶点子集。由于图是无向的，连通分量中的所有顶点都彼此可达。

![具有两个连通分量的图](../img/disconnected.png)

给定一个具有 $n$ 个顶点和 $m$ 条边的无向图 $G$，要求找出它的所有连通分量，即把图的顶点分成若干组，使得同一组内可以从一个顶点到达任意另一个顶点，而不同组之间不存在路径。

为解决问题，我们修改深度优先遍历：从某个分量的一个顶点出发，用它所属分量的编号标记该分量的所有顶点——也就是所有可达的顶点。为此，可以用每个顶点的分量编号数组替换 `used` 数组，该数组初始全为 0：

```cpp
const int maxn = 1e5;
int component[maxn]; // тут будут номера компонент

void dfs(int v, int num) {
    component[v] = num;
    for (int u : g[v])
        if (!component[u]) // если номер не присвоен, то мы там ещё не были
            dfs(u, num);
}
```

现在执行一系列遍历：先从第一个顶点启动遍历，它遍历到的所有顶点构成第一个连通分量。然后找到第一个尚未被访问的剩余顶点，从它启动遍历，从而找到第二个连通分量。如此继续，直到所有顶点都被标记。

写出来非常简洁：

```cpp
int num = 0;
for (int v = 0; v < n; v++)
    if (!component[v])
        dfs(v, ++num);
```

此后，变量 `num` 保存连通分量的个数，而数组 `component` 保存每个顶点的分量编号，例如可以用它快速检查给定的一对顶点之间是否存在路径。

总复杂度为 $O(n + m)$，因为这样的算法不会从同一个顶点启动两次，而且每条边恰好被查看两次（从它的两端各一次）。
