图的一种正确的*双色染色*是这样的染色：没有任何一条边连接两个同色的顶点。可以进行这种染色的图称为*二分图*。

注意，如果这样的染色存在，并且固定一个顶点的颜色，那么从它可达的所有顶点的颜色就都唯一确定了：设这个顶点是白色，那么它的所有邻居都是黑色，距离为 2 的所有顶点又都是白色，距离为 3 的又是黑色，依此类推。

可以用深度优先遍历检查图是否为二分图并输出染色。这一次，我们的 `dfs` 接受一个参数：要给顶点涂的颜色，并递归地从所有邻居启动，把它们涂成相反的颜色。算法结束时，我们要么发现图不是二分图（在某个时刻看到两个相邻顶点需要被赋予同一种颜色），要么找到图顶点的一个二划分。

```cpp
const int maxn = 1e5;
int color[maxn];

void dfs(int v, int col) {
    color[v] = col;
    for (int u : g[v]) {
        if (!color[u]) {
            dfs(u, -col);
        } else if (color[u] != -col) {
            cout << "Graph is not bipartite" << endl;
            exit(0);
        }
    }
}
```

由于图可能不连通，可能需要从不同的顶点多次启动它：

```cpp
for (int v = 0; v < n; v++)
    if (!color[v])
        dfs(v, 1);
```

由于每个顶点和每条边都只查看一次，复杂度为 $O(n + m)$。

### 关于图染色的有用结论

图的*色数*是能对它进行正确染色的最少颜色数。一般情况下，求色数的问题无法在多项式时间内解决。

![任何地图都可以表示成平面图，其中国家是顶点，边界是边](../img/russia.png)

不过，关于染色可以证明一些有用的结论，例如：

- 图可以染成两种颜色——或者说，图是二分图——当且仅当它的所有简单环的长度都是偶数。
- 如果任何顶点的度都不超过 $k$，那么图可以染成 $k$ 种颜色。
- 任何平面图都可以染成 4 种颜色。

建议把前两个结论留作练习题自行证明；至于最后一个，目前人们[只会用计算机](https://neerc.ifmo.ru/wiki/index.php?title=%D0%9F%D1%80%D0%BE%D0%B1%D0%BB%D0%B5%D0%BC%D0%B0_%D1%87%D0%B5%D1%82%D1%8B%D1%80%D1%91%D1%85_%D0%BA%D1%80%D0%B0%D1%81%D0%BE%D0%BA)来证明它。
