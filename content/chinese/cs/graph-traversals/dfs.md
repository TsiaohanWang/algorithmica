**深度优先搜索**（英文 *depth-first search*，**DFS**），又称*欧拉遍历*（эйлеров обход），是一种递归遍历有根树或图的算法：从根顶点出发（对于图可以任选一个顶点），递归地遍历整个图，每个顶点恰好访问一次。

```cpp
const int maxn = 1e5;
bool used[maxn]; // тут будем отмечать посещенные вершины

void dfs(int v) {
    used[v] = true;
    for (int u : g[v])
        if (!used[u])
            dfs(u);
}
```

我们对它稍作修改：为每个顶点记录我们进入它的时刻和离开它的时刻——对应的数组记为 $tin$ 和 $tout$。

怎么填充它们：维护一个定时器，记录遍历当前状态下的“时刻”，每进入一个新顶点就把它加一：

```cpp
int tin[maxn], tout[maxn];
int t = 0; // таймер

void dfs(int v) {
    tin[v] = t++;
    for (int u : g[v])
        if (!used[u])
            dfs(u);
    tout[v] = t; // иногда счетчик тут тоже увеличивают
}
```

这两个数组有很多有用的性质：

- 顶点 $u$ 是 $v$ 的祖先 $\iff tin_v \in [tin_u, tout_u)$。这个检查可以在常数时间内完成。
- 两个半开区间 $[tin_v, tout_v)$ 和 $[tin_u, tout_u)$ 要么不相交，要么一个包含另一个。
- $tin$ 数组包含从 0 到 $(n - 1)$ 的所有数，而且每个顶点对应一个不同的编号。
- 顶点 $v$ 的子树大小（包括顶点本身）等于 $(tout_v - tin_v)$。
- 如果按 $tin$ 给顶点编号，那么任何子树的编号总是这个编号序列中的某个连续区间。

我们后面会看到，这些性质在其他遍历和各种树上的问题中都非常有用。
