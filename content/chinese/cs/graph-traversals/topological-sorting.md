图的拓扑排序问题如下：给定一个有向图，要求找出顶点的一种排列顺序，使得图中所有的边都是从排在前面的顶点指向排在后面的顶点。

这在规划有依赖关系的任务时可能很有用：比如你需要穿衣服，要按正确的顺序先穿短裤 (1)、再穿长裤 (2)、穿靴子 (3)、卷起裤脚 (4)——像潮人那样——最后系鞋带 (5)。

![](../img/sorting.png)

首先，立刻可以注意到，含环的图不可能进行拓扑排序——无论怎么把环排列在数组里，都无法沿着环的边一直向右走。

其次，反过来也成立：如果没有环，就一定能对它进行拓扑排序——现在就来展示怎么做。

注意，没有任何边引出的顶点总可以放在最后，而无环图中一定存在这样的顶点（否则就可以沿着边的反方向无限走下去）。由此立即得到构造性的证明：迭代地把没有出边的顶点放入数组，并从图中删掉它。这个过程结束后，还需要把数组反转。

这个算法用 `dfs` 中顶点的退出时间来实现更简单。我们最先退出的顶点是那个没有新的出边的顶点。之后我们只会从这样的顶点退出：它们即使有出边，也都只指向我们已经退出的顶点。

因此，只需按 `dfs` 的退出顺序列出顶点，然后把得到的列表反转，就能得到某种正确的拓扑排序。

```cpp
const int maxn = 1e5;

bool used[maxn];
vector<int> t;

void dfs(int v) {
    used[v] = true;
    for (int u : g[v])
        if (!used[u])
            dfs(u);
    t.push_back(v);
}

void topological_sort() {
    for (int v = 0; v < n; v++)
        if (!used[v])
            dfs(v);
    reverse(t.begin(), t.end());
}
```

拓扑排序可以用来检查可达性：比较顶点在所得数组中的编号。顶点 $a$ 排在顶点 $b$ 之后这一事实说明，从 $a$ 无法到达 $b$——但 $a$ 从 $b$ 出发可能是可达的，也可能是不可达的。
