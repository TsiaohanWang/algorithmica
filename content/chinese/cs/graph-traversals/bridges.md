**定义.** *桥*（мост）是这样一条边：删去它之后，连通的无向图会变得不连通。

**定义.** *割点*（точка сочленения）是这样的顶点：删去它之后，连通的无向图会变得不连通。

一个适合找出它们的示例问题：给定一个网络拓扑（计算机以及它们之间的物理连接），要求找出所有单点故障——即缺少某些节点和连接后，就会存在两个之间没有路径的节点。

逐个删除每条边 $(u, v)$ 并检查 $u \leadsto v$ 之间是否存在路径的朴素算法需要 $O(m^2)$ 次操作。为了学会更快地找桥，先来阐述几个与深度优先遍历相关的结论。

从任意顶点启动 DFS。引入两类新的边：

* *树边*（прямые рёбра）—— dfs 中沿着它们产生转移的边。

* *回边*（обратные рёбра）—— dfs 中未沿它们产生转移的边。

注意，任何回边 $(u, v)$ 都不可能是桥：即使删掉它，从 $u$ 到 $v$ 仍然存在某条路径，因为由树边构成的子图是一棵连通树。

因此，只需要检查所有树边。这已经好一点了——这样的算法复杂度为 $O(nm)$。

要把它优化到线性时间（一次 dfs 遍历），可以利用如下事实：回边只能指向“上方”——即遍历树中的某个祖先，而不能指向其他“分支”——否则 dfs 会更早看到这条边，它就会是树边而不是回边。

![](../img/bridges.png)

那么，要判断树边 $v \to u$ 是否为桥，可以用如下判据：顶点 $v$ 的深度 $h_v$ 小于所有通过回边与子树 $u$ 中某个顶点相连的顶点的最小深度。

为清晰起见，把这个量记为 $d_u$，它可以在遍历过程中按下面的公式计算：

$$
d_v = \min \begin{cases}
h_v, &\\
d_u, &\text{边 } (v \to u) \text{ 是树边} \\
h_u, &\text{边 } (v \to u) \text{ 是回边}
\end{cases}
$$

如果这个条件（$h_v < d_u$）不成立，那么就存在一条从 $u$ 到 $v$ 的某个祖先或到 $v$ 本身的路径，且不经过边 $(v, u)$；反之则不存在这样的路径。

```cpp
const int maxn = 1e5;

bool used[maxn];
int h[maxn], d[maxn];

void dfs(int v, int p = -1) {
    used[v] = true;
    d[v] = h[v] = (p == -1 ? 0 : h[p] + 1);
    for (int u : g[v]) {
        if (u != p) {
            if (used[u]) // если ребро обратное
                d[v] = min(d[v], h[u]);
            else { // если ребро прямое
                dfs(u, v);
                d[v] = min(d[v], d[u]);
                if (h[v] < d[u]) {
                    // если нельзя другим путем добраться в v или выше,
                    // то ребро (v, u) -- мост
                }
            }
        }
    }
}
```

**注.** 更广为人知的算法是用顶点的 $tin$ 而不是深度，但作者认为那样稍微难理解一些。

### 割点

割点问题与桥问题差别不大。

当从 $v$ 的某个孩子 $u$ 出发、不经过边 $(v, u)$ 就无法到达 $v$ 的祖先时，顶点 $v$ 就是割点。对具体的树边 $v \to u$，可以用 $h_v \leq d_u$ 来检查这个事实（现在不等式是不严格的，因为如果从子树只能到达 $v$ 本身，删去 $v$ 后图仍然不连通，$v$ 依旧是割点）。

利用这一点，算法几乎可以保持不变——只需对所有树边 $v \to u$ 检查这个判据：

```cpp
void dfs(int v, int p = -1) {
    used[v] = 1;
    d[v] = h[v] = (p == -1 ? 0 : h[p] + 1);
    int children = 0;
    for (int u : g[v]) {
        if (u != p) {
            if (used[u])
                d[v] = min(d[v], h[u]);
            else {
                dfs(u, v);
                d[v] = min(d[v], d[u]);
                if (h[v] <= d[u] && p != -1) { // корень (p == -1) обрабатываем отдельно
                    // v -- точка сочленения
                    // (это условие может выполниться много раз для разных детей)
                }
              	children++;
            }
        }
    }
    if (p == -1 && children > 1) {
        // v -- корень и точка сочленения
    }
}
```

唯一的边界情况是根，因为按定义我们会比别的顶点更早进入根。但这里的修正很简单——只需看它在遍历中是否有超过一个分支（如果删掉根，它的各子树之间就会彼此不连通）。
