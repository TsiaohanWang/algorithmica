之前我们学会了如何对*无环*图进行拓扑排序。但在*有环*图中，有时也需要找出某种结构，为此需要引入*强连通*的概念。

**定义.** 如果存在一条从其中一个到另一个的路径，反之亦然，则说有向图的两个顶点*强连通*（英文 *strongly connected*）。换句话说，它们都在某个环上。

显然，这种关系是传递的：如果 $a$ 和 $b$ 强连通，$b$ 和 $c$ 强连通，那么 $a$ 和 $c$ 也强连通。因此，所有顶点可以划分为*强连通分量*——顶点的一种划分：同一分量内所有顶点彼此强连通，而不同强连通分量的顶点之间不强连通。

![具有三个强连通分量的图](../img/scc.png)

强连通分量最简单的例子是环。但它也可以是完全图，或者多个环的复杂交叉。

人们经常考虑由强连通分量本身（而不是单个顶点）构成的图。显然，这样的图已经是无环的，处理起来更简单。把每个强连通分量压缩成一个顶点的问题称为图的*缩点*（конденсация），我们马上来描述它的解法。

## 图的缩点

如果已经知道每个强连通分量包含哪些顶点，那么构造缩点图并不难：需要对邻接表做一些处理，把所有边的顶点编号替换为它们所属分量的编号，然后把每个分量的所有顶点的邻接表合并起来。因此，直接把原问题归结为求出各分量本身。

**引理.** 运行 dfs。设 $A$ 和 $B$ 是两个不同的强连通分量，并且缩点图中存在从 $A$ 到 $B$ 的边 $A \to B$。那么：

$$
\max\limits_{a \in A}(tout_a) > \max\limits_{b\in B}(tout_b)
$$

**证明.** 根据 dfs 先进入哪个分量，分两种情况讨论。

设先到达分量 $A$，即在某个时刻 dfs 进入分量 $A$ 的某个顶点 $v$，此时分量 $A$ 和 $B$ 的其余顶点都尚未被访问。但由于按条件缩点图中有边 $A \to B$，从顶点 $v$ 出发不仅整个分量 $A$ 可达，整个分量 $B$ 也可达。这意味着从顶点 $v$ 启动的深度优先遍历会经过分量 $A$ 和 $B$ 的所有顶点，因此它们会成为遍历树中 $v$ 的后代，并且对任意顶点 $u \in A \cup B, u \ne v$，都有 $tout_v] > tout_u$，正如所断言的那样。

第二种情况更简单：按条件从 $B$ 无法到达 $A$，因此如果先到达 $B$，那么 dfs 会在进入 $A$ 之前就从 $B$ 的所有顶点退出。

由这个事实得到解法的第一部分。按退出时间的降序对顶点排序（相当于做一次拓扑排序，但作用在含环图上）。考虑排序中第一个顶点所在的强连通分量。这个分量中肯定没有从其他分量进来的边——否则引理的条件就会被违反，因为第一个顶点的 $tout$ 最大。因此，如果把图中的所有边反转，那么从这个顶点出发只能到达它自己的强连通分量 $C^\prime$，而不会到达别处——如果原图中没有从其他分量**出发**的边，那么在转置图中就不会有**指向**其他分量的边。

处理完第一个顶点后，可以继续沿着拓扑排序后的列表前进，对尚未标记连通分量的顶点做同样的事情。

```cpp
vector<int> g[maxn], t[maxn];
vector<int> order;
bool used[maxn];
int component[maxn];
int cnt_components = 0;

// топологическая сортировка
void dfs1(int v) {
    used[v] = true;
    for (int u : g[v]) {
        if (!used[u]) 
            dfs1(u);
    order.push_back(v);
}

// маркировка компонент сильной связности
void dfs2(int v) {
    component[v] = cnt_components;
    for (int u : t[v])
        if (component[u] == 0)
            dfs2(u);
}


// в содержательной части main:

// транспонируем граф
for (int v = 0; v < n; v++)
    for (int u : g[v])
        t[u].push_back(v);

// запускаем топологическую сортировку
for (int i = 0; i < n; i++)
    if (!used[i])
        dfs1(i);

// выделяем компоненты
reverse(order.begin(), order.end());
for (int v : order)
    if (component[v] == 0)
        dfs2(v), cnt_components++;
```

TL;DR:

1. 按退出时间降序对顶点排序。
2. 按这个顺序遍历顶点数组，对尚未标记的顶点在转置图上运行 dfs，把所有可达顶点标记为新的连通分量的编号。

之后，连通分量的编号就是按拓扑序排列的。
