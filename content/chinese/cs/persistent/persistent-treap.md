与线段树一样，用可持久化的 treap（笛卡尔树）可以解决一些有趣的题目——尤其常与字符串相关。先看几个例子，再转向实现。

### 例题

**题目**。 给定一个字符串。需要支持在任意位置的复制、删除和插入。

在字符上建一棵可持久化 treap。那么只需调用两次 `split`，就能得到任意子串的副本（指向某顶点的指针），之后可以插入到任意位置，同时不修改原始子串。

**题目**。 给定一个字符串。需要支持在任意位置的复制、删除、插入*以及任意两个子串的比较*。

可以在顶点里存对应子串的[多项式哈希](/cs/hashing/polynomial)。那么可以用比较两次 split 得到的顶点哈希来检查子串是否相等。

要比较字符串大小而不是仅相等，可以用标准的二分查找技巧：枚举重合后缀的长度，找到后看下一个字符。

**题目**。 给——你猜——字符串。需要支持同样的修改操作，并在每次查询后找出字符串的最小*周期*，即最小的数 $k$，使由长度为 $k$ 的前缀重复 $\frac{n}{k}$ 次得到整个字符串。

先学会用建好的树检查 $k$ 是否是周期（某个周期，不一定要最小）。取出前 $k$ 个字符，算它们的多项式哈希 $h_k$，以及整个字符串的哈希 $h$。如果整个字符串只是前缀 $k$ 的 $\frac{n}{k}$ 份副本连在一起，那么它的哈希应等于：

$$
h = h_k + h_k \cdot p^k + h_k \cdot p^{2k} + \ldots + h_k \cdot p^{n-k}
$$

于是可以在 $O(\log n)$ 内做检查——用提取或下降求出长度为 $k$ 的前缀哈希。

现在可以枚举 $n$ 的各个因数 $k$ 作为候选，对每个在对数时间内检查。还能更快：注意如果 $p$ 是某周期的因数，那么 $\frac{n}{p}$ 也是周期。可以看 $n$ 的分解，这种检查每次去掉一个质因子，直到只剩最小周期的分解。

由于 $n$ 的分解中至多有 $O(\log n)$ 个因子，这个解法每次查询运行在 $O(\log^2 n)$（不计分解——如果对字符串长度有合理限制，可以预计算）。

### 实现

实现与所有基于引用的可持久化结构几乎一样——进入某个顶点前，先创建它的副本并进入副本。为此建一个辅助函数 `copy`：

```c++
Node* copy(Node *v) { return new Node(*v); }
```

在所有方法中，我们都从复制其中提到的所有顶点开始。例如，可持久化 `split` 这样开头：

```c++
Pair split(Node *p, int x) {
    p = copy(p);
    // ...
}
```

在线段树中，只复制顶点就够了——对确定性数据结构通常足够——但 treap 更复杂。

存在一个「击穿」优先级的测试：可以复制同一个顶点的许多版本，而删掉其余所有。于是所有顶点优先级相同，树变成「竹竿」，所有操作运行在 $O(n)$。

这个问题有非常优雅的解法——去掉优先级，做如下重挂：如果左树大小为 $L$、右树大小为 $R$，则以概率 $\frac{L}{L+R}$ 挂到左侧，否则挂到右侧。

**定理**。 这种重挂等价于优先级。

**证明**。 证明所有顶点仍然等概率地成为根。用归纳法：

- 叶子以概率 1 成为自己的根（归纳基础）。
- 归纳递推——`merge` 操作。左树中的任意顶点以概率 $\frac{1}{L}$ 成为其根（由归纳假设），合并后它以概率 $\frac{1}{L} \cdot \frac{L}{L+R} = \frac{1}{L+R}$ 成为整棵树的根。右树的顶点类似。

于是这种重挂下，任何子树的每个顶点仍然等可能地成为它的根，而这正是 treap 复杂度证明的基础。

```c++
Node* merge(Node *l, Node *r) {
    if (!l) return r;
    if (!r) return l;
    l = copy(l), r = copy(r);
    if (rand() % (size(l) + size(r)) < size(l)) {
        // ...
    }
    else {
        // ...
    }
}
```

一个哲学问题：如果从 treap 中既去掉 $x$ 又去掉 $y$，它还能叫 treap（笛卡尔树）吗？
