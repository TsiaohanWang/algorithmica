Pollard 的 rho 算法是一种随机化的整数分解算法，运行在 $O(n^\frac{1}{4})$，基于生日悖论的一个推论：

> 需要往多重集中加入 $O(\sqrt{n})$ 个从 1 到 $n$ 的随机数，才会出现两个相同的数。

## Pollard 的 $\rho$ 算法

我们想分解数 $n$。假设 $n = p q$ 且 $p \approx q$。显然这大概是最难的情况。算法迭代地找最小因数，从而把问题归结为至少缩小一半的子问题。

取如下函数：

$$
f(x) = (x+1)^2 \bmod n
$$

算法需要的一个性质是：从数论角度看，这个函数「足够随机」。后面还会回到它。

**定义**。 从每个顶点出发恰好有一条边 $x \to f(x)$ 的图称为*函数图*。

如果在函数图里画出任意元素的「轨迹」，得到的是一条变成环的路径。

![每个元素的轨迹看起来像字母 $\rho$（rho）。算法因此得名。](../img/rho.jpg)

考虑某个元素 $x_0$ 的轨迹：{$x_0$, $f(x_0)$, $f(f(x_0))$, $\ldots$}。从它造一个新的序列，心算地把每个元素取模 $p$——$n$ 的两个质因数中较小的那个。

**命题**。 这个序列中循环的期望长度是 $O(\sqrt[4]{n})$。

*证明*：由于 $p$ 是较小的因数，$p \leq \sqrt n$。现在直接代入生日悖论的推论：需要往集合中加入 $O(\sqrt{p}) = O(\sqrt[4]{n})$ 个元素才会出现两个相同，也就是序列发生了循环。

如果在这样的序列里找到循环，即存在 $i$ 和 $j$ 使

$$
f^i(x_0) \equiv f^j(x_0) \pmod p
$$

那么我们就能找到 $n$ 的某个因数，即

$$
d = \gcd(|f^i(x_0) - f^j(x_0)|, n)
$$

这个数小于 $n$ 且被 $p$ 整除，因此应等于 $p$。

算法本质上用标准的「龟兔赛跑」算法找这个序列的循环：维护两个距离越来越大的指针 $j$ 和 $i = 2j$，检查 $f^i(x_0) \equiv f^j(x_0)$，等价于检查

$$
\gcd(|f^i(x_0) - f^j(x_0)|, n) \not \in \{ 1, n \}
$$

一个简单但不那么可靠的实现：

```c++
typedef long long ll;

inline ll f(ll x, ll n) { return (__int128_t) (x + 1) * (x + 1) % n; }

ll find_divisor(ll n, ll seed = 1) {
    ll x = seed, y = seed;
    ll d = 1;
    while (d == 1 || d == n) {
        // 第一个指针走一步
        y = f(y);
        // 第二个走两步
        x = f(f(x));
        // 尝试找公因数
        d = gcd(abs(x - y), n);
    }
    return d;
}
```

由于算法是随机的，完整实现时要考虑各种细节。例如，有时找不到因数（需要多跑几次），或者尝试分解质数时会运行 $O(\sqrt n)$（需要加素性测试或按时间截断）。

这个实现的复杂度是 $O(\sqrt[4]{n} \log n)$，因为每次迭代都要用 $O(\log n)$ 求 $\gcd$。可以用下面的技巧去掉对数：声明常数 $M = \Theta(\log n)$，对 $M$ 次连续迭代维护乘积 $P = \prod |f^i(x_0) - f^j(x_0)|$ 模 $n$ 的值，不每步都求 $\gcd$，而是每 $M$ 次迭代求一次 $\gcd(P, n)$。

当我们遇到因数时，它会进入乘积，且至多再过 $M = \Theta(\log n)$ 步就能在乘积的 $\gcd$ 里找到它。由于现在只需每 $\Theta(\log n)$ 步用 $O(\log n)$ 求一次 $\gcd$，对数就从复杂度中消失了。

### 备注

大数分解在密码学语境下很有意义——例如 RSA 算法就依赖于「无法在线性时间内分解」的假设。

还存在[亚指数](https://ru.wikipedia.org/wiki/%D0%A4%D0%B0%D0%BA%D1%82%D0%BE%D1%80%D0%B8%D0%B7%D0%B0%D1%86%D0%B8%D1%8F_%D1%86%D0%B5%D0%BB%D1%8B%D1%85_%D1%87%D0%B8%D1%81%D0%B5%D0%BB#%D0%A1%D1%83%D0%B1%D1%8D%D0%BA%D1%81%D0%BF%D0%BE%D0%BD%D0%B5%D0%BD%D1%86%D0%B8%D0%B0%D0%BB%D1%8C%D0%BD%D1%8B%D0%B5_%D0%B0%D0%BB%D0%B3%D0%BE%D1%80%D0%B8%D1%82%D0%BC%D1%8B)但不是多项式的分解算法。人类[已经能够](https://en.wikipedia.org/wiki/Integer_factorization_records)分解量级达 $10^{250}$ 的数。

[Shor 算法](https://en.wikipedia.org/wiki/Shor%27s_algorithm)能在量子计算机上多项式时间内分解数。但截至 2019 年，所有量子计算都更容易在普通计算机上模拟。在真实量子计算机上分解的最大数是 4088459。
