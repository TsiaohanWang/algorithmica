## 在 $O(\\sqrt{N})$ 内检验素性

$N$ ——我们要判断是否为质数的数。

### 基本概念

建议先读[质数](Простое_число "wikilink")一文。

### 在 $O(N)$ 内检验素性

线性检验非常简单——只需枚举从 2 到 $N - 1$ 的所有数，检查 $N$ 是否被它们中任何一个整除。$N = 1$ 的情况单独处理。

``` C++
bool isPrime(int n) {
    if (n == 1) {
        return false;
    }
    for (int i = 2; i < n; i++) {
        if (n % i == 0) {
            return false;
        }
    }
    return true;
}
```

### 加速到 $O(\\sqrt{N})$

换句话说，如果数 $N$ 等于两个数的乘积，那么其中一个不大于 $N$ 的平方根，另一个不小于 $N$ 的平方根。

由此推出，如果数 $N$ 不被 $2, 3, 4, \\ldots, \\bigl\\lfloor\\sqrt{N}\\bigr\\rfloor$ 中任何一个整除，那么它也不被 $\\bigl\\lceil\\sqrt{N}\\bigr\\rceil + 1, \\ldots, N-2, N-1$ 中任何一个整除，因为如果存在大于平方根的因数（不等于 $N$），则也存在小于平方根的因数（不等于 $1$）。因此 `for` 循环里只需检查到平方根而不必到 $N$。

``` C++
bool isPrime(int n) {
    if (n == 1) {
        return false;
    }
    for (int i = 2; i * i <= n; i++) {
        if (n % i == 0) {
            return false;
        }
    }
    return true;
}
```

## 需要的理论

取任意质数 $p$。设 $p - 1 = 2^n \\cdot m$，其中 $m$ 是奇数。

那么注意到，如果存在某个数 $x$，对它上面的断言不成立，则说明 $p$ 肯定不是质数。如果对 $x$ 上面的断言成立，则称 $x$ 是 $p$ 的**素性见证**（此时 $p$ 不一定是质数）。

由于 $\\varphi(n) \< n$，若取随机数 $a$，它以小于 $1/4$ 的概率是 $p$ 的素性见证。

## 算法

设有一个待检验素性的数 $p$。检查 $p - 1$ 是否被 2 整除，运行在 $O(\\log p)$（数 $p$ 的长度）。由于能整除 $p - 1$ 的 2 的最高次幂是 $\\log p$，故在 $O(\\log^2 p)$ 内可把 $p - 1$ 表示成 $2^n \\cdot m$。

然后取从 1 到 $p$ 的随机数 $a$。用[快速幂](Бинарное_возведение_в_степень "wikilink")可算出 $a^m$ 模 $p$。由于数的长度是 $O(\\log p)$，两个数相乘运行在 $O(\\log^2 p)$，因此快速幂运行在 $O(\\log^3 p)$。这样我们算出 $a^m$ 模 $p$。如果它与 -1 或 1 同余，则 $a$ 是素性见证。否则，把数平方 $n$ 次，检查它是否与 $-1$ 模 $p$ 同余。总计在 $O(\\log^3 n)$ 内可检验一个数是否为见证。

之后，你需要的「$p$ 是合数」的概率越精确，就越要多重复几次测试。若测试重复 $k$ 次且每个数都是见证，则合数的概率是 $1/2^{2k}$。总运行时间 $O(k\\cdot\\log^3 n)$。
