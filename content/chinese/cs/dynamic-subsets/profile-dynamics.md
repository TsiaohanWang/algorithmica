### 题目

给一个普通的多米诺骨牌（$1 \\times 2$），我们可以把它横放成 $1 \\times 2$ 或竖放成 $2 \\times 1$。要求说出用多米诺牌铺满一块棋盘的方法数。

### 朴素解法

用递归暴力枚举，如实统计方法数。这运行得非常久。想想如何优化。

### 动态规划

注意，一列可以由一个二进制掩码唯一确定（0 —— 空，1 —— 被某块多米诺覆盖），但我们已经学会按子掩码做动态规划，就把同样的思想应用到这里。

### 宽轮廓

设 $dp\[i\]\[j\]\[mask_{1}\]\[mask_{2}\]$ 是铺到第 $i$ 列的方法数，其中第 $i$ 列用掩码 $mask_{1}$ 编码、第 $i + 1$ 列用 $mask_{2}$，且我们正在考虑第 $i$ 列的第 $j$ 个位置。

1）动态规划基——$dp\[0\]\[0\]\[0\]\[0\]$ = 1

2）答案——$dp\[n - 1\]\[j\]\[(1 \<\< m) - 1\]\[0\]$

3）转移：

枚举掩码 $mask_{1}$ 中的位置

``` C++ numberLines
for (int j = 0; j < m; j++) {
    if ((1 << j) & mask1) { //j 位已被占，因此不能再放多米诺
        continue;
    }
    dp[i][j + 1][mask1 | (1 << j)][mask2 | (1 << j)] += dp[i][j][mask1][mask2]; //横放，考虑在列边界的情况
    if ((1 << (j + 1)) & mask1) { //(j + 1) 位空闲，还需检查它是否存在
        dp[i][j + 2][mask1 | (1 << j) | (1 << (j + 1))][mask2] += dp[i][j][mask1][mask2];//也单独考虑边界
    }
}
```

这个思路有很多边界情况，所以现在看这个问题的另外两种解法。

### 普通轮廓

设 $can\[mask_{1}\]\[mask_{2}\]$ ——能否在 $mask_{1}$ 里放多米诺，使得下一列得到 $mask_{2}$。

于是我们有 $dp\[i\]\[mask\]$ ——考虑第 $i$ 列、想在其中拼出 mask 的方法数。

现在转移非常简单：

``` C++ numberLines
for (int mask1 = 0; mask1 < (1 << m); mask1++) {
     dp[i + 1][mask1] += dp[i][mask] * can[mask][mask1];
}
```

### 复杂度估计

遗憾的是两种方法都运行得足够久：宽轮廓 $O(n \\cdot m \\cdot 2^m \\cdot 2^m)$，因为要枚举列、行、第一个和第二个掩码；普通轮廓 $O(n \\cdot 2^m \\cdot 2^m)$，好一些但还是很慢，所以有时用另一种方法——折线轮廓（broken profile）。

### 折线轮廓

方法名里已经含其思想——把我们的掩码「折断」：现在掩码不再表示整个第 $i$ 列，而是从第 $i$ 列的第 $j$ 个单元到第 $i$ 列的第 $m - 1$ 个单元，加上第 $i + 1$ 列的第 0 个单元到第 $i + 1$ 列的第 $j + 1$ 个单元。

<https://wampi.ru/image/6p95C8Q>

于是我们有 $dp\[i\]\[j\]\[mask\]$ ——用掩码 $mask$ 到达第 $i$ 行第 $j$ 个单元的方法数。

1）基 $dp\[0\]\[0\]\[0\] = 1$

2）答案——取决于实现，但我通常写到 $dp\[n\]\[0\]\[0\]$ ——表中不存在的第 0 行、掩码为 0。

3）转移——几乎和宽轮廓一样，唯一不同是我们现在需要把掩码向下移，但在 C++ 里有 \>\> 运算。

### 复杂度估计

$n \\cdot m \\cdot 2^m$
