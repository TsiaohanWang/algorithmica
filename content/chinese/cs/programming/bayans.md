凡未特别说明之处，时间复杂度均为 $O(n)$；若给出了具体数字，则时限（TL）为 1 秒。

题目按照回忆/构思的顺序排列，也就是说顺序相当随机。

## 鹦鹉

你需要传递 64 字节的某些信息。为此你有 320 只经过特殊训练的鹦鹉，每只都能记住一个 0 到 255 之间的数。所有鹦鹉迟早都会飞到目的地并报出自己携带的字节，但到达顺序可能与放出的顺序不同。鹦鹉在外观上无法区分。

## 最小值与最大值

给定 68 块重量各不相同的石头，要求在 100 次称重操作内找出最轻和最重的石头。

## 排列

有一个包含 64 个元素的排列。你可以询问指定位置集合上有哪些元素（会以任意顺序告知元素列表）。请用 6 次询问还原该排列。

## 凸包

需要回答两类询问：

1. 向凸包中添加一个点。
2. 检查某个点是否位于凸包内部。

两种操作均为在线进行，复杂度 $O(\log n)$。

## 等比数列

请找出一种方法，在任意模数下用 $O(\log n)$ 的时间计算 $\frac{1-a^n}{1-a}$。

## 宝可梦

锦标赛中有 1024 种宝可梦参赛。作为宝可梦专家，你知道谁能够击败谁。换句话说，你完全了解一个包含 1024 个顶点、$1023 \times 1022 : 2$ 条边的*锦标赛图*，其中每对顶点之间恰好有一条有向边，决定可能对决中的胜者。注意，由 $a \to b$ 和 $b \to c$ 并不能推出 $a \to c$。

你有 10 个精灵球。请组建一支 10 只宝可梦的队伍，使得对于 1024 种类型的每一只宝可梦，你的队伍中都能找到一只能够击败它的宝可梦。可认为同种宝可梦对战时你的那只获胜。

## 排序

能否完成以下排序：

- 用 8 次称重给 5 块石头排序？
- 用 7 次称重给 5 块石头排序？
- 用 60 次称重给 20 块石头排序？

## 圆内的点

给定 $n$ 个点，均匀分布在以原点为圆心的单位圆内。请给出一个平均复杂度 $O(n)$ 的算法，按它们到原点的距离排序。

## 二分查找

交互器一方生成了一个由 $n$ 个随机数组成的数组，这些数*均匀分布*在某个区间上，然后被排序。每次询问可以按数组下标得知该位置上的数。要求在*平均* $O(\log \log n)$ 次操作内判断给定数 $x$ 是否存在于该数组中。

## 随机化二分查找

考虑这样的二分查找：我们不再取中间元素，而是随机取一个：

```c++
int lower_bound(int x) {
    int l = 0, r = n - 1;
    while (l < r) {
        int m = l + rand() % (r - l);
        if (t[m] >= x)
            r = m;
        else
            l = m + 1;
    }
    return l;
}
```

所有键和询问都是随机的。当 $n \to \infty$ 时，随机化二分查找平均会比普通二分查找多进行多少倍的迭代？

## 非递减数组

给定一个由 $n$ 个整数组成的数组。要求在 $2n$ 次「把一个元素加到另一个元素上」的操作内将其变为非递减的。

## 主导元素

给定一个包含 $n$ 个元素的数组。需要回答 $m$ 个询问：区间 $[l, r]$ 上是否存在*主导*元素——即在该区间内至少出现 $\frac{r-l}{2}$ 次的元素。时间复杂度为 $O((n+m) \log n)$。

## 树的摧毁

给定一棵有根树。每一轮从所有剩余顶点中等概率选出一个顶点，然后删除该顶点对应的整棵子树。求该过程平均会持续多少轮，即树根被删除那一轮编号的数学期望。

## 区间第 $k$ 小元素

给定一个由 $n$ 个整数组成的数组。需要回答 $m$ 个询问：任意区间上的第 $k$ 小顺序统计量。时间复杂度为 $O((n+m) \log n)$。

## 区间内不同数的个数

给定一个由 $n$ 个整数组成的数组。需要回答 $m$ 个询问：任意区间上不同元素的个数。时间复杂度为 $O(m\sqrt{n})$。

## 体育课

某学院的体育课学分按出勤次数评定，因此弄清楚学期结束前还剩多少上课天非常重要（尤其是当你翘了很多课的时候）。学期共 $m$ 天。教务处依次发布 $n$ 条命令，分为两类：

1. 宣布从 $l$ 到 $r$ 的所有天为休息日（不能刷体育课）
2. 宣布从 $l$ 到 $r$ 的所有天为上课日（可以刷体育课）

一条命令可能部分撤销之前命令的效果。

每条命令发布后都需要计算学期中上课日的总数。复杂度为 $O(n \log n)$。

## 细绳

## 饺子

一群朋友想用一大块矩形面团制作饺子坯。为此他们动用了各种圆形物体：玻璃杯、马克杯、锅……最终，面团被 $n$ 个可能相交、半径和圆心任意的圆划分。我们想知道一共得到了多少块饺子坯，也就是面团被分成了多少块。复杂度为 $O(n^2 \log n)$。

## 圆

有一个半径为 $R$ 的圆，称它为*外圆*。其内部有一个半径为 $r < R$ 的圆与之相切。接下来按如下规则构造无穷多个圆：第 $k$ 个圆必须

* 与*外圆*相切，
* 与上一个（第 $k-1$ 个）圆相切，
* 并且此时半径取最大值。

## 虚张声势

卡佳和谢廖沙在玩一个游戏。卡佳有 $n$ 张牌，谢廖沙有 $m$ 张。还有一张额外的牌背面朝上放在桌上，称它为*特殊牌*。玩家的目标是猜出这张牌。所有 $n+m+1$ 张牌各不相同，玩家起初只知道自己的牌。两人轮流行动，卡佳先手。轮到自己时，玩家可以：

* 尝试猜出*特殊牌*。如果猜中则获胜，否则落败。无论结果如何，游戏到此结束。
* 说出牌堆中的任意一张牌。如果对手手中有这张牌，他必须展示它并将其移出游戏；如果没有，他会如实告知。

若双方都最优地玩，卡佳获胜的概率是多少？复杂度为 $O(nm)$。

## 钱币收藏家

有 $n$ 位贪婪的硬币收藏家，他们只愿意在一种情况下交换：用自己多出的硬币换取自己完全没有的硬币。总共有 $k$ 种硬币。已知每位收藏家以及收藏家谢廖沙手中每种硬币的数量。谢廖沙希望通过与这些贪婪收藏家交换，使自己拥有的不同硬币种类数最大化。可认为贪婪收藏家之间不会互相交换。

请设计任意一个多项式算法。

## 公主

某王国住着一位公主。她美若天仙，王国里每个年轻人都想娶她。公主十分挑剔，因而下定决心只嫁给全国最英俊的年轻人。

她列出了一份 $n$ 位最英俊年轻人的名单，并每天随机召见一人。每当一位年轻人到来，她都要做出决定：嫁给他，或不嫁。如果她决定嫁给某人，她仍会逐一见过其余所有人，以确认他确实是最英俊的。若是如此，他们就从此幸福地生活在一起。若不是（她嫁的人并非最英俊，或者她始终没有嫁人），公主就会自尽。

公主记忆力很好，因此她可以把新来的年轻人的英俊程度与之前所有人比较；她品味也很挑剔，任何两位年轻人在她看来都不会同样英俊。

请帮公主设计一种策略，最大化她嫁给最英俊年轻人的概率。

复杂度为 $O(n^2)$。

大路的地图卡米尔知晓。相应地，秘密小径的地图马特乌什知晓。

## 果酱

## 带噪的异或

猜定了一个数 $x$。你可以进行如下类型的询问：说出一个数 $y$，作为回答你会得到 $x$、$y$ 和 $m$ 的三者异或和中**置 1 的比特位数**。其中 $m$ 是随机生成的掩码，每一位以概率 $p = \frac15$ 为 1，也就是说 $x \oplus y$ 的每一位以概率 $y$ 被翻转，然后返回置 1 的比特位数。为清晰起见：

```python
x = # ...

def mask(p=0.2):
    r = 0
    for i in range(32):
        if random.random() < p:
            r += 2**i
    return r

def query(y):
    return bin(x ^ y ^ mask()).count('1')
```

你的任务是用不超过 10000 次尝试猜出这个数。

## 异步猜词

谢廖沙和他的 $(n - 1)$ 位朋友决定玩「猜词帽」游戏：一位玩家需要在限定时间内尽可能多地解释词语，让搭档猜出。

每位玩家都要与任意其他玩家配对一次；通常游戏是这样进行的：

- 第 1 位玩家用一分钟向第 2 位玩家解释词语，
- 第 2 位玩家向第 3 位玩家解释，
- ...，
- 第 $n$ 位玩家向第 1 位玩家解释，
- 第 1 位玩家向第 3 位玩家解释，
- 第 2 位玩家向第 4 位玩家解释……

……依此类推，直到第 $(n-1)$ 位玩家向第 $(n-2)$ 位玩家解释完。

如果朋友很多，游戏可能耗时相当长。谢廖沙想知道，如果允许玩家对同时、以任意顺序进行交流，游戏最短能持续多久。

对于给定的 $n \le 500$，求最短时间 $k$ 及相应的安排表。
