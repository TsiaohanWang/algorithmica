合法括号序列是指仅由括号字符（通常只考虑圆括号，但这里也会讨论多种括号类型的一般情形）组成的字符串，其中每个右括号都能找到与之对应（且类型相同）的左括号。

这里我们将讨论合法括号序列（下文简称“序列”）的经典问题：合法性检查、序列的数量、生成所有序列、求字典序中的下一个序列、在全部序列的排序列表（按字典序）中找第 k 个序列，以及反过来求一个序列的编号。每个问题都分两种情况讨论——只允许一种括号时，以及允许多种括号时。

合法性检查
先假设只允许一种括号，那么可以用非常简单的算法检查序列是否合法。设 \rm depth 为当前未闭合的左括号数量，初始时 \rm depth = 0。从左到右扫描字符串：遇到左括号就把 \rm depth 加一，遇到右括号就减一。如果过程中出现过负数，或者算法结束时 \rm depth 不为零，则该字符串不是合法括号序列；否则就是。

如果允许多种括号，则需要修改算法。不再使用计数器 \rm depth，而是维护一个栈，把遇到的左括号依次压栈。如果当前字符是左括号，就压入栈中；如果是右括号，则检查栈非空、且栈顶是与当前字符同类型的括号，然后将其弹出。如果任一条件不满足，或者算法结束时栈非空，则序列不是合法括号序列；否则就是。

这样，我们就能在 O(n) 时间内解决这两个问题。

序列的数量
公式
只有一种括号时，合法括号序列的数量可以用卡特兰数计算。即若有 n 对括号（字符串长度为 2n），数量为：

 \frac{1}{n+1} \cdot C^n_{2n}. 

现在假设不是一种，而是有 k 种括号。那么每对括号都可以独立地取 k 种类型中的任意一种，因此得到如下公式：

 \frac{1}{n+1} \cdot C^n_{2n} \cdot k^n. 

动态规划
另一方面，也可以从动态规划的角度来考虑。设 d[n] 为 n 对括号的合法括号序列数量。注意，第一个位置永远是左括号。显然，这对括号内部是某个合法括号序列；同样，这对括号之后也紧跟着一个合法括号序列。为计算 d[n]，我们枚举第一对括号内部放 i 对括号，那么第一对括号之后就相应地放 n-1-i 对括号。因此，d[n] 的公式为：

 d[n] = \sum_{i=0}^{n-1} d[i] \cdot d[n-1-i]. 

该递推公式的初始值为 d[0] = 1。

找出所有序列
有时需要找出并输出指定长度 n 的所有合法括号序列（这里的 n 是字符串的长度）。

可以这样做：从字典序最小的序列 ((\ldots(())\ldots)) 开始，然后每次用下一节描述的算法求字典序中的下一个序列。

但如果限制条件不大（n 不超过 10-12），可以做得简单得多。枚举这些括号的所有排列（使用 next_permutation() 函数很方便），共有 C_{2n}^n 个，用上面的算法逐一检查其合法性，合法则输出当前序列。

另外，寻找全部序列的过程也可以写成带剪枝的递归枚举（理想情况下其运行速度可以达到第一种算法的水平）。

求下一个序列
这里只考虑一种括号的情形。

给定一条合法括号序列，要求找出字典序中紧随其后的合法括号序列（如果不存在，则输出 "No solution"）。

总体算法如下：找到最靠右的、可以合法地改成右括号的左括号（保证这样做不破坏合法性），然后把右侧剩余的整段字符串换成字典序最小的形式——即若干个左括号，再接上所有剩余的右括号。换句话说，我们尽量保留原序列尽可能长的前缀不变，而把后缀替换成字典序最小的序列。

剩下要解决的是如何找到这第一个发生改变的位置。为此从右向左扫描字符串，并维护左右括号的平衡值 \rm depth（遇到左括号时 \rm depth 减一，遇到右括号时加一）。如果某时刻我们站在一个左括号上，且处理完该字符后平衡值大于零，那么就找到了可以开始修改序列的最右侧位置（确实，\rm depth > 0 意味着左侧还有未闭合的括号）。把当前位改成右括号，然后放尽可能多的左括号，再接上所有剩余的右括号——答案就得到了。

如果扫描完整条字符串都没有找到合适的位置，说明当前序列已经是最大的，答案不存在。

算法实现：

string s;
cin >> s;
int n = (int) s.length();
string ans = "No solution";
for (int i=n-1, depth=0; i>=0; --i) {
	if (s[i] == '(')
		--depth;
	else
		++depth;
	if (s[i] == '(' && depth > 0) {
		--depth;
		int open = (n-i-1 - depth) / 2;
		int close = n-i-1 - open;
		ans = s.substr(0,i) + ')' + string (open, '(') + string (close, ')');
		break;
	}
}
cout << ans;
这样，我们就在 O(n) 时间内解决了这个问题。

序列的编号
这里设 n 为序列中括号的对数。给定一条合法括号序列，要求找出它在按字典序排列的合法括号序列列表中的编号。

先学会计算辅助动态规划 d[i][j]，其中 i 是括号序列的长度（该序列是“半合法的”：每个右括号都有与之配对的左括号，但并非所有左括号都已闭合），j 是平衡值（即左括号数减右括号数），d[i][j] 是满足条件的序列数量。计算这个动态规划时，我们只考虑一种括号。

计算方式如下。设 d[i][j] 是我们要计算的值。若 i=0，答案立即可得：d[0][0] = 1，其余 d[0][j] = 0。设 i > 0，那么想象该序列的最后一个字符是什么。如果它是 '('，则此前我们处于状态 (i-1,j-1)；如果它是 ')'，则此前处于状态 (i-1,j+1)。于是得到公式：

 d[i][j] = d[i-1][j-1] + d[i-1][j+1] 

（规定 j 为负时所有 d[i][j] 均为零）。这样，该动态规划可以在 O(n^2) 时间内算完。

现在来解原问题。

先假设只允许一种括号。维护括号嵌套深度计数器 \rm depth，从左到右扫描序列。如果当前字符 s[i]（i=0 \ldots 2n-1）是 '('，就把 \rm depth 加 1，继续下一个字符。如果当前字符是 ')'，则把 d[2n-i-1][\rm depth+1] 加到答案中，以此计入该位置本来可以放 '(' 的情况（放 '(' 会得到比当前序列字典序更小的序列）；然后把 \rm depth 减 1。

现在假设允许 k 种括号。那么在考察当前字符 s[i]、重算 \rm depth 之前，要枚举所有比当前字符小的括号，尝试把这种括号放到当前位置（从而得到新的平衡值 \rm ndepth = \rm depth \pm 1），并把相应“尾部”的数量加到答案中：这些尾部长度为 2n-i-1、平衡值为 \rm ndepth、包含 k 种括号。可以断言，该数量的公式为：

 d[2n-i-1][{\rm ndepth}] \cdot k^{ (2n-i-1 - {\rm [...] 

该公式推导如下。首先“忘掉”括号有多种类型这一点，直接从 d[2n-i-1][{\rm ndepth}] 取答案。再考虑 k 种括号会如何改变答案。共有 2n-i-1 个未确定的位置，其中 \rm ndepth 个是用于闭合此前已开括号的右括号——这些括号的类型无法改变。而其余括号（共 (2n-i-1 - {\rm ndepth})/2 对）可以是 k 种中的任意一种，因此答案要乘以 k 的这个幂次。

求第 k 条序列
这里设 n 为序列中括号的对数。给定 k，要求找出按字典序排列的序列列表中的第 k 条合法括号序列。

和上一节一样，先计算动态规划 d[i][j]——长度为 i、平衡值为 j 的合法括号序列的数量。

先假设只允许一种括号。

从第 0 位到第 2n-1 位逐个确定所求字符串的字符。和上一题一样，维护计数器 \rm depth——当前的括号嵌套深度。在每个位置枚举可能的字符——左括号或右括号。假设我们想放左括号，那就看 d[i+1][\rm depth+1] 的值：如果它 \ge k，就在当前位置放左括号，\rm depth 加 1，继续下一位；否则从 k 中减去 d[i+1][\rm depth+1]，放右括号并把 \rm depth 减 1。最终就能得到所求的括号序列。

使用 Java 大整数实现的代码：

int n;  BigInteger k;  // входные данные
 
BigInteger d[][] = new BigInteger [n*2+1][n+1];
for (int i=0; i<=n*2; ++i)
	for (int j=0; j<=n; ++j)
		d[i][j] = BigInteger.ZERO;
d[0][0] = BigInteger.ONE;
for (int i=0; i<n*2; ++i)
	for (int j=0; j<=n; ++j) {
		if (j+1 <= n)
			d[i+1][j+1] = d[i+1][j+1].add( d[i][j] );
		if (j > 0)
			d[i+1][j-1] = d[i+1][j-1].add( d[i][j] );
	}
 
String ans = new String();
if (k.compareTo( d[n*2][0] ) > 0)
	ans = "No solution";
else {
	int depth = 0;
	for (int i=n*2-1; i>=0; --i)
		if (depth+1 <= n && d[i][depth+1].compareTo( k ) >= 0) {
			ans += '(';
			++depth;
		}
		else {
			ans += ')';
			if (depth+1 <= n)
				k = k.subtract( d[i][depth+1] );
			--depth;
		}
}
现在假设不只有一种，而是有 k 种括号。算法与上一种情况的唯一区别是：要把 D[i+1][\rm ndepth] 乘以 k^{(2n-i-1- \rm ndepth)/2}，以计入这段剩余部分里可能出现不同类型的括号。这段剩余部分的括号对数只有 2n-i-1- \rm ndepth，因为其中 \rm ndepth 个括号是用于闭合这段剩余部分之外的左括号的（因此它们的类型无法改变）。

两种括号（圆括号和方括号）情形的 Java 实现：

int n;  BigInteger k;  // входные данные
 
BigInteger d[][] = new BigInteger [n*2+1][n+1];
for (int i=0; i<=n*2; ++i)
	for (int j=0; j<=n; ++j)
		d[i][j] = BigInteger.ZERO;
d[0][0] = BigInteger.ONE;
for (int i=0; i<n*2; ++i)
	for (int j=0; j<=n; ++j) {
		if (j+1 <= n)
			d[i+1][j+1] = d[i+1][j+1].add( d[i][j] );
		if (j > 0)
			d[i+1][j-1] = d[i+1][j-1].add( d[i][j] );
	}
 
String ans = new String();
int depth = 0;
char [] stack = new char[n*2];
int stacksz = 0;
for (int i=n*2-1; i>=0; --i) {
	BigInteger cur;
	// '('
	if (depth+1 <= n)
		cur = d[i][depth+1].shiftLeft( (i-depth-1)/2 );
	else
		cur = BigInteger.ZERO;
	if (cur.compareTo( k ) >= 0) {
		ans += '(';
		stack[stacksz++] = '(';
		++depth;
		continue;
	}
	k = k.subtract( cur );
	// ')'
	if (stacksz > 0 && stack[stacksz-1] == '(' && depth-1 >= 0)
		cur = d[i][depth-1].shiftLeft( (i-depth+1)/2 );
	else
		cur = BigInteger.ZERO;
	if (cur.compareTo( k ) >= 0) {
		ans += ')';
		--stacksz;
		--depth;
		continue;
	}
	k = k.subtract( cur );
	// '['
	if (depth+1 <= n)
		cur = d[i][depth+1].shiftLeft( (i-depth-1)/2 );
	else
		cur = BigInteger.ZERO;
	if (cur.compareTo( k ) >= 0) {
		ans += '[';
		stack[stacksz++] = '[';
		++depth;
		continue;
	}
	k = k.subtract( cur );
	// ']'
	ans += ']';
	--stacksz;
	--depth;
}

# 问题

给定 $n$，按字典序输出 $n$ 对括号的所有合法括号序列。例如，当 $n = 3$ 时，
应输出

1.  ((()))
2.  (()())
3.  (())()
4.  ()(())
5.  ()()()

# 递归枚举

让我们编写如下过程

``` C++
void gen(int n, vector<char>& cur_seq, int cur_balance=0, int cur_index=0) {
  if (cur_index == 2 * n) {
    for (auto& bracket : cur_seq) {
       cout << bracket;
    }
    cout << endl;
  } else {
    if (cur_balance == 2 * n - cur_index) {
        // если количество оставшихся позиций в точности равно
        // количеству скобок, которые надо закрыть, то новые скобки мы не можем открывать

        cur_seq[cur_index] = ')';
        cur_balance--;
        gen(n, cur_seq, cur_balance, cur_index + 1);
    } else {
        // пробуем поставить обе скобки, сначала ставим ту,
        // которая лексикографически меньше

        cur_seq[cur_index] = '(';
        cur_balance++;
        gen(n, cur_seq, cur_balance, cur_index + 1);

        if (cur_balance > 1) {
            cur_seq[cur_index] = ')';
            cur_balance -= 2;
            gen(n, cur_seq, cur_balance, cur_index + 1);
       }
    }
  }
}
```

# 问题

给定一条合法括号序列，要求输出字典序中紧随其后的那一条。

# 思路

与排列问题一样，我们需要找到不能继续增大的最大后缀（字典序上）。

# 题解

不难发现，最后一条合法括号序列由左右括号交替构成，因此我们需要找到
最短的、连续出现两个右括号的后缀；找到这个位置后，再找出第一
个左括号，把它与某个右括号交换；得到的后缀要像排列的情形那样
做成字典序最小的形式。

# 例子

假设给定合法括号序列 ()()(())() ：

1\) 那么我们关心的后缀是 ()()(( || ))()

2\) 交换 ( 和 )，得到 ()()()()()

3\) 构造字典序最小的后缀——()()()(())

# 证明

为证明正确性，需要证明：

1\) 得到的序列在字典序上大于原序列

这很容易验证，因为现在右括号出现得更早了

2\) 不存在这样的序列：它字典序上大于原序列，但字典序上小于得到的序列。

如果存在这样的序列，那么它要么有更小的后缀（不可能，因为我们已经
取了最小可能的后缀），要么在我们交换的位置上更小（也不可能，因为
我们已取了最小可能的后缀）。

# 问题

在「由序列求编号」和「由编号求序列」两个问题中，我们需要辅助动态规划
ValidSequencesCount(n, balance)，其中 n 是序列中剩余的位置数，balance 是
当前括号平衡值，该函数返回具有给定长度和平衡值的合法括号序列的数量。

# 如何计算 ValidSequencesCount？

用动态规划预先计算出该函数的所有取值。

1.  基础 $VSC\[0\]\[0\] = 1$，$VSC\[0\]\[1 \\ldots n\] = 0$
2.  转移 $VSC\[n\]\[balance\] = \\underbrace{VSC\[n-1\]\[balance +
    1\]}_{\\text{放 "("}} + \\underbrace{VSC\[n-1\]\[balance -
    1\]}_{\\text{放 ")"}}$

# 问题

给定一条合法括号序列，要求求出它在字典序中的编号。

# 思路

注意到，与[由排列求编号](Получения_номера_по_перестановке "wikilink")中
一样，对每个位置我们只关心有多少个字典序更小的选择可以放在该位置，
因为该位置上任何更小的选择都会得到更小的合法括号序列，与后缀无关。
因此，让我们为每个位置累加：由于该位置上的字符更小，总共使序列
少掉了多少种，而这可以用[上文中的动态
规划](Количество_ПСП_с_заданным_балансом_и_нужной_длиной "wikilink")
来实现。

# 题解

合法括号序列的编号 = $\\sum \\limits_{i} amount(n - i - 1, bal + 1) \\cdot
(a\[i\] == ')')$
