之前有关于恢复第 $k$ 个组合对象的主题，那里我们用动态规划来恢复复杂的对象，
也就是说，恢复第 $k$ 个数大概也可以用动态规划来做。例如，假设给定一个
问题：找出各位数字之和为 $s$ 的第 $k$ 个数，首先我们需要找到这样一个数的
长度，即找到 $min(x), dp\[x\]\[s\] \>= k$，现在我们需要恢复这个数本身：
为此让我们枚举第一位数字 1 到 9，找到最小可行的，然后枚举第二位数字，以此类推。

---

假设我们需要得到字典序中的第 $k$ 个对象（排列、组合、括号序列等）。
以寻找第 $k$ 个合法括号序列为例。

我们用递归来解。设当前已经确定的前缀为 $s$，平衡值为 $b$，而 $k$ 是所求
序列的编号。我们需要确定现在该放哪个括号。显然，字典序上先出现前缀为
$s + '('$ 的序列，然后才是 $s + ')'$。设以 $s + '('$ 开头的序列数量为 $c_1$，
以 $s + ')'$ 开头的为 $c_2$。那么，如果 $k \\leq c_1$，我们需要的
前缀就是 $s + '('$。否则，从 $k$ 中减去 $c_1$（这样后面就不再考虑已经
数过的序列），在 $s$ 后接上右括号。然后再递归求解。

同样的想法也适用于其他对象：我们只需考察当前前缀的所有可能的延续，
按字典序逐个尝试，如果 $k$ 大于以某个前缀开头的对象数量，就从 $k$
中减去该数量，然后延展前缀；当 $k$ 不再超过该数量时，就用该前缀
上的最小对象延展。

---

假设我们想按字典序枚举所有排列。该怎么做？写出一个简单的递归：我们得到
排列的一个前缀，并知道需要多长的排列。那么我们可以按升序枚举 1 到 $n$
中尚未使用的数（因为我们关心字典序），把这个数放到下一位上，然后从
新前缀出发继续递归。代码如下：

``` C++
void f(int n, vector<int> & a, vector<char> & used) { // vector<bool> работает долго
    if (a.size() == n) { // получили новую перестановку в векторе a. Можем вывести/сохранить ее
        ...
    }
    a.push_back();
    for (int i = 1; i <= n; ++i) {
        if (!used[i]) {
            used[i] = true;
            a.back() = i;
            f(n, a, used);
            used[i] = false;
        }
    }
    a.pop_back();
}
```

同理，也可以枚举组合、合法括号序列（维护前缀和当前平衡值）等
其他对象。

回到排列。看起来枚举全部排列是一个非常常见而简单的任务，标准库
里应该有现成的东西。确实如此。让我们用内置函数 `next_permutation()` 编写
枚举所有排列的代码（同样是字典序）：

``` C++
sort(a.begin(), a.end());  // чтобы перебрать все перестановки с next_permutation, нужно чтобы a изначально был отсортирован
do {
    ... // получили очередную перестановку
} while (next_permutation(a.begin(), a.end()));
```

---

这个问题与“按编号生成对象”在意义上相反。但原理是相同的。以排列为例
来看解法。

设排列为 $(a_1, a_2, \\dots, a_n)$。

第一个元素是 $a_1$。那么，所有以 $1$ 到 $a_1 - 1$ 开头的排列都必然小于
当前排列。让我们计算有多少个。恰好是 $(n-1)\! \\cdot (a_1
- 1)$。也就是说，我们在字典序中跳过了 $a_1 - 1$
类排列（按第一个元素分类），每类有 $(n-1)\!$ 个元素，因为排列的
一个元素已经确定，只需确定其余 $n-1$ 个元素的顺序。

把跳过的排列数累加到计数器后，转到第二个元素，把考察范围缩小到以
$a_1$ 开头的排列。这是可行的，因为我们已经统计了所有以其他元素
开头的排列。现在重复同样的过程，只不过是对 $n-1$ 个元素的排列。
注意，元素 $a_1$ 已经从我们的考虑范围中消失了。因此剩下的数 $a_2,
\\dots , a_n$ 不能直接按原值考虑。例如，如果 $a_2
\> a_1$，那么比我们小的排列就不是 $(a_2 - 1) \\cdot (n-2)\!$
个，而是 $(a_2 - 2) \\cdot (n-2)\!$。因此，我们需要把剩下的数
重新编号为 1 到 $N-1$（保持它们的相对顺序），然后对重编号后的
序列继续处理。

例子：5 个元素的排列。对象为 $(2, 4, 5, 1, 3)$

$Num(x)$ 表示数 $x$ 在当前元素集合中的序号。例如，如果剩下的数是
$(1, 2,5, 9, 11)$，那么 $Num(5) = 3$。每次我们都重新计算 $Num$，
先把所有已处理的数 $a_1 \\dots a_{k-1}$ 划掉，如果我们现在位于
$a_k$ 上。

  - $a_1 = 2 \\Rightarrow ans += (2 - 1) \\cdot (5-1)\! = 4\! = 24$
  - $a_2 = 4 \\Rightarrow Num(a_2) = 3 \\Rightarrow ans += (3 - 1)
    \\cdot (4 - 1)\! = 2 \\cdot 6 = 12$
  - $a_3 = 5 \\Rightarrow Num(a_3) = 3 \\Rightarrow ans += (3 - 1)
    \\cdot (3 - 1)\! = 2 \\cdot 2 = 4$
  - $a_4 = 1 \\Rightarrow Num(a_4) = 1 \\Rightarrow ans += 0 $
  - $a_5 = 3 \\Rightarrow Num(a_5) = 1 \\Rightarrow ans += 0$
  - $ans = 40$
