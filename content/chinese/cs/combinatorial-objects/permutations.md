## 排列

有时题目要求计算某些对象的数量、做某件事的方法数。而通常这个数量
过于庞大，无法把所有对象一一列举出来。

例如，可以这样计算 $n$ 个不同元素的排列数。显然，排列的第一个位置可以放
$n$ 个元素中的任意一个，第二个位置可以放剩下 $n - 1$ 个中的任意一个，
以此类推。最后一个位置只剩 1 个元素可选。因此，$n$ 个元素的排列数等于
$n\\cdot(n-1)\\cdot\\ldots\\cdot2\\cdot1$，简记为 $n\!$

通常约定 $0\!=1$

---

### 排列的 k 次幂

题意。给定长度为 n 的排列 p。要求将其提升到 k 次幂，即求出对恒等排列连续应用 k 次排列 p 后得到的结果。

题解。只需对排列 p 应用上文所述的二进制快速幂算法。与数的快速幂没有任何区别。该解法的时间复杂度为 O (n \log k)。

（注：该问题还可以更高效地在线性时间内解决。为此只需找出排列中的所有循环，然后分别考察每个循环，将 k 对当前循环的长度取模，即可求出该循环的答案。）



同样，快速幂还可以应用于以下问题：

- 求排列的 $n$ 次幂：可以证明排列的复合（把一个排列应用到另一个上）同样满足结合律，因此可以使用快速幂，只需把数的乘法换成排列的复合，每次复合的代价为 $O(n)$。（不过，该问题也可以在线性时间内更高效地解决：只需找出排列中的所有循环，然后分别考察每个循环，将 $n$ 对当前循环的长度取模，即可求出该循环的答案。）

# 问题

按字典序枚举所有排列

# 代码

``` C++
int perm[MAXN];
bool used[MAXN];
void gen(int cur_index) {
  if (cur_index == n) {
    //получена перестановка
  } else {
    for (int i = 1; i <= n; i++) {
     if (!used[i]) {
        used[i] = 1;
        perm[cur_index] = i;
        used[i] = 0;
     }
  }
}
```

# 重要说明

在 C++ 中有函数 next_permutation，它用于生成下一个排列，因此为了生成
下一个排列，我们只需不断调用它，直到找到最后一个排列为止。

# 问题

给定自然数 $k$ 和 $n$ $s.t. 0 \\leq k \< n\!$。要求找出 $1$ 到 $n$ 的
排列中字典序第 $k$ 小的那个。例如，当 $n = 3$、$k = 4$ 时应输出 $3 1 2$。

# 题解

回忆一下：如果某排列在字典序中排第 $k$，那么恰好有 $k$ 个排列比它小。
我们将从左到右依次确定所求排列的各个元素，同时（隐式地）逐步累计那 $k$
个比我们小的排列。

如果第一个位置放的不是 $1$ 而是 $2$，那么我们得到的排列必然大于所有以
$1$ 开头的排列，而以 $1$ 开头的排列共有 $(n-1)\!$ 个。如果第一个位置放
的不是 $2$ 而是 $3$，那么比我们小的排列就有 $2 \\cdot (n-1)\!$ 个，以此
类推。因此，我们不断增大第一位数字，直到不能增大为止（即 $(d-1)
\\cdot (n-1)\! \\leq k$ 不再成立）。然后从 $k$ 中减去我们已经确定大于的
那部分排列数，再开始确定第二位数字，此时每次减去 $(n-2)\!$，直到
不能减为止。当然，每次确定某个位置上的数字时，都要跳过前面已经用过的数字。

# 正确性

由于我们减去的各个排列类是互不相交的，最终得到的排列 $\\sigma$ 恰好有
$k$ 个排列在字典序上小于 $\\sigma$。

# 问题

给定一个排列，要求求出它在字典序中的编号。

# 思路

注意到，对每个位置我们只关心有多少个字典序更小的选择可以放在这个位置上，
因为只要这个位置上的数更小，无论后缀如何，得到的排列都会更小。因此，
让我们对每个位置累加：由于该位置上的数更小，总共使排列少掉了多少种。

# 题解

排列的编号 = $\\sum \\limits_{i} \\sum \\limits_{i \< j}
a\[i\] \> a\[j\] \\cdot (n - i)\!$

# 问题

给定 $1$ 到 $n$ 的一个排列，要求生成字典序中的下一个排列。

# 题解

1.  设 $i \~-$ 是从右往左扫描时第一个满足 $a\[i\] \\leqslant a\[i + 1\]$ 的元素位置。
2.  设 $j \~-$ 是 $i$ 右侧大于 $a\[i\]$ 的最小元素所在的下标。
3.  交换 $swap(i, j)$，此后从第 $i$ 个位置开始的后缀按降序排列。
4.  将从 $i+1$ 开始的后缀反转。

# 正确性证明

为证明正确性，需要证明：

1.  得到的序列在字典序上大于原序列
2.  不存在这样的序列：它字典序上大于原序列，但字典序上小于得到的序列。

---

我们来解决下面的问题：给定一个排列/组合/选排列，需要根据它生成字典序中的
下一个对象。

例如，8 个元素的排列：

$(1, 5, 2, 3, 4, 8, 7, 6) \\Rightarrow (1, 5, 2, 3, 6, 4, 7, 8)$

无论对象类型如何，总的原则都一样：找出一个长度最短的、可以在不改变其余
前缀的情况下（字典序上）增大的后缀。

### 排列

对排列来说这意味着什么？再看同一个例子。我们逐步扩大后缀，并检查它
能否被增大。

  - $(1, 5, 2, 3, 4, 8, 7, \[6\])$ 单个 6 无法再改变
  - $(1, 5, 2, 3, 4, 8, \[7, 6\])$ 后缀为 (7,6)，由 7 和 6 无法
    拼出更大的排列
  - $(1, 5, 2, 3, 4, \[8, 7, 6\])$ 后缀为 (8,7,6)，这些元素相互之间
    也构成了最大可能的排列。
  - $(1, 5, 2, 3, \[4, 8, 7, 6\])$ 现在后缀是 $(4, 8, 7,
    6)$，我们可以增大它。做法是：在后缀的第一个位置放上紧跟在 4
    后面的那个数，本例中即 6，然后把剩余的数排成最小可能的顺序。
    也就是把 6 放到第一个位置，其余数字按升序排列。

### 组合

沿用同样的原则。每个组合都是 $1$ 到 $N$ 中选出的一组长度为
$K$ 的升序序列。因此，我们要找这样的后缀：可以用前缀中未使用的数增大
它的第一个元素。后缀的剩余部分自然地用连续的数补全，它们肯定没有在
前缀中出现过，因为序列始终是升序的。

看一个例子：$C_6^4$

$(1, 2, 5, 6)$

后缀 $(6)$ 和 $(5,6)$ 都无法增大，只能取 $(2,
5, 6)$。于是把 $2$ 换成 $3$，再用连续的数补全 —— $(3, 4, 5)$。

本质上，后缀能否增大的判据是：它不是序列 $1, 2, 3, \\dots, N -
1, N$ 的后缀。

### 如何求出前一个对象

这里反过来，需要找出可以减小的最短后缀。修改方法如下：把后缀的
第一个元素换成前一个可能的值，其余部分则做成所有可能中最大的。

以 8 个元素的排列为例：

$(1, 5, 2, 3, 6, 4, 7, 8) \\Rightarrow (1, 5, 2, 3, \[6, 4, 7, 8\])
\\Rightarrow (1, 5, 2, 3, 4, 8, 7, 6)$
