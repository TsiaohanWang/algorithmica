*Mo 算法*（中 莫隊算法）可能不是莫涛发明的，但确由中国竞赛选手莫涛（莫涛）及其队友在 2000 年代末推广。

它允许离线回答各种子段查询，其中很多即使最先进的数据结构也常常难以解决。

例如考虑这样一道题：给大小为 $n$、值在 1 到 $n$ 的整数数组，回答 $q$ 个预先已知的「区间 $[l_i, r_i]$ 上不同数的个数」查询。

### 算法

如果说[按查询的根号启发式](../rollback)按时间特征分组查询，那么 Mo 算法按空间特征分组。

把所有查询按左边界分成大小为 $c \approx \sqrt n$ 的块，块内按右边界排序：

```cpp
// 边界和要回答的查询编号
struct query { int l, r, idx; };

int a[maxn], ans[maxq]; // 原数组和查询答案数组
vector<query> b[c];


// 在 main 的某处：

for (query q : queries)
    b[q.l / c].push_back(q);

for (int i = 0; i < c; i++) {
    sort(b[i].begin(), b[i].end(), [](query a, query b){
        return a.r < b.r;
    });
}
```

逐块处理这些查询，建如下变量：

- 当前区间的边界 $[l, r]$（初始为空：$l = i \cdot c$、$r = i \cdot c - 1$）；
- 数组 `cnt`（大小 $n$），对每个值存它在当前区间中的出现次数（初始全零）；
- 变量 `res`，等于当前区间上不同元素个数，即 `cnt` 中非零元素个数（初始为零）。

数组 `cnt` 与变量 `res` 容易在边界扩缩一格时在 $O(1)$ 内重算：

```cpp
int cnt[maxn];
int res;

void add(int k) {
    if (cnt[a[k]]++ == 0)
        res++;
}

void del(int k) {
    if (--cnt[a[k]] == 0)
        res--;
}
```

我们慢慢左右移动边界，使当前区间在某个时刻等于每个查询区间；那个时刻就回答该查询，把 `res` 写进答案数组 `ans` 的相应单元。

具体说，先移动当前区间的右边界直到等于某查询的右边界（它们按右边界排序），再左右移动左边界直到等于它的左边界：

```c++
for (int i = 0; i < c; i++) {
    // 清零变量
    int l = i * c, r = i * c - 1;
    memset(cnt, 0, sizeof cnt);
    res = 0;
    for (query q : b[i]) {
        // 直到右边界到达查询边界
        while (r < q.r)
            add(++r);
        // 再让左边界一致
        while (l < q.l)
            del(l++);
        while (l > q.l)
            add(--l);
        ans[q.idx] = res;
    }
}
```

诀窍在于：右边界总计移动 $O(n)$，因为区间已排序；左边界每次至多移动 $O(\sqrt n)$，因为所有左边界按根号块分组。所有块左边界的变化总计 $O(q \sqrt n)$，右边界 $O(n \sqrt n)$，因此解的总体复杂度是 $O(q \sqrt n + n \sqrt n)$。

### 变体

**题目。** 求区间上出现次数最多的元素。

同样维护 `cnt`，此外再维护一个内部结构，能有序地存（出现次数, 元素）对并取最大值。可以用 `set` 之类二叉结构，但这会加一个多余对数。

要在纯 $O(n \sqrt n)$ 内解决，可作内部结构：一个双向链表数组（元素出现次数 → 具有该次数的元素），以及一个迭代器指针数组——对每个元素存它当前在哪个列表的哪个位置。加入/删除元素时把它从当前列表取出、插入更高/更低的列表；回答查询时从最高非空列表任取一个元素。

也可以简化，完全不用结构：只维护 `cnt` 数组和答案 `res`（最频元素出现次数），但只在加入元素时松弛后者，删除时什么也不做：

```cpp
void add(int k) {
    res = max(res, ++cnt[a[k]]);
}

void del(int k) {
    cnt[a[k]]--;
    // res 这里不更新
}
```

现在主过程里回退左边界时，先记住处理查询前（开始扩展左边界前）的 `res` 值，再回退它：

```cpp
for (int i = 0; i < c; i++) {
    int l = i * c, r = i * c - 1;
    memset(cnt, 0, sizeof cnt);
    res = 0;
    for (query q : b[i]) {
        while (r < q.r)
            add(++r);
        int backup = res;
        while (l < q.l)
            del(l++);
        ans[q.idx] = res;
        while (l > q.l)
            add(--l);
        res = backup;
    }
}
```

**题目。** 求区间上的第 $k$ 个序统计量。

可以把查询中的数都存进 treap 或其他树——例如求和线段树甚至树状数组——更新并在其上下降，$O(\log n)$。

要去掉对数，意外地可以把根号分解用作内部结构。把数压缩到 1 到 $n$，建「数 $x$ 出现多少次」数组，并为它的每个根号块维护和。更新时在 $O(1)$ 内对两个单元做 $\pm 1$；查询第 $k$ 个序统计量时先走 $O(\sqrt n)$ 个块，再走某个块内 $O(\sqrt n)$ 个元素。

由于内部结构的更新查询有 $O(n \sqrt n)$ 次，而读查询只有 $O(n)$ 次，所以后者 $O(\sqrt n)$ 的复杂度不影响大局。这是根号优化在同题中渐近胜过树的罕见情形——在另一个根号优化内部。

**树上。** 有些题要算树上路径操作的结果。例如：每个顶点旁有个数，需要返回路径上不同值个数。

思想与 [LCA 归结为 RMQ](/cs/trees/lca-rmq) 类似：写出树的欧拉遍历（每个顶点两次），问题就归结为数组问题，只差一点——我们要往结构里只加那些在区间中恰好出现一次的元素。

详见[树上查询](/cs/trees/tree-queries/)。

**「3D Mo」。** 若很想，这方法也能用于需处理更新查询的题。为此给 get 查询引入第三个参数 $t$，等于当前 get 之前 update 查询数（「时间」）。

再次排序所有 get 查询，但这回按

$$
\left(\lfloor \frac{t}{n^{\frac 2 3}} \rfloor, \lfloor \frac{l}{n ^{\frac{2}{3}}} \rfloor, r\right)
$$

处理，用同样的算法，只是三维。

唯一细节：现在在数组版本间切换时，恰好要改一个元素，并且如果它属于当前区间，有时还要在结构中改它。

这种做法的运行时间是 $O(n^{\frac{5}{3}})$，证明与原算法类似。
