**题目**。 给定直线上的 $n$ 个点，按坐标 $x_i$ 排序。需要找到覆盖所有点的 $m$ 个线段，同时最小化它们的长度平方和。

**基础解法**——把动态规划状态 $f[i, j]$ 定义为用不超过 $j$ 个线段覆盖前 $i$ 个点的最小代价。可以通过枚举所有可能的最后一段来转移：

$$
f[i, j] = \min_{k < i} \{f[k, j-1] + (x_{i-1}-x_k)^2 \}
$$

最终答案是 $f[n, m]$，这样整段动态规划总复杂度为 $O(n^2 m)$。

```c++
// x[] —— 排序后的点坐标数组，下标从零开始

// 从第 i 个点到第 j 个点的线段长度的平方
int cost(int i, int j) {
    return (x[j] - x[i]) * (x[j] - x[i]);
}

for (int i = 0; i <= m; i++)
    f[0][i] = 0; // 如果什么都不需要覆盖，那一切都好
// 其余所有 f 假定为无穷大

for (int i = 1; i <= n; i++)
    for (int j = 1; j <= m; j++)
        for (int k = 0; k < i; k++)
            f[i][j] = min(f[i][j], f[k][j - 1] + cost(k, i - 1));
```

（注意，`i` 和 `j` 的两层循环可以互换位置。）

本章我们将讨论 4 种相互关联的优化方法，除了这道题本身，它们也普遍适用于许多其他动态规划。
