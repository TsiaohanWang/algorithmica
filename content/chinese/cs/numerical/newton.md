牛顿法，有时也叫牛顿–拉夫逊法，是一种简单高效地求实值函数根（即解形如以下方程）的近似算法：

$$
f(x) = 0
$$

对函数 $f$ 的唯一要求是：至少有一个根，且在搜索区间上连续、可微。

## 算法描述

算法从某个初始近似 $x_0$ 出发，然后迭代地构造更好的解：在点 $x = x_i$ 处作图的切线，把切线与 $x$ 轴交点的坐标作为下一个近似 $x_{i+1}$。直觉是：如果函数 $f$ 是「[好的](https://en.wikipedia.org/wiki/Smoothness)」，且 $x_i$ 已经足够接近根，那么 $x_{i+1}$ 会更近。

![](../img/newton.png)

要求 $x_i$ 处的交点，把切线方程令为零：

$$
0 = f(x_i) + (x_{i+1} - x_i) f'(x_i)
$$

由此可解出

$$
x_{i+1} = x_i - \frac{f(x_i)}{f'(x_i)}
$$

牛顿法在计算数学中极其重要：多数情况下，数值解方程用的就是它。

## 求平方根

作为一个具体例子，考虑求平方根的问题，它可以改写为解下面的方程：

$$
x = \sqrt n \iff x^2 = n \iff f(x) = x^2 - n = 0
$$

如果把 $f(x) = x^2 - n$ 代入牛顿法，就得到下面的规则：

$$
x_{i+1} = x_i - \frac{x_i^2 - n}{2 x_i} = \frac{x_i + n / x_i}{2}
$$

如果要以给定精度 $\epsilon$ 求根，可以在每次迭代做相应检查：

```cpp
const double eps = 1e-9;

double sqrt(double n) {
    double x = 1;
    while (abs(x * x - n) > eps)
        x = (x + n / x) / 2;
    return x;
}
```

对许多函数算法都能可靠收敛到正确答案，但只有对特定一类函数（例如凸函数）这种收敛是可靠且可证明的。另一个问题是一旦收敛，它有多快。

### 收敛速度

用牛顿法求 $2$ 的平方根，从 $x_0 = 1$ 出发，看每次迭代后有多少位数字是正确的：

可以注意到，每次迭代后正确数字的个数大约翻倍。这种漂亮的收敛速度并非巧合。

要数值地估计收敛速度，考虑第 $i$ 次迭代的*较小*相对误差 $\delta_i$，看下一次迭代的误差 $\delta_{i+1}$ 会小多少。

$$
|\delta_i| = \frac{|x_n - x|}{x}
$$

用相对误差表示，可以把 $x_i$ 写成 $x \cdot (1 + \delta_i)$。把这个表达式代入下一次迭代的公式，两边除以 $x$，得到

$$
1 + \delta_{i+1} = \frac{1}{2} (1 + \delta_i + \frac{1}{1 + \delta_i}) = \frac{1}{2} (1 + \delta_i + 1 - \delta_i + \delta_i^2 + o(\delta_i^2)) = 1 + \frac{\delta_i^2}{2} + o(\delta_i^2)
$$

这里我们把 $(1 + \delta_i)^{-1}$ 在 0 处展开成泰勒级数，用了误差 $d_i$ 很小的假设：由于序列 $x_i$ 收敛到 $x$，对足够大的 $n$ 有 $d_i \ll 1$。

最后，解出 $\delta_{i+1}$，得到

$$
\delta_{i+1} = \frac{\delta_i^2}{2} + o(\delta_i^2)
$$

这意味着在已经接近解时，相对误差每次迭代大约被平方再减半。由于 $(- \log_{10} \delta_i)$ 大约等于数 $x_i$ 正确有效数字的个数，误差平方就对应答案有效数字翻倍，这正是我们前面观察到的。

这个性质称为*平方收敛*，它不仅适用于求平方根。把形式证明留作练习，一般情形可以证明

$$
|\delta_{i+1}| = \frac{|f''(x_i)|}{2 \cdot |f'(x_n)|} \cdot \delta_i^2
$$

这意味着在几个附加假设下至少是平方收敛，这些假设具体是：$f'(x)$ 不为零且 $f''(x)$ 连续。
