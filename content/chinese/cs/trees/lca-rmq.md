有一大类问题都需要先解决下面这个辅助问题。

**问题**。给定一棵有根树。要求回答查询：求顶点 $u_i$ 与 $v_i$ 的最近公共祖先，即这样一个顶点 $w$：它既在从根到 $u_i$ 的路径上，又在从根到 $v_i$ 的路径上，并且是所有这样的顶点中最深（最靠下）的一个。

这个问题在英文中叫做 *least common ancestor*——最近公共祖先。

![顶点 $i$ 是顶点 $k$ 和 $n$ 的 LCA](../img/lca.png)

为便于理解，先看看如何慢速（线性时间）地求最近公共祖先：

```c++
bool ancestor(int u, int v) {
    return tin[u] <= tin[v] && tin[v] < tout[u];
}

int lca(int u, int v) {
    while (!ancestor(u, v))
        u = p[u];
    return u;
}
```

解决这个问题的方法有很多种，本章后续会介绍主要的几种。本文要做的，是把 LCA 问题归结为区间最小值问题（以及反过来）。

## 归结为静态 RMQ

用 `dfs` 遍历这棵树，写出两个数组：各顶点深度和顶点编号。我们在进入顶点和离开顶点时都记录。

![](../img/tour.png)

现在来一个查询：求顶点 $v$ 和 $u$ 的 LCA。为确定起见，假设 $v$ 在遍历中更早出现：$tin_v < tin_u$。看我们写下的路径中，从*离开* $v$ 的时刻到第一次*进入* $u$ 的时刻之间的那一段。由于树中任意两点间的简单路径唯一，这一段上必然会经过最近公共祖先。同时，在这段路上我们肯定不会爬到 LCA 之上，所以 LCA 就是这段路上的最高顶点。

也就是说，要求 LCA，只需在深度数组（第一个数组）的区间 $[tout_v, tin_u]$ 上找到最小值的位置，再看看它对应欧拉遍历（第二个数组）中的哪个顶点。这样，LCA 问题就归结为 RMQ 问题（区间最小值），例如可以用[线段树](/cs/segment-tree)在每次查询 $O(\log n)$ 内解决。

查询的时间复杂度还可以进一步改善，利用的事实是我们实际上在解决 *static RMQ* 问题——数组没有修改。为此有更合适的结构——[稀疏表](/cs/range-queries/sparse-table)，它可以在 $O(1)$ 内回答最小值查询，但预处理需要 $O(n \log n)$ 次操作和内存，常数较小。

原来，反过来归约也是可行的。

## Farach–Colton 与 Bender 算法

*免责声明：*本节描述的 LCA 算法在实际中完全没用，但从理论上看非常有趣。

原来，LCA 和静态 RMQ 都可以做到每次查询 $O(1)$、预处理 $O(n)$。

事实上，在把 LCA 归结为 RMQ 时，我们解决的并不是完整的 RMQ 问题。我们处理的不是 1 到 $n$ 范围内所有整数数组，而只是一部分——相邻两个元素恰好相差 1 的那些数组，因为 dfs 中的每一步要么是下降要么是上升。这个限制让我们能更快地在这样的数组上求子区间最小值。

### 预处理

做法如下：既然每个元素要么比前一个多 1，要么少 1，就把原深度数组映射为一个大小为 $(n - 1)$ 的布尔数组：第 $i$ 个位置为 1 表示下一个值更大，为 0 表示更小。这个数组需要以二进制形式存储，以便能在常数时间内取出较短子区间的布尔掩码。

**预处理的第一部分。**取常数 $k = \lfloor \frac{\log n}{2} \rfloor$，把原数组分成每块 $k$ 个元素的小块。对每块求最小值，再在这些最小值上建 [sparse table](/cs/range-queries/sparse-table)。

这样的块总共有 $O(\frac{2 n}{\log n})$ 个，因此建表是线性时间的：

$$
O(\frac{2 n}{\log n} \log \frac{2 n}{\log n}) = O(\frac{2 n}{\log n} (\log 2n - \log \log n)) = O(n)
$$

**预处理的第二部分。**对每个大小为 $k$ 的「上升/下降」掩码，计算它上面的最大下降——即遍历这个掩码，维护遇到的 0 和 1 的差值，记住这个平衡值的最小值。这可以在「掩码长度乘以掩码数量」的时间内完成：

$$
O(k \cdot 2^k) = O(\frac{\log n}{2} 2^{\frac{\log n}{2}}) = O(\sqrt n \log n)
$$

可能的掩码总数并不多——这正是当初在定义 $k$ 时把对数除以 2 的原因。

### 回答查询

现在需要用已算好的结构在某个区间 $[l, r]$ 上求 RMQ。这个区间包含一些完整的小块，以及左右两端各剩下的一些不构成完整块的单元。

- 对完整小块部分，只需在 sparse table 中查询一次——常数时间。

- 对两端的非完整部分，各算一个候选答案。为此把预处理的掩码最小值加到边界元素上即可——这个掩码可以用位运算在布尔数组上以常数时间取出。

对所有块预先算好所有后缀和前缀最小值来应对第二种情况，很遗憾是不行的——有一种特殊情况：查询很小，没有覆盖任何完整块。这时只能取边界元素，再加上所需掩码在上升数组中的最小值。

### 静态 RMQ → LCA

这个算法在理论上很重要，因为借助它不仅能解决 LCA，还能在一般情况下以线性预处理、常数查询解决静态 RMQ。

建一棵[笛卡尔树](/cs/tree-structures/treap)，把元素下标作为键 $x_i$，把元素值本身作为优先级 $y_i$。笛卡尔树可能是不平衡的（因为优先级没有随机化），但我们也不需要它平衡。然后把上面描述的算法应用到这棵树上：要求原数组中某区间的最小值，只需查询第 $l$ 个和第 $r$ 个顶点在这棵树中的公共祖先——它在笛卡尔树中的优先级就是所求的最小值。

更详细的内容和实现（作者从没写过这个代码，也不建议你写）可以看 [e-maxx](http://e-maxx.ru/algo/lca_linear)。不过，在实际中这个算法并不划算，因为常数太大：为了去掉复杂度里的对数，要算的东西实在太多了。
