给定一棵有 $n$ 个顶点的树 $G$ 和 $m$ 个形如 $(a_i, b_i)$ 的查询。对每个查询 $(a_i, b_i)$，需要求出顶点 $a_i$ 和 $b_i$ 的最近公共祖先，即这样一个顶点 $c_i$：它离树根最远，同时又是 $a_i$ 和 $b_i$ 两个顶点的祖先。

我们以离线方式考虑这个问题，即假设所有查询在开始时都是已知的。下面描述的算法可以在总共 $O(n+m)$ 的时间内回答全部 $m$ 个查询，因此当 $m$ 足够大时每个查询是 $O(1)$。

Tarjan 算法
该算法的基础是「并查集」这种数据结构，而它正是由 Tarjan 发明的。

算法实际上是从树根出发的一次深度优先遍历，在遍历过程中逐步求出各查询的答案。具体来说，查询 $(v,u)$ 的答案会在深度优先遍历位于顶点 $u$、而顶点 $v$ 已被访问过时求出，反之亦然。

假设深度优先遍历当前位于顶点 $v$（并且已经递归进入了它的儿子们），结果发现对某个查询 $(v,u)$ 而言，顶点 $u$ 已经被深度优先遍历访问过了。这时我们就能求出这两个顶点的 \rm LCA。

注意，{\rm LCA}(v,u) 要么就是顶点 $v$ 本身，要么是它的某个祖先。也就是说，我们需要在 $v$ 的祖先（包括它自己）中找出最下方的、$u$ 是其后代的那个顶点。注意，固定 $v$ 时，按这个判定标准（即 $v$ 的哪个最小祖先同时也是某个顶点的祖先），树的所有顶点被划分成若干互不相交的类。对 $v$ 的每个祖先 $p \not= v$，它的类包含该顶点本身，以及以它的儿子为根、位于通往 $v$ 的路径「左侧」的所有子树（即那些在到达 $v$ 之前就已经处理完的子树）。

我们需要高效地维护所有这些类，为此要用到「并查集」这种数据结构。结构中每个类对应一个集合，并且对每个集合的代表元素，我们定义量 \rm ANCESTOR——即构成这个类的那个顶点 $p$。

下面详细说明深度优先遍历的实现。假设我们站在某个顶点 $v$ 上。把它放进并查集的一个独立类中，{\rm ANCESTOR}[v] = v。和通常的深度优先遍历一样，枚举所有出边 (v, to)。对每个这样的 to，我们都要先从这个顶点递归做深度优先遍历，然后把这个顶点连同整棵子树并入顶点 $v$ 所在的类。这可以用并查集的 \rm Union 操作实现，随后把集合代表元素的 {\rm ANCESTOR} 设为 v（因为合并后代表元素可能变了）。最后，处理完所有边之后，枚举所有形如 (v,u) 的查询：如果 $u$ 已被标记为访问过，那么这个查询的答案就是顶点 {\rm LCA}(v,u) = {\rm ANCESTOR}[{\rm FindSet}(u)]。不难发现，对每个查询，「查询的一个顶点是当前顶点、另一个之前已被访问过」这个条件恰好满足一次。

估计一下复杂度。它由几部分组成。首先，深度优先遍历的复杂度，这里是 $O(n)$。其次，集合合并操作，对所有合理的 $n$ 加起来共 $O(n)$ 次操作。再次，对每个查询检查条件（每个查询两次）并确定答案（每个查询一次），这些同样对合理的 $n$ 都是 $O(1)$。最终总复杂度为 $O(n+m)$，也就是说当 $m$ 足够大（$n = O(m)$）时，每个查询只需 $O(1)$。

实现
下面给出该算法的完整实现，包括稍作修改（支持 \rm ANCESTOR）的并查集实现（随机化版本）。

const int MAXN = максимальное число вершин в графе;
vector<int> g[MAXN], q[MAXN]; // граф и все запросы
int dsu[MAXN], ancestor[MAXN];
bool u[MAXN];
 
int dsu_get (int v) {
	return v == dsu[v] ? v : dsu[v] = dsu_get (dsu[v]);
}
 
void dsu_unite (int a, int b, int new_ancestor) {
	a = dsu_get (a),  b = dsu_get (b);
	if (rand() & 1)  swap (a, b);
	dsu[a] = b,  ancestor[b] = new_ancestor;
}
 
void dfs (int v) {
	dsu[v] = v,  ancestor[v] = v;
	u[v] = true;
	for (size_t i=0; i<g[v].size(); ++i)
		if (!u[g[v][i]]) {
			dfs (g[v][i]);
			dsu_unite (v, g[v][i], v);
		}
	for (size_t i=0; i<q[v].size(); ++i)
		if (u[q[v][i]]) {
			printf ("%d %d -> %d\n", v+1, q[v][i]+1,
				ancestor[ dsu_get(q[v][i]) ]+1);
}
 
int main() {
	... чтение графа ...
 
	// чтение запросов
	for (;;) {
		int a, b = ...; // очередной запрос
		--a, --b;
		q[a].push_back (b);
		q[b].push_back (a);
	}
 
	// обход в глубину и ответ на запросы
	dfs (0);
}
