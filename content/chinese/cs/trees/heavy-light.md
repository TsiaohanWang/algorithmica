重链剖分（heavy-light decomposition）是解决「路径查询 + 更新查询」类问题的强大方法。如果没有更新查询，最好写[更简单的东西](../centroid)。

对一棵有根树做重链剖分的过程如下：对每个顶点 $v$ 考察它的所有直接孩子 $u$，在其中选出子树最大的孩子 $u_{max}$——如果有多个，任选一个——并把边 $(v, u_{max})$ 称为重边（英文 heavy），其余所有边称为轻边（英文 light）。

这样一来，树就分裂成了重边和轻边。这个划分就叫做重链剖分。

![](../img/heavy-light.png)

下面证明这个划分的几条有用性质。

**结论**。树被划分成若干互不相交的、由重边组成的路径。

**证明**。每个顶点最多进入一条重边，每个顶点最多引出一条重边。

把一条轻边，或者一段由重边组成的竖直路径，称为一个*块*。

**结论**。任意竖直路径上至多有 $O(\log n)$ 个块。

**证明**分为两部分：

* 竖直路径上的轻边不超过 $O(\log n)$ 条：考虑最下方的顶点，从下往上沿竖直路径走。每经过一条轻边，当前顶点子树的大小就翻一倍，因为如果一个顶点通过轻边与父节点相连，那么父节点一定还有某个不比当前顶点小的孩子。
* 由重边组成的连续段不超过 $O(\log n)$ 段：如果不是路径的端点，那么每段都被两条轻边包围，而轻边总共只有 $O(\log n)$ 条。

**推论**。任意路径上至多有 $O(\log n)$ 个块。

我们做这一切就是为了这个：现在在每条重链上搭建某种数据结构（例如[线段树](/cs/segment-tree)），回答查询（比如路径上的和）时，把它拆成 $O(\log n)$ 个对重链子段或轻边的查询。

## 实现

绝大多数公开的 HLD 实现都有 120～150 行代码。我们则利用下面这个技巧，它能大大简化我们的生活：对树的顶点重新编号，使得每条重链上的所有顶点都有连续的编号。

具体来说，在统计子树大小的阶段，修改每个顶点的邻接表，让它的「重」孩子排在最前面。这样，如果对图做一次普通的欧拉遍历，数组 `tin` 就是所需的编号，因为在每个顶点处我们都优先走向它的重孩子。

```c++
vector<int> g[maxn];
int s[maxn], p[maxn], tin[maxn], tout[maxn];
int head[maxn]; // «голова» тяжелого пути, которому принадлежит v
int t = 0;

void sizes(int v = 0) {
    s[v] = 1;
    for (int &u : g[v]) {
        sizes(u);
        s[v] += s[u];
        if (s[u] > s[g[v][0]])
            // &u -- это ссылка, так что её легально использовать при swap-е
            swap(u, g[v][0]);
    }
}

void hld(int v = 0) {
    tin[v] = t++;
    for (int u : g[v]) {
        // если это тяжелый ребенок -- его next нужно передать
        // в противном случае он сам является головой нового пути
        head[u] = (u == g[v][0] ? head[v] : u);
        hld(u);
    }
    tout[v] = t;
}
```

现在我们可以在这个大小为 $n$ 的数组上建一棵线段树或其他结构，查询某条重链时，就对该结构做一次区间查询。

## 如何用它解题

一个最简单的 HLD 题目例子：给一棵树，每个顶点上写有一个数，有两种查询：

1. 求 $v_i$ 与 $u_i$ 之间路径上的最小数。
2. 把第 $v_i$ 个顶点的数改成 $x_i$。

把树挂到任意一个顶点上，在上面做 HL 剖分，并用线段树作为内部结构。线段树的代码这里不给出，就当作它和[对应文章](/cs/segment-tree)里实现得差不多，有 `upd(k, x)` 和 `get_min(l, r)` 两个方法。

```c++
int val[maxn];
segtree st(0, n);
```

更新操作只需要更新线段树中对应的单元格：

```c++
void upd(int v, int x) {
    st.upd(tin[v], x);
}
```

最小值查询要复杂一些——需要把原始查询拆成对若干竖直路径的查询：

```c++
int ancestor(int a, int b) {
    return tin[a] <= tin[b] && tin[b] < tout[a];
}

void up(int &a, int &b, int &ans) {
    while (!ancestor(head[a], b)) {
        ans = min(ans, st.get_min(tin[head[a]], tin[a]));
        a = p[head[a]];
    }
}

int get_min(int a, int b) {
    int ans = inf;
    up(a, b, ans);
    up(b, a, ans);
    if (!ancestor(a, b))
        swap(a, b);
    ans = min(ans, st.get_min(tin[a], tin[b]));
    return ans;
}
```

注意，要把路径拆成两条竖直路径，甚至不需要单独求解 LCA 问题：沿着重链上升，$O(\log n)$ 次上升后就能到达最大公共祖先。

## 备注

- 如果题目没有更新查询，可以对查询做「缓存」。注意，需要对结构发起的绝大多数查询都在重链的前缀上，这些都可以用 $O(1)$ 预处理给出答案，而每个查询的前缀子查询有 $O(\log n)$ 个。另外还要做 $O(1)$ 个对结构的查询，每个耗时 $O(\log n)$。于是每个查询总共 $O(\log n)$。
- 由于我们的 HLD 实现是在树的欧拉遍历上建结构，我们还可以加入子树查询，因为子树就是欧拉遍历的连续子区间。
