title: 计数排序

前面所有算法处理的数组中都可以放任意可比较的对象：数字、字符串、pair、其他数组——几乎任何东西。

在元素只能属于某个小集合的特殊情形下，可以使用另一种算法——*计数排序*（英文 *counting sort*）。

例如，假设保证所有数都是自然数，且落在 1 到 100 之间。于是有这样一个简单算法：

- 创建一个大小为 100 的数组，在第 $k$ 个位置存数字 $k$ 在该数组中出现的次数。
- 遍历原数组的所有数，把对应位置的值加 1。
- 统计完每个数出现次数后，只需遍历这个数组，输出 $1$ 出现多少次、输出 $2$ 出现多少次，依此类推。

该算法运行时间为 $O(m + n)$，其中 $m$ 是可能取值的个数，$n$ 是数组元素个数。如果集合中可能的互异元素个数相对不大，计数排序就是最优解之一。

### 一种实现

创建大小为 100 的数组 $c$，遍历原数组一次填满它。

然后维护一个指针 $k$ 指向原数组中要写入下一个数的位置，每次当我们递减 $c$ 中的某个格子时递增它。

```cpp
void count_sort(int *a, int n) {
    int c[100] = {0};

    for (int i = 0; i < n; i++)
        c[a[i]]++;

    int k = 0;
    for (int i = 0; i < 100; i++)
        while (c[i]--)
            a[k++] = i;
}
```
