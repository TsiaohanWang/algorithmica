数组排序问题就是把它的元素按某种顺序重新排列——最常见的是按非递减顺序：每个元素都应大于或等于前一个。

```python
a = [5, 2, 1, 3, 1]
a.sort()
print(a)  # [1, 1, 2, 3, 5]
```

虽然大多数语言的标准库都实现了高效的排序算法，但了解有哪些方法是很有用的，因为常常可以改造它们来解决其他相关的问题。本节的所有算法都相对简单，也是练习[时间复杂度估算](../complexity)的好题目。

在阅读算法描述的同时，观看它们的[可视化演示](https://visualgo.net/nl/sorting)也很有帮助。
