与之类似的方法是**选择排序**（选最小或最大）。

要对数组排序，$n$ 次从未排序的数中选出最小值，放到它的位置上（具体说，在第 $k$ 次迭代后放到第 $k$ 个位置）。为简化实现，在第 $k$ 次迭代时，我们在区间 $[k, n - 1]$ 上找最小值，与当前的 $k$-th 元素交换，之后区间 $[0, k]$ 就排好序了。

```cpp
void selection_sort(int *a, int n) {
    for (int k = 0; k < n - 1; k++)
        for (int j = k + 1; j < n; j++)
            if (a[k] > a[j])
                swap(a[j], a[k]);
}
```

正确性与时间复杂度的证明与[冒泡排序](../bubble)类似：经过 $O(n)$ 次迭代中的每一次，我们都在 $O(n)$ 时间内得到一个已排序的前缀（前 $k$ 个元素），因此在 $O(n^2)$ 次操作内排好整个数组。
