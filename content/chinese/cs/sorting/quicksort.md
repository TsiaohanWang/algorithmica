快速排序的做法是：每一步找出一个基准元素，把所有小于它的元素扔到左半部分、其余的扔到右半部分，然后递归地进入两部分。

```cpp
// partition - 把元素分成小于和大于/等于 a[index] 的函数，
// 该函数返回分界的位置
void partition(int l, int r, int p) {

}

void quicksort(int l, int r){
    if (l < r){
        int index = (l + r) / 2; /* index - 基准元素的下标，
        为了简单起见，先把它设为区间的中点*/
        index = partition(l, r, index);
        quicksort(l, index);
        quicksort(index + 1, r);
    }
}
```

来估算这个排序的复杂度。对随机数据它运行在 $O(NlogN)$，因为每次我们都会把数组分成大约相等的两半，所以递归的规模之和大约是常数个对数层，而且每一层递归最多查看整个数组大小的元素。
不过很容易发现两个问题，一是相同数字，二是万一中点恰好是最小值或最大值。

有几种办法应对：

1. 如果快速排序运行太久，就改用任意其他 $NlogN$ 排序。
2. 把数组分成三部分（小于、等于、大于）而不是两部分。
3. 为了消除中点取到最大值/最小值的问题，让我们**随机选择**基准元素。
