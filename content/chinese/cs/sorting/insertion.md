---
title: 插入排序
weight: 3
---

设第 $k$ 步时我们已经排好了长度为 $k$ 的前缀。要扩大这个有序前缀，可以取它后面的那个元素，不断与左邻居交换，直到这个元素大于它的左邻居。当这发生时，说明它比左边所有元素都大、比右边前缀所有元素都小，于是我们就正确地把它插入到了数组的已排序部分。

```cpp
void insertion_sort(int *a, int n) {
    for (int k = 1; k < n; k++)
        for (int i = k; i > 0 && a[i - 1] < a[i]; i--)
            // 我们还没到数组开头，且前一个元素更小
            swap(a[i], a[i - 1]);
}
```

最坏情况下运行时间也是平方级——例如当数组按降序排列时。

然而，与前两种平方级排序不同，在某些好的情形下运行时间可以更短，因为我们在内层循环中加入了提前停止的条件。例如，如果数组初始就有序，算法只需 $O(n)$ 次操作。

**练习**。 证明：如果数组「几乎有序」——即每个元素到它在有序数组中位置的距离不超过 $k$——那么算法做 $O(n k)$ 次操作。
