我们的第一个方法如下：设 $n$ 为数组长度，从左到右遍历它 $n$ 次，如果第一个比第二个大就交换两个相邻元素。

每轮迭代，最大元素就像气泡一样「浮」到数组末尾——名字即由此而来。

```cpp
void bubble_sort(int *a, int n) {
    for (int k = 0; k < n; k++)
        for (int i = 0; i < n - 1; i++)
            // 把元素与下一个比较
            if (a[i] > a[i + 1])
                // 如果下一个更小，就交换
                swap(a[i], a[i + 1]);
}

int a[5] = {5, 2, 1, 3, 1};

bubble_sort(a, 5);

for (int i = 0; i < 5; i++)
    cout << a[i] << " ";
```

**正确性。** 用归纳法可以证明，冒泡排序算法执行 $k$ 步后，最后 $k$ 个数总是有序的，因此算法正确。

**复杂度。** 因为有两个嵌套循环，每个最多做 $O(n)$ 次迭代，内部在 $O(1)$ 内完成比较和 `swap`，总运行时间至多为 $O(n^2)$。

**练习。** 算法可以（非渐近地）稍作加速。要如何修改两个 `for` 循环的边界，才能不做任何多余操作？
