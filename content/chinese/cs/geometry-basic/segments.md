线段可以用它两个端点的点来给定。顺序任意——因为它与向量不同，是无向的。

```cpp
struct segment {
    r p, q;
};
```

计算几何中常需要判断几何对象的相互位置。例如检查线段是否相交。这要借助点积与叉积，以及少量分类讨论：

![](../img/segments.png)

用乘积的术语，「线段的端点位于另一条线段的两侧」例如写成：

$$
[(M_1 - P_1) \times (P_2 - P_1)]
\cdot
[(M_2 - P_1) \times (P_2 - P_1)]
< 0
$$

再写一个关于 $(M_1, M_2)$ 作为分割线段的附加条件，就得到容易计算的谓词，它当且仅当线段相交时为真。

## 射线与直线

*射线*是在一个方向上无限的线段。可以存成一点加显式的方向向量，或加它的任意另一点。

直线稍复杂。有整整 4 种成立的存储方式：

1. 一般式：$A \cdot x + B \cdot y + C = 0$。
2. 两点。
3. 一点加方向向量（任意）：$\vec{r} = \vec{a}t + \vec{b}$。
4. 一点加法向量（任意）。

也常像学校那样用 $y = kx + b$ 存，但对竖直线得单独处理。

常常输入给一种形式、方便用的是另一种。主要转换这样实现：

- $2 \rightarrow 1$：只需解一个 2 方程 3 未知数的方程组。
- $1 \rightarrow 3$：如果直线用方程给出，则向量 $\overline{(-B; A)}$ 是直线方向（记住直线有两个「方向」）。
- $1 \rightarrow 4$：如果直线用方程给出，则向量 $\overline{(A; B)}$ 是直线法向量（记住直线有 2 个「法向方向」）。
- $4,3 \rightarrow 1$：需要解 1 方程 1 未知数，因为从前几项已知道合适的 $A$ 和 $B$。
- $1 \rightarrow 2$：只需在直线上取任意两点——例如：

```c++
// 给 A, B, C (A^2 + B^2 != 0)
r a, b;
if (eq(A, 0)) // 如果这是水平直线
    a = {0, -C/B}, b = {1, -C/B);
else
    a = {-C/A, 0}, b = {-(C+B)/A, 1);
```

### 检查

对方式 2-4，所有检查与线段几乎相同。实际上，几何题里常引入「bounding box」——边界很远的正方形，其外所有点都看作「无穷」。于是无限直线和射线可替换成顶到这些无穷边界的线段，像普通线段那样做所有检查。

对用公式给出的直线，情况完全不同。

### 点到直线的距离

注意，如果直线用 $Ax + By + C = 0$ 给出，那么*半平面*可以用同样的不等式给出。这可以直接用来判断点在直线的哪一侧。

这条直线的*法向量*坐标是 $(A, B)$。它垂直于直线，而在半平面 $Ax + By + C \geq 0$ 的情形指向半平面自身。

要求点 $(x_0, y_0)$ 到直线 $Ax + By + C = 0$ 的距离，可用下面公式：

$$
d = \frac{|Ax_0+By_0+C|}{\sqrt{A^2+B^2}}
$$

可以把这个公式想成点向量与归一化（$\frac{1}{\sqrt{A^2+B^2}}$）法向量的点积，几何上等于点在它上的投影。

如果直线用 2 点给出，可以从三角形面积公式表达出高：

$$
A = \frac{1}{2} bh
\implies
h = \frac{2A}{b}
$$

并这样算高：

$$
\rho(P, L(A, B)) = \frac{|\overrightarrow{PA} \times \overrightarrow{PB}|}{|\overrightarrow{AB}|}
$$

注意分子里是[叉积](../products)——我们利用它取模后等于三角形 $\angle PAB$ 面积的两倍。

### 直线交点

求两条直线交点，就是求同时满足两个方程的点：

$$
\begin{cases}
A_1 x + B_1 y + C_1 = 0 \\
A_2 x + B_2 y + C_2 = 0
\end{cases}
$$

从两个方程解出 $x$ 并令相等，得到

$$
\begin{cases}
-x = \frac{B_1 y + C_1}{A_1} \\
-x = \frac{B_2 y + C_2}{A_2}
\end{cases}
\implies 
\frac{B_1 y + C_1}{A_1} = \frac{B_2 y + C_2}{A_2}
\implies 
y = - \frac{A_1 C_2 - A_2 C_1}{A_1 B_2 - A_2 B_1}
$$

类似地，$x = \frac{B_1 C_2 - B_2 C_1}{A_1 B_2 - A_2 B_1}$（注意符号）。

注意分母可能为零。这意味着法向量的叉积为零，即直线平行——此时要么无交点，要么（重合情形）有无穷多个。这种情况要单独处理。

再给几个构造性方法的例子。

### 点到直线的投影

要把点 $P$ 投影到直线 $L$，只需给它加上直线的法向量，长度取 $\rho(P, L)$、方向从点指向直线。由于法向量可能有两个（彼此相反！）方向，只需尝试两种，取得到点离直线距离更小的那个。

### 直线反射

设要把点 $(x_0, y_0)$ 关于直线 $ax+by+c=0$ 对称反射。

纯粹出于教学目的，先用数学家的方式解这道题，以后千万别这么做。

$$
\Pr_a b = \frac{a \cdot b}{|a|} \frac{a}{|a|} = \frac{|a| |b| \cos \alpha}{|a|} \frac{a}{|a|} = |b| \cos \alpha \frac{a}{|a|}
$$

几何意义：长度乘单位方向向量。

我们不想逐坐标展开这些公式、给出现成答案。知道它必然冗长。我们愿意分步计算——这里没有必要优化。也想分步，因为这样算法逻辑更直观，因而更容易调试。

```c++
// 直线 r = at + b，点 c
r pr(r a, r b, r c) {
    c -= b; // 让 c 和 a 从同一点出发
    return b + (a * b / len(a) / len(a)) * a;
}

r reflect(r a, r b, r c) {
    return c + 2*(pr(a, b, c)-c);
}
```
