除了显而易见的加法、减法和数乘之外，向量还有一些特有的运算，能让生活更简单。

## 点积（标量积）

两个向量的**点积**（英文 *dot product*，标量积）等于它们长度的乘积再乘以夹角的*余弦*。对它成立如下公式：

$$
a \cdot b = |a| \cdot |b| \cdot \cos \theta = x_a x_b + y_a y_b
$$

它的证明繁琐且纯粹是技术性的，所以我们就不证了。

几何上，它等于向量 $b$ 在向量 $a$ 上的投影乘以 $a$ 的长度：

![](../img/dot.jpg)

有用的性质：

- 点积是对称的（$a \cdot b = b \cdot a$）。
- 垂直向量的点积为零。
- 夹角为*锐角*时，点积为*正*。
- 夹角为*钝角*时，点积为*负*。

在实现中加入对应的运算符：

```c++
int operator*(r a, r b) { return a.x * b.x + a.y * b.y; }
```

## 叉积（向量积）

两个向量的**叉积**（英文 *cross product*，也叫*斜积*或*伪标量积*）等于它们长度的乘积再乘以夹角的正弦——且这个正弦的符号取决于操作数的顺序。它同样可以方便地用坐标表示：

$$
a \times b = |a| \cdot |b| \cdot \sin \theta = x_a y_b - y_a x_b
$$

和点积一样，坐标公式的证明留作读者练习。如果有人想做：它由两种乘积的线性性（这本身也需要证明）以及按基向量 $\overline{(0, 1)}$ 和 $\overline{(1, 0)}$ 展开得出。

几何上，它是以 $a$ 和 $b$ 为边的平行四边形的有向面积：

![](../img/cross.jpg)

它的性质：

* *反对称*：$a \times b = - (b \times a)$。
* 共线向量的叉积为零。
* 如果 $b$ 在 $a$ 的「左侧」，叉积为*正*。
* 如果 $b$ 在 $a$ 的「右侧」，叉积为*负*。

通常也为它重载运算符——用 `^` 或 `%`：

```c++
int operator^(r a, r b) { return a.x*b.y - b.x*a.y; }
```

*注*。 严格来说，正式的叉积定义并非如此。它被定义为一个长度与原向量相同、但垂直于两个原始向量的向量。这在三维几何和物理中有应用，不过在咱们这个二维世界里暂时还不用考虑。

---

点积和叉积与向量间的夹角密切相关，可用于计算有向角和有向面积之类的量，这些量通常用于各种判断。

一旦实现了它们，使用乘积就比依赖代数容易得多。例如，把叉积和点积代入熟悉的 `atan2`，就能轻松算出两个向量之间的夹角：

```c++
double angle(r a, r b) {
    return atan2(a ^ b, a * b);
}
```

今后，乘积的这些性质将帮助我们判断点与点、点与直线等的相对位置，因此理解并牢记这些性质非常重要。
