构建凸包最简单的算法之一是 Jarvis 算法。

选一个保证会进入凸包的点 $p_0$。例如最下面的点，如果有多个，就选其中最左的。

然后这样做：找出相对于最后加入的点「最右」的点（即相对它极角最小的点），加入凸包。如此迭代加入点，直到「闭合」——即最右的点变成 $p_0$ 为止。

![](../img/jarvis.png)

算法的正确性用归纳法容易证明：

- 在第零步，我们选了一个确实在凸包里的点。
- 在第 $i$ 步，我们取的点使得所有其他点都位于线段 $(p_{i-1}, p_i)$ 的左侧，因此肯定不会盖住点 $p_i$。

Jarvis 算法也叫礼品包装法（gift wrapping）：我们就像拿着一卷包装纸绕着点集走，包装纸自然地包住下一个角。

为简单起见，我们假设所有点互异、坐标为整数，且没有三个点共线。

```c++
vector<r> jarvis(vector<r> points) {
    r p0 = points[0];
    for (r p : points)
        if (p.x < p0.x || (p.x == p0.x && p.y < p0.y))
        p0 = p;
    vector<r> hull = {p0};
    while (true) {
        r t = p0; // 下一个点的候选
        for (r p : points)
            // 最好别真的算极角
            if ((p - p0) ^ (t - p0) > 0)
                t = p;
        if (t == p0)
            continue;
        else {
            p0 = t;
            hull.push_back(t);
        }
    }
    return hull;
}
```

对凸包上的每个点（其数量记为 $h$），我们都从剩下的 $O(n)$ 个点中找最优者，总计运行在 $O(n h)$。

重要的是，复杂度是 $O(nh)$ 而非 $O(n^2)$：存在凸包很小的题目，此时这一点很关键。

**题目**。 给定一个点集，对它迭代地构建凸包并删除进入凸包的点。对每个点，要求确定它在第几次迭代后被删除。复杂度 $O(n^2)$。
