设想我们是某个威权国家的记者，这个国家控制着媒体，并时不时颁布法律，禁止提及某些政治事件或使用某些词语。如何用程序高效地实现这样的审查？

更形式化地说，给定一组字符串 $s_1, s_2, \ldots, s_m$，它们来自大小为 $k$ 的字母表，总长度为 $n$，称为*词典*，以及一段长文本 $t$。需要判断文本中是否至少出现词典中的某个单词，如果出现，出现在什么位置。

我们已经会解这个问题，例如可以分别[检查](../../string-searching)每个单词是否出现，复杂度为 $O(n \cdot |t|)$；或者以 $O(\max |s_i| \cdot |t|)$ 的复杂度[哈希](../../hashing)所有短子串。但我们仍然想要一个复杂度为 $O(|t|)$ 的可扩展方案，今天我们将构造一个能解决该问题的*自动机*。

Aho–Corasick 算法（以发明者阿尔弗雷德·阿霍（Alfred Aho）和玛格丽特·科拉西克（Margaret Corasick）的姓氏命名；民间戏称为「[小鲫鱼](https://fishingwiki.ru/%D0%9A%D0%B0%D1%80%D0%B0%D1%81%D1%8C)」（карасик，由 Корасик 谐音而来））用 $O(nk)$ 的时间和内存为该字符串集合构建*字典树*，然后在这棵树上构建*自动机*，它可应用于该问题及许多其他字符串问题。该算法于 1975 年问世，此后在流式文本处理的系统程序中得到了广泛应用——例如 [grep](https://en.wikipedia.org/wiki/Grep) 工具。

本文作者在工作中整整两次需要实现 Aho–Corasick 算法——比其他所有「竞赛」算法加起来的次数还多两次。

## 核心思想

按词典构建字典树。假设词典中的字符串互不为对方的子串——这种情况下可以把较长的字符串去掉，不过稍后我们会看到，这一假设其实是不需要的。

为了解决问题，我们将构建一个自动机：在读入每个新字符后，自动机维护的状态对应于*最长的*、同时满足以下两点的字符串：

1. *某条词典字符串的前缀*，且
2. *已读入文本的后缀*。

这个状态信息就足够了：如果该状态被标记为终止状态，那么这个后缀与词典中的某个字符串重合，我们就输出它。否则，根据定义，我们找到的是字典树接受的最长后缀，而它的任何子串都不是被禁的，因此当前位置不包含任何被禁单词。

困难的部分在于构建这样的自动机：给定字典树中的状态和新字符，快速找到与新写出的文本前缀的、最长的可被字典树接受的后缀所对应的顶点。为此我们需要几个辅助概念。

### 后缀链接

**反形式主义说明。** 为了避免到处写冗长的「与顶点 $v$ 对应的字符串 $s$」，我们约定下文把顶点与它在字典树中对应的字符串等同看待。

**定义。** *后缀链接*（suffix link）$l(v)$ 指向顶点 $u \neq v$，它对应于字典树接受的 $v$ 的最长后缀。

**定义。** *自动机转移*（automaton transition）$\delta(v, c)$ 指向对应于字符串 $v + c$ 的、字典树接受的最大后缀的顶点。

**观察。** 如果字典树中已经存在该转移（我们称这种转移为*直接转移*），那么自动机转移就会指向同一个地方。

自动机转移正是解决问题所需要的：它们恰好指向对应于最长可接受后缀的那些顶点。

### 如何计算

注意后缀链接与自动机转移之间有以下联系：

- $l(s_{:n}) = \delta(l(s_{:n-1}), s_n)$：先走到父节点，沿它的后缀链接走，再按最后一个字符做自动机转移，就得到自己的后缀链接。

- 如果不存在直接转移 $v \to_c u$，那么 $\delta(v, c) = \delta(l(v), c)$：沿后缀链接走，再按字符 $c$ 做自动机转移，就得到自己按该字符的自动机转移。

根节点及其直接子节点有一些细节需要注意，但关键之处在于：我们刚刚把长度为 $n$ 的字符串的 $l$ 和 $\delta$，用长度不超过 $(n-1)$ 的字符串的 $l$ 和 $\delta$ 表达了出来。也就是说，后缀链接和自动机转移可以按刚写出的公式用动态规划来计算。

### 实现

与字典树相比，除了直接转移数组 `to` 和顶点的「终止性」标记外，我们还需要存储一些额外信息：

- 与 `to` 同样大小的自动机转移数组 `go`；
- 后缀链接 `link`；
- 「父节点」字符 `pch`，后缀链接的公式中需要用到它。

假设我们处理的是拉丁字母表：

```c++
const int k = 26;

struct Vertex {
    Vertex *to[k] = {0}, *go[k] = {0};
    Vertex *link = 0, *p;
    int pch;
    Vertex (int _pch, Vertex *_p) { pch = _pch, p = _p; }
};

Vertex *root = new Vertex(-1, 0);
```

插入字符串的代码几乎一样：

```c++
void add_string(string &s) {
    Vertex *v = root;
    for (char _c : s) {
        int c -= int(_c - 'a');
        if (!v->to[c])
            v->to[c] = new Vertex(c, v);
        v = v->to[c];
    }
}
```

我们将用「惰性动态规划」来计算 `go` 和 `link`——为它们引入两个会记住自身结果的函数：

```c++
// нам нужно объявить две функции, ссылающиеся друг на друга
// в C/C++ для этого нужно сигнатуру хотя бы одной из них объявить перед другой
Vertex* go(Vertex *v, int c);

Vertex* link(Vertex *v) {
    if (!v->link) {
        // для строк длины меньше двух суффиксная ссылка это корень
        if (v == root || v->p == root)
            v->link = root;
        else // в остальных случаях формула работает
            v->link = go(link(v->p), v->pch);
    }
    return v->link;
}

Vertex* go(Vertex *v, int c) {
    if (!v->go[c]) {
        // если переход есть, то автоматный должен вести туда же
        if (v->to[c])
            v->go[c] = v->to[c];
        // если перехода нет, но вершина корень, то нужно сделать петлю
        else if (v == root)
            v->go[c] = root;
        else // в остальных случаях формула работает
            v->go[c] = go(link(v), c);
    }
    return v->go[c];
}
```

用 `bfs` 构建自动机会更高效也更「干净」——较长字符串的状态只依赖于较短的字符串，所以可以从根节点开始「扩散」——但这样理解和实现起来都更复杂。
