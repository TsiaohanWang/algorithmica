*广度优先搜索*（英文 *breadth-first search*，BFS）是图上的基本算法之一，可求从给定顶点出发的所有最短路径，并解决许多其他问题。

广度优先搜索也叫*遍历*——与[深度优先搜索](/cs/graph-traversals/dfs)及其他遍历一样，它把图所有顶点各访问一次，只是顺序不同：按到起始顶点距离递增。

## 算法描述

算法输入*无权*图和起始顶点 $s$ 的编号。图可有向也可无向——对算法无所谓。

算法核心思想可理解成「点燃」图的过程：第零步点燃顶点 $s$，之后每步火焰从每个已燃顶点跳到它所有邻居，最终点燃整个图。

模拟这个过程，每次迭代「火环」在宽度上扩大一格。顶点 $v$ 开始燃烧的步号正好等于从 $s$ 到它的最短路径长度。

![](../img/bfs.svg)

这样模拟：建一个队列放燃烧的顶点，并建布尔数组对每个顶点标记是否燃烧——即是否已被访问。初始只有 $s$ 入队，并立刻标记为燃烧。

然后算法是个循环：只要队列非空，从队头取出一个顶点 $v$，看它所有出边，若有相邻顶点 $u$ 未燃，则点燃它们并入队尾。

最终队列为空时，我们恰好一次地遍历了所有从 $s$ 可达的顶点，且都经最短路径到达。最短路径长度可单独用数组 $d$ 算：入队时按 $d_u = d_v + 1$ 重算。也可紧凑存恢复路径的额外信息：建「祖先」数组，对每个顶点存我们是从哪个顶点到它的。

### 实现

既然反正维护距离数组，就不必另建布尔标记数组，而给所有顶点赋初始距离某个特殊值（例如 -1），表示还未查看。

``` c++
vector<int> g[maxn];

void bfs(int s) {
    queue<int> q;
    q.push(s);
    
    vector<int> d(n, -1), p(n);
    d[s] = 0;
    
    while (!q.empty()) {
        int v = q.front();
        q.pop();
        for (int u : g[v]) {
            if (d[u] == -1) {
                q.push(u);
                d[u] = d[v] + 1;
                p[u] = v;
            }
        }
    }
} 
```

现在恢复到某顶点 $v$ 的最短路，可用数组 `p`：

```cpp
while (v != s) {
    cout << v << endl;
    v = p[v];
}
```

注意路径按相反顺序输出。

### 隐式图

广度优先搜索常用于在隐式给定的图中找最短路。

作为具体例子，假设有 $n \times n$ 布尔矩阵，标记坐标 $(x, y)$ 的格子是否空闲，要求在每步可移动到垂直或水平相邻空闲格的情况下，求从 $(x_s, y_t)$ 到 $(x_y, y_t)$ 的最短路径。

![广度优先搜索可用于找迷宫出口](../img/maze.gif)

可以把图转成显式格式：给所有格子编号（例如按公式 $x \cdot n + y$），对每格看所有邻居，若对应格空闲就加边到 $(x \pm 1, y \pm 1)$。

这在最优线性时间内工作，但实现上更简单的是不去改输入，而改遍历算法本身：

```cpp
bool a[N][N]; // 格子 (x, y) 是否空闲
int d[N][N];  // 到 (x, y) 的最短距离

// 为简化代码
struct cell {
    int x, y;
};

void bfs(cell s, cell t) {
    queue<cell> q;
    q.push(s);

    memset(d, -1, sizeof d);
    d[s.x][x.y] = 0;

    while (!q.empty()) {
        auto [x, y] = q.front();
        q.pop();
        // 查看所有邻居
        for (auto [dx, dy] : {{-1, 0}, {+1, 0}, {0, -1}, {0, +1}}) {
            // 算邻居坐标
            int _x = x + dx, _y = y + dy;
            // 检查它空闲且未被访问
            if (a[_x][_y] && d[_x][_y] == -1) {
                d[_x][_y] = d[x][y] + 1;
                q.push_back({_x, _y});
            }
        }
    }
} 
```

运行 `bfs` 前要确保不越界。与其在看邻居时加 `_x < 0 || x >= n` 等检查，不如用技巧：初始创建维度多 2 的矩阵 `a`，读取数据时从 1 而不是 0 开始填充。于是矩阵边界总是填 0（即标为不可通行），算法绝不会越界。

## 应用与推广

除在无权图中求距离外，广度优先还用于许多深度优先也适用的问题，例如找[连通分量](/cs/graph-traversals/connectivity)或[判二分图](/cs/graph-traversals/bipartite)。

**多源 BFS**。 初始不只把一个顶点、而把多个顶点入队，就能为每个顶点求到其中某个的最短距离。

这在模拟火灾、洪水、火山喷发等「波源」不止一个的现象时有用。也可更快地为特定顶点对求最短路：从两端各并行跑一次遍历，在它们相遇时停下。

**游戏**。 若系统每个状态可表示成图的顶点、状态间转移表示成边，就能用 BFS 求最少步数的解——例如最少步数还原魔方。

**最短环**。 要求有向无权图的最短环，可以从每个顶点做一次 BFS。遍历中一旦试图从当前顶点沿某条边走到已访问顶点，就说明为该顶点找到了最短环，停下遍历。在所有这样找到的环中（每次遍历一个）选最短的。

这种算法运行 $O(n^2)$：最坏情形是一个大环，其中对每个顶点遍历其余所有顶点。

**最短路径上的边**。 可以线性求出位于给定顶点对 $a$ 和 $b$ 之间*某条*最短路径上的所有边。为此从 $a$ 和 $b$ 各跑一次 BFS。

记两次遍历所得最短距离数组为 $d_a$ 和 $d_b$。则每条边 $(u,v)$ 可用准则检查

$$
d_a[u] + d_b[v] + 1 = d_a[b]
$$

另一种做法：从 $a$ 跑一次遍历，到 $b$ 后开始递归地沿所有通向更靠近 $a$ 的顶点（即满足 $d[u] = d[v] - 1$）的反向边走，单独标记它们。

类似可找位于某条最短路径上的所有顶点。

**0-1 BFS**。 若某些边权可为零，找最短路也不难多少。

关键观察：若从顶点 $a$ 到 $b$ 能经全零边到达，则从 $s$ 到这些顶点的最短距离相同。

若图中只保留 $0$ 边，就分成若干连通分量，每分量答案相同。若把单位边放回，说这些边连接的不是顶点而是连通分量，就归结为普通 BFS。

于是遍历中处理顶点 $v$ 时，若它有到未访问顶点的零边，就立刻走它们、加入整个零分量，给它们设与 $v$ 相同的距离。

也可直接做：访问顶点时把其所有未访问的零边邻居加到队列*头*，让它们比已在队列中的先处理。用 deque 替换队列即可：

```cpp
vector<int> d(n, -1);
d[s] = 0;

deque<int> q;
q.push_back(s);

while (!q.empty()) {
    int v = q.front();
    q.pop_front();
    for (auto [u, w] : g[v]) {
        if (d[u] == -1) {
            d[u] = d[v] + w;
            if (w == 0)
                q.push_front(u);
            else
                q.push_back(u);
        }
    }
}
```

也可不用 deque 而用两个队列：一个放零边、一个放单位边，`while` 里先看第一个、空了再看第二个。这方法能推广。

**1-k BFS**。 现在边权取 1 到某个小 $k$ 之间的值，仍要求从 $s$ 的最短距离，但在总权意义上。

*观察*： 图中最大最短距离是 $(n - 1) \cdot k$。

对每个距离 $d$ 建一个队列 $q_d$，存距 $s$ 距离 $d$ 的顶点——可能还含一些我们已找到距 $s$ 长度 $d$ 的路径、但可能还有更短路径的顶点。需要 $O((n - 1) \cdot k)$ 个队列。

初始把 $s$ 放进 $q_0$，然后取最小非空列表中的顶点，把所有未访问邻居放进编号 $d_v + w$ 的队列并松弛 $d_u$，别忘了它真正的最短距离可能更小。

```cpp
int d[maxn];
d[s] = 0;

queue<int> q[maxd];
q[0].push_back(s);

for (int dist = 0; dist < maxd; dist++) {
    while (!q[dist].empty()) {
        int v = q[dist].front();
        q[dist].pop();
        // 若距离更小且我们已考察过该顶点，
        // 但它还在更靠前的队列里
        if (d[v] > dist)
            continue;
        for (auto [u, w] : g[v]) {
            if (d[u] < d[v] + w) {
                d[u] = d[v] + w;
                q[d[u]].push(u);
            }
        }
    }
}
```

复杂度 $O(k n + m)$：每个顶点至多被松弛、加入另一队列 $k$ 次，且只在第一次处理时才看它的出边。

其实不需要这么多列表。若每条边权不超过 $k$，那么任意时刻至多 $k$ 个队列非空。只建 $k$ 个列表，用 $(d_v+w) \bmod k$ 代替加入第 $(d_v + w)$ 个列表。

注意算法在只对路径长度有总体限制、而非对每条边权有限制时也工作。更一般的情形（边权任意非负）有[Dijkstra 算法](../dijkstra)，下一篇文章讲。
