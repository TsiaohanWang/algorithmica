我们已经会动态规划，看下面这个动态：

$d_{i j}^k$ 是从顶点 $i$ 到 $j$、只以编号前 $k$ 个顶点作中间点的最短路长度（有点像背包）。

动态基（$k = 0$）只由单边路径决定。若存在从 $i$ 到 $j$、代价 $c$ 的边，则 $d_{i j}^{0}$ = $c$。若有多条这样的边，自然取最小值。

要算 $d_{i j}^{k}$，有两个选项：

1) 路径上不用第 $k$ 个顶点，则 $d_{i j}^{k}$ = $d_{i j}^{k - 1}$。

2) 路径某处用第 k 个顶点，则路径分成两段——从 $i$ 到 $k$ 和从 $k$ 到 $j$；因总路径最短，这两段也应最短，故公式 $d_{i j}^{k}$ = $d_{i k}^{k - 1}$ + $d_{k j}^{k - 1}$。

最终答案——$d_{A B}^{n}$。

可以想想如何按这种动态恢复路径本身。

另外，该算法不必用三维动态，可用二维：在 $dp_{ij}$ 中存 $dp_{ij}^0$、$dp_{ij}^1$、$dp_{ij}^2$、$\ldots$、$dp_{ij}^n$ 中最近的值。

```
for(int k = 0; k < n; k++){
    for(int i = 0; i < n; i++){
        for(int j = 0; j < n; j++){
            a[i][j] = min(a[i][j], a[i][k] + a[k][j]);
        }
    }
}
```

# Dijkstra 算法

此算法只考虑无负权边的图。

Dijkstra 算法解决稍不同的问题：它求从**一个**顶点 $A$ 到**每个**顶点的距离。为每个顶点在数组 $d$ 中存到 $A$ 的距离。例如：
* $d[A] = 0$
* $d[x] = \infty$，若 x 从 A 不可达

把通过边 $(a, b, c)$ 更新顶点 $b$ 的答案称为**松弛**：$d[b] = \min(d[b], d[a] + c)$。

* 这样答案不会优于到 $b$ 的最短距离，因为我们只是用顶点 $a$ 的路径再延长到 $b$。
* 若按正确顺序松弛最短路径上的所有边到顶点 $b$，就得到到 $b$ 的最短路径。

现在每次取距离 $A$ 当前最小、且我们还没看过的顶点，更新它所有邻居。设最小距离顶点是 x，则松弛它的所有边。

用归纳法证明算法正确：

基础) 第一个考察的顶点总是 $A$，但对它成立「$A$ 到 $A$ 的距离 = 0」。

递推) 取出顶点 $i$，已知它所有祖先的答案正确。若对第 $i$ 个顶点找到的答案大于应有值，说明应从某个尚未考察的顶点过来；但图中没有负权边，故不可能 $\Rightarrow$ 证毕。

有两种可能实现：

1) 在线性内从数组找最小距离实现。因为每步找最小顶点，至多 $N$ 步，但每步线性找最小值，所以 $O(N^2)$。

```
for (int i = 0; i < n; ++i){
    int uk = -1;
    for (int j = 0; j < n; j++){
        if ((mark[j] == 0) && ((uk == -1) || (d[j] < d[uk]))){
                uk = j;
        }
    }
    for (int j = 0; j < n; j++){
        if ((j != uk) && (g[uk][j] != -1)) d[j] = min(d[j], g[uk][j] + d[uk]);
    }
    mark[uk] = 1;
}
```

# Ford–Bellman

该算法解决与 Dijkstra 相同的问题，但能处理负权边！

和 Dijkstra 一样建距离数组，起始顶点距离 = 0。算法在于把图中每条边**松弛** $N-1$ 次。

这能工作，因为最短路径至多 $N-1$ 条边，若按正确顺序松弛它们，就找到该路径。$N-1$ 遍遍历所有边并松弛后，我们必然做到并找到最短路径。

这种情况也方便显式存**边列表**而不是邻接表。

```
int from[m], to[m], cost[m];
for (int i = 0; i < n - 1; ++i) {
		for (int j = 0; j < m; ++j) {
				d[to[j]] = min(d[to[j]], d[from[j]] + cost[j]);
    }
}
```

# Floyd 算法

## 问题描述

Floyd（–Warshall）算法在没有负环的图 $G = (V, E)$ 中求所有点对最短路。若图有负环，算法可能返回其中一个。

## 用动态规划解

设图所有顶点编号 1 到 $n$，顶点 $i$ 与 $j$ 之间边权为 $w(i, j)$。

### 定义

引入动态规划 $sp\[i\]\[j\]\[k\]$ ——图在顶点 $i$ 与 $j$ 之间的最短路长度，条件是所有**中间**顶点的编号不超过 $k$。注意对 $i$ 和 $j$ 无此限制。

### 基

$ \begin{equation}

` sp[i][j][0]=\begin{cases}`
`   w(i, j), & \text{若 $(i, j) \in E$}.\\$
`   0, & \text{否则}.`
` \end{cases}`

\end{equation} $

### 重算

在动态规划第 $k$ 层，我们允许顶点间的路径访问编号 $k$ 的顶点。因此某些 $i$ 和 $j$ 之间的路径可因经过路径 $i \~- k$ 再 $k \~- j$ 而缩短。

于是重算公式如下（$k \\geq 1$）：$ \begin{equation}

` sp[i][j][k]=min\begin{cases}`
`   sp[i][j][k - 1]\\`
`   sp[i][k][k - 1] + sp[k][j][k - 1]`
` \end{cases}`

\end{equation} $

### 答案在哪？

顶点 $i$ 与 $j$ 之间的最短距离在 $sp\[i\]\[j\]\[n\]$。

### 恢复答案

若还需恢复答案，算法中要为每对 $i$、$j$ 记住我们最后一次通过哪个顶点 $k$ 改进。最后，恢复 $i$ 到 $j$ 的路径时，先递归恢复 $i$ 到 $k$（不含）的路径、再递归恢复 $k$ 到 $j$ 的路径，然后输出 $j$。

## 减少内存

注意动态规划每一刻只需存上一 $k-1$ 层，因此可把内存缩小 $n$ 倍——去掉最后一维。

若完全去掉公式中最后一维，则第 $k$ 步动态对某对顶点可能用到已更新的值，从而算出 $k+1$ 层或更高的值。但若只关心最终最短路，这个特效不是问题——$n$ 步后仍得到最短路，只是可能算得更早。

## 负环呢？

### 定理

图有负环 $\\iff$ 算法 $n$ 遍外层迭代后主对角线有负数。而且，所有满足 $sp\[i\]\[i\] \< 0$ 的顶点 $i$ 都位于某个负权环上。

### 证明

#### $\\impliedby$

若主对角线某刻出现负数，说明某刻成立 $sp\[i\]\[k\] + sp\[k\]\[j\] \< 0$，这正意味着环 $ i \~- k \~- i$ 有负权。

#### $\\implies$

设图有负环 $C$。取它中某顶点 $i$。设 $k$ 是 $C$ 中除 $i$ 外编号最大的顶点。若没有，则 $C$ 是负权自环，主对角线初始就有负数。

注意算法第 $k$ 次迭代对 $sp\[i\]\[i\]$ 会考虑值 $sp\[i\]\[k\] + sp\[k\]\[i\]$。且 $sp\[i\]\[k\] \\leq |C\[i:k\]| \\land sp\[k\]\[i\] \\leq |C\[k:i\]| \\implies sp\[i\]\[k\] + sp\[k\]\[i\] \\leq |C| \< 0 \\implies$ 第 $k$ 次迭代 $sp\[i\]\[i\]$ 会是负数，因而所有迭代后更必是。$C\[i:k\]$ 是环 $C$ 在固定遍历下 $i$ 与 $k$ 之间的部分；$C\[k:i\]$ 是环的其余部分。

### 输出负环

算法很简单：

1. 找满足 $sp\[i\]\[i\] \< 0$ 的 $i$。
2. 运行恢复从 $i$ 到 $i$ 最短路径的算法。

注意我们只输出某个负权环。最坏情形可有约 $n\!$ 个。练习：在哪个图里？
