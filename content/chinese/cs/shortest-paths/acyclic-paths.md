如果图中没有环，最短路就非常好找。

此时，求从给定顶点到所有其他顶点的最短距离的问题可以像动态规划那样解决——顶点 $v$ 的最短距离可以通过枚举最短路径上所有可能的最后一条边来求得：

$$
d_v = \min_{(u, v) \in E} (d_u + w_{uv})
$$

要计算这个公式，需要能快速遍历给定顶点 $v$ 的所有反向边，还要找到一种遍历顺序，使得计算 $d_v$ 时所有需要的 $d_u$ 都已算好。

### 实现

具体说，把图转置并转成邻接表格式——即为每个顶点列出所有指向它的边及其权重：

```cpp
vector< pair<int, int> > t[N]; // 边从哪里来及其权重
```

建一个数组 $d$，对每个顶点存它到初始顶点的距离——为方便起见，认为初始顶点编号为 0。除第一个单元外，这个数组初始都填「无穷大」——某个肯定大于任何正确距离的数。

```cpp
vector<int> d(n, inf);
d[0] = 0;
```

现在，按某种[拓扑排序](/cs/graph-traversals/topological-sorting)的顺序——可以通过单独一次遍历得到，也可以某种隐式地得到——遍历图的顶点，用上面的公式考虑其反向边，对 $v$ 的距离做*松弛*（用更优的值更新）：

```cpp
for (int v = 1; u < n; u++)
    for (auto [u, w] : t[v])
        d[v] = min(d[v], d[u] + w);
```

这个算法非常简单，运行在 $O(m)$。

遗憾的是，在一般情形（图中有环）下它不工作：虽然松弛 `d[v] = min(d[v], d[u] + w)` 总是正确的、对任何 $v$ 和 $y$ 都不会破坏什么，但关键假设是我们存在一种遍历顺序，使得所有需要的前驱距离都已算好；而寻找这种顺序的问题，一般并不比求最短路本身更容易。

### 路径恢复

要不仅能得到距离、还能恢复出路径本身，我们可以为每个顶点除了距离外，再存它最后一次松弛来自哪个顶点：

```cpp
vector<int> p(n);

for (int v = 1; u < n; u++) {
    for (auto [u, w] : t[v]) {
        if (d[v] < d[u] + w) {
            d[v] = d[u] + w;
            p[v] = u;
        }
    }
}
```

要恢复出到 $v$ 的最短路，只需沿 $v$ 的前驱走：

```cpp
while (v != 0) {
    cout << v << endl;
    v = p[v];
}
```

在题目中还常有用的是考虑图的「骨架」：跑某个求最短路的算法，然后只保留位于某条路径上的边——即满足 $d_v = d_u + w_{uv}$ 的边。这样的子图是无环的，且容易处理，例如用同样的方式算各种动态规划。

**练习**。 要求在 $O(m)$ 内求出无环图中从 $s$ 到 $t$ 的*最短路径条数*。
