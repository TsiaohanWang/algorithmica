树是编程中最常见的数据结构之一。

树由一组顶点（节点、结点）和它们之间的有向边（链接）组成。顶点之间如此相连：从某个被称为*根*的顶点（图中顶点 8）出发，能以唯一的方式到达其他所有顶点。

![画树时通常把根放在上方](/img/bst.svg)

相关定义：
- 顶点 $v$ 的**父节点**——有一条直接指向 $v$ 的链接的顶点。
- 顶点 $v$ 的**子节点**（孩子、儿子、女儿）——从 $v$ 有直接链接指向的顶点。
- **祖先**——父节点的父节点，它们的父节点，以此类推。
- **后代**——子节点的子节点，它们的子节点，以此类推。
- **叶**（终端顶点）——没有子节点的顶点。
- **子树**——一个顶点连同它的所有后代。
- 顶点的**度**——它的子节点个数。
- 顶点的**深度**——从根到它的距离。
- 树的**高度**——所有顶点深度的最大值。

树在内存中通常表示为由指向其子节点的显式指针构成的动态结构，或者表示为由它们在数组中的位置隐式确定关系的数组元素。

树也用于[图的语境](/cs/trees)。

## 二叉搜索树

二叉搜索树（英文 *binary search tree*，BST）是满足以下性质的树：

- 每个顶点至多有两个子节点。
- 所有顶点带有*键*，键上定义了比较运算（例如整数或字符串）。
- 顶点 $v$ 的*左*子树中所有顶点的键都*不大于* $v$ 的键。
- 顶点 $v$ 的*右*子树中所有顶点的键都*大于* $v$ 的键。
- 左右两棵子树本身也都是二叉搜索树。

更一般的概念是普通（非二叉）搜索树——其中子节点个数可以大于二，并且「更左」子树中的键应小于「更右」子树中的键。目前我们只关注二叉的，因为它们更简单。

二叉搜索树最常见的存储方式是结构体——每个顶点一个——其中记录指向右子和左子的（可能为空的）链接、键以及可能的附加数据。

```cpp
struct Node {
    int x;
    Node *l, *r;
};
```

从名字可以看出，*搜索*二叉树的主要优势在于可以方便地搜索元素：

```cpp
bool find(Node *v, int x) {
    if (!v)
        return false;
    if (v->x == x)
        return true;
    return (v->x < x) ? find(v->l, x) : find(v->r, x);
}
```

这个函数——和许多其他基本操作（如插入或删除元素）一样——最坏情况下耗时与树高成正比。二叉树在最坏情况下的高度可能是 $O(n)$（「竹竿」），因此在高效实现中会维护一些不变量，保证顶点的*平均*深度为 $O(\log n)$，从而基本操作也有相应的代价。这样的树称为*平衡树*。
