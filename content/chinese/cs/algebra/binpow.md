*二进制快速幂（快速幂*）是一种技巧，它只需 $O(\log n)$ 次乘法就能把任意数求 $n$ 次幂（而普通做法需要 $n$ 次乘法）。

## 核心思想

注意，对任意数 $a$ 和*偶数* $n$，下面的恒等式成立：

$$
a^n = (a^{n/2})^2 = a^{n/2} \cdot a^{n/2}
$$

也就是说，对于任意偶数 $n$，我们只需一次乘法运算就能把问题规模减半（$n' = \frac{n}{2}$）。

如果 $n$ 是*奇数*，那么有：

$$
a^n = a^{n-1} \cdot a 
$$

也就是说，对于奇数 $n$，我们可以把问题化归到规模为 $(n-1)$ 的子问题，而它将是偶数。

我们实际上得到了计算 $a^n$ 的递推公式：

$$
a^n = f(a, n) = \begin{cases}
   1,               && n = 0
\\ f(a, \frac{n}{2})^2,     && 2 \mid n
\\ f(a, n - 1) \cdot a, && 2 \nmid n
\end{cases}
$$

因为每两次转移 $n$ 都保证至少减半，所以在到达 $n = 0$ 之前，最多会有 $2 \cdot \log_2 n$ 次转移。每次转移正好需要一次乘法，于是我们得到了只需 $O(\log n)$ 次乘法的算法。

## 实现

最直接的想法是这个算法的递归实现：

```cpp
int binpow(int a, int n) {
    if (n == 0)
        return 1;
    if (n % 2 == 1)
        return binpow(a, n - 1) * a;
    else {
        int b = binpow(a, n / 2);
        return b * b;
    }
}
```

这个实现是递归的，运行起来比较慢。我们试着把递归「展开」，得到一个迭代版本。

考察数 $n$ 的二进制表示。结果 $a^n$ 可以表示为 $a$ 的某些 2 的幂次幂的乘积。例如，若 $n = 42 = 32 + 8 + 2$，则

$$
a^{42} = a^{32+8+2} = a^{32} \cdot a^8 \cdot a^2 
$$

为了迭代地计算这个乘积，我们遍历 $n$ 的所有二进制位，并维护两个变量：结果本身，以及当前迭代轮次 $k$ 对应的 $a^{2^k}$。每一步，如果 $n$ 的第 $k$ 位是 1，就把 $a^{2^k}$ 乘进当前结果；无论如何，都要把它平方，得到下一轮要用的 $a^{2^k \cdot 2} = a^{2^{k+1}}$。

```cpp
int binpow(int a, int n) {
    int res = 1;
    while (n != 0) {
        if (n & 1)
            res = res * a;
        a = a * a;
        n >>= 1;
    }
    return res;
}
```

值得一提的是，很多编程语言已经内置了二进制快速幂。但 C++ 没有：标准库中的 `pow` 函数只支持实数，并使用近似方法，因此对整数参数无法给出精确结果。

## 推广

二进制快速幂不仅适用于数的乘法，还适用于任意*可结合*的运算——即对任意 $a$、$b$ 和 $c$ 满足：

$$
(a \circ b) \circ c = a \circ (b \circ c) 
$$

最明显的推广是[模运算](/cs/modular)：

```cpp
const int mod = 1e9 + 7;

long long binpow(long long a, int n) {
    long long  res = 1;
    while (n != 0) {
        if (n & 1)
            res = res * a % mod;
        a = a * a % mod;
        n >>= 1;
    }
    return res;
}
```

第二「热门」的推广是矩阵乘法，我们会在[下一篇文章](../matrix)中详细讨论。

### 等比数列

在组合数学中经常需要对某些对象求幂；除此之外，有时还需要计算下面这种和：

$$
S = 1 + a + a^2 + \ldots a^{n-1}
$$

简单情况下这就是等比数列求和，代数上它等于 $\frac{1-a^n}{1-a}$，所以可以先算 $a^n$（用二进制快速幂），再把 $(1-a^n)$ 除以 $(1-a)$。但一般情况下不能这么干——例如，至少因为[并非所有模数下](/cs/modular/reciprocal)都存在逆元。因此，对这类公式需要把二进制快速幂稍作修改：

$$
\begin{aligned}
f(a, n)  &= 1 + a + a^2 + \ldots a^{n-1}
\\ &= (1 + a + \ldots + a^{n/2}) + a^{n/2} \cdot (1 + a + \ldots a^{n/2})
\\ &= (1 + a^{n/2}) \cdot f(a, n)
\end{aligned}
$$
